## Commands

### `push.convert`

**Push 2 Convert**. Permission: `edit`. Contexts: `global`.

What Push 2's Convert button makes of what is selected, as one undo step: with a Simpler in Classic or One-Shot mode, a new MIDI track after the selected one with a drum rack holding a copy of the Simpler on the pad for note 36 and copies of the track's other devices in their places; with a Simpler in Slice mode, the Simpler replaced by a drum rack of its slices (the same as `device.slice_to_drum_rack`); with a drum rack pad selected, a new MIDI track holding copies of the pad's devices; with an audio clip selected, a new MIDI track with a Simpler holding its sample (`to` `simpler`, the default) or with a drum rack holding it in a Simpler on its first pad (`drum_rack`), either way with the clip's warp settings and copies of the track's devices. Refused when none of these is selected. Read back by `song.query` of `tracks`.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `to` | [`PushConvertTo`](README.md#pushconvertto) or null | no | For an audio clip: what to make of it. Left out, a Simpler. |

Result: [`PushConverted`](README.md#pushconverted).

### `push.display_frame`

**Push 2 Display Frame**. Permission: `read`. Contexts: `global`.

Returns what Push 2's display shows as a 960 × 160 PNG, base64, drawn from the same content `push.state` reports as text. Changes nothing.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `row` | integer or null | no | The row, from 1 to 6. Left out, the first Push 2. |

Result: [`PushDisplayFrame`](README.md#pushdisplayframe).

### `push.duplicate`

**Push 2 Duplicate**. Permission: `edit`. Contexts: `global`.

Push 2's Duplicate button pressed alone. With Workflow Scene (or `scene`) it runs Capture and Insert Scene, so the new scene plays without a break. With Workflow Clip it copies the selected clip into the slot below, inserting a scene if that slot holds a clip, and launches the copy as a Legato launch, leaving the other tracks playing. One undo step.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `scene` | boolean | no | For `push.duplicate`: capture a scene, as Shift with Duplicate does, whatever the Workflow. |
| `workflow` | [`PushWorkflow`](README.md#pushworkflow) or null | no | The Workflow to act as. Left out, the Setup menu's. |

Result: nothing (`null`).

### `push.new`

**Push 2 New**. Permission: `edit`. Contexts: `global`.

Push 2's New button: stops the selected track's clip and selects an empty slot on it to record into. With Workflow Scene it inserts a scene after the selected one holding copies of the clips playing on the other tracks, which carry on from it, and selects the track's empty slot there; with Workflow Clip it selects the next empty slot below on the track, inserting a scene if there is none. One undo step.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `scene` | boolean | no | For `push.duplicate`: capture a scene, as Shift with Duplicate does, whatever the Workflow. |
| `workflow` | [`PushWorkflow`](README.md#pushworkflow) or null | no | The Workflow to act as. Left out, the Setup menu's. |

Result: nothing (`null`).

### `push.set_fixed_length`

**Set Push 2 Fixed Length**. Permission: `edit`. Contexts: `global`.

Sets Fixed Length on Push 2: whether it is on, the length of the clip a Session recording makes (1 beat, 2 beats, 1 bar, 2 bars, 4 bars, 8 bars, 16 bars or 32 bars) and Phrase Sync. They are preferences, kept between launches and the same for every set. With Fixed Length on, `session.record` makes an empty clip of the length and ends by itself at its end. Read back by `push.state` (`recording.fixed_length`).

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `enabled` | boolean or null | no | Whether Fixed Length is on. |
| `length` | [`PushFixedLengthValue`](README.md#pushfixedlengthvalue) or null | no | The length of the clip a recording makes. |
| `phrase_sync` | boolean or null | no | Whether Phrase Sync is on. |

Result: [`PushFixedLength`](README.md#pushfixedlength).

### `push.set_mode`

**Set Push 2 Mode**. Permission: `read`. Contexts: `global`.

Sets the pad mode (`note` or `session`) and the display mode (`device`, `browse`, `mix` or `clip`, with Mix's page) of one Push 2 or all of them, as a tap on their buttons does; an open menu closes. The surface switches on its next tick. Changes only what Push 2 shows, never the set. Read back by `push.state`.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `display` | [`PushDisplayMode`](README.md#pushdisplaymode) or null | no | The display mode to switch to. |
| `mix` | [`PushMixPage`](README.md#pushmixpage) or null | no | Mix's page, with `display` `mix`; Track Mix if left out. |
| `pad` | [`PushPadMode`](README.md#pushpadmode) or null | no | The pad mode to switch to. |
| `row` | integer or null | no | The row, from 1 to 6. Left out, every Push 2. |

Result: [`PushSetModeResult`](README.md#pushsetmoderesult).

### `push.set_setup`

**Set Push 2 Setup**. Permission: `edit`. Contexts: `global`.

Sets Push 2's Setup menu: Pad Sensitivity, Pad Gain and Pad Dynamics (0 to 10, which shape the velocity curve), Display Light and LED Brightness (0 to 100 %) and PushWorkflow (`scene` or `clip`), any of them. The values are preferences, kept between launches and the same for every set, and reach every Push 2 that runs. Read back by `push.state` (`setup`).

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `display_light` | integer or null | no | Display Light, 0 to 100 %. |
| `led_brightness` | integer or null | no | LED Brightness, 0 to 100 %. |
| `pad_dynamics` | integer or null | no | Pad Dynamics, 0 to 10. |
| `pad_gain` | integer or null | no | Pad Gain, 0 to 10. |
| `pad_sensitivity` | integer or null | no | Pad Sensitivity, 0 to 10. |
| `workflow` | [`PushWorkflow`](README.md#pushworkflow) or null | no | Workflow. |

Result: [`PushSetup`](README.md#pushsetup).

### `push.set_swing`

**Set Push 2 Swing Amount**. Permission: `edit`. Contexts: `global`.

Sets the swing amount, 0 to 100 %: the share of half a step by which Repeat and Quantize delay every second note. A preference, the same as Push 2's swing encoder and its Quantize menu set. Read back by `push.state` (`recording.swing`).

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `amount` | integer from 0 to 100 | yes | The swing amount, 0 to 100 %. |

Result: [`uint8`](README.md#uint8).

### `push.state`

**Push 2 State**. Permission: `read`. Contexts: `global`.

Reads each Push 2 that runs in the Control Surfaces table: its ports, firmware version and power supply; its MIDI mode; the pad mode, the display mode (with Track Mix or Global Mix), any open menu and the buttons held or locked; each LED's colour index and animation by control name; the touch strip's configuration and LEDs; the Setup menu's values; and the display's content as text, by band and column: labels, parameter names and values, dots, notifications; and, in Browse Mode, what Load does, its columns with their entries and selection and the column in use; in Device Mode, the devices on the upper buttons with their depth and which is selected, whether Edit Mode is on, the bank and its page of banks, the parameters on the encoders, the chains shown while a rack's button is held, and whether Mute is locked; in Mix Mode, Track Mix's view, what Global Mix sets, the sends' shift, the eight tracks or chains shown with what each encoder sets and its value, and the groups and racks that are unfolded; and, in Session Mode, the ring, what each pad and Scene/Grid button shows, whether Session Overview is shown or locked and the Stop Clip lock. Changes nothing.

Default keys: none.

Arguments: none (send `{}`).

Result: [`PushState`](#pushstate).
