## Commands

### `mixer_view.crossfader`

**Mixer Crossfader**. Permission: `read`. Contexts: `global`.

Shows or hides the mixers' Crossfader section, as View > Mixer Controls > Crossfader does: under the strips, a track's A and B assign buttons and, in Main's column, the crossfader itself. Hidden in a new set. Switches unless `shown` says which. Changes only the view; the assign and the position are in the set (`mixer.set_crossfade_assign`, `mixer.set_crossfader`).

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `shown` | boolean or null | no | Show it (true) or hide it (false); switches it if left out. |

Result: [`MixerViewState`](README.md#mixerviewstate).

### `mixer_view.devices`

**Mixer Devices**. Permission: `read`. Contexts: `global`.

Shows or hides the mixers' Devices section, as View > Mixer Controls > Devices does: between In/Out and Sends, each track's top-level devices in chain order, each with its activator and name. A click on a name selects the device and shows the Device View; a click on an activator switches the device. Hidden in a new install. Switches unless `shown` says which. Changes only the view; the devices and whether each is on are in the query tool's `track` devices, as `enabled`.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `shown` | boolean or null | no | Show it (true) or hide it (false); switches it if left out. |

Result: [`MixerViewState`](README.md#mixerviewstate).

### `mixer_view.focus`

**Move Focus to Mixer**. Permission: `read`. Contexts: `arrangement`.

Moves the keyboard focus to the Arrangement View's mixer, as Navigate > Mixer (Option-Shift-M) does, showing it if it's hidden: to the selected track's column, or the first track's. Left and Right then move the track selection. Changes only the view.

### `mixer_view.fold_chains`

**Fold Rack Chains**. Permission: `read`. Contexts: `global`.

Folds a rack's chains out in the mixers as strips after the track's, as the fold button in the track's title bar does, or folds them back in. `rack` is the rack: a rack of more than one chain, on a track or inside another rack's chain. A track's fold button is for the instrument or drum rack it holds; a chain's is for the rack inside it. A rack of one chain has no chains to fold out. Switches unless `shown` says which. Changes only the view, and isn't saved with the set; the chains it shows read back in `mixer_view.state`.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `rack` | [`DeviceId`](README.md#deviceid) | yes | The rack whose chains fold out. |
| `shown` | boolean or null | no | Show them (true) or hide them (false); switches them if left out. |

Result: [`MixerViewState`](README.md#mixerviewstate).

### `mixer_view.return_tracks_scroll`

**Return Tracks Scroll with Tracks**. Permission: `read`. Contexts: `global`.

Scrolls the return tracks with the other tracks, in the Session View's grid, in the Arrangement View's lanes and in both mixers, as View > Mixer Controls > Return Tracks Scroll with Tracks does: the returns come after the drop area and only Main stays pinned at the right. Off in a new install, so the returns stay pinned, as in Live. It is an application setting, kept between launches and not saved with the set. Switches unless `on` says which. Changes only the view.

Default keys: none.

### `mixer_view.scroll`

**Scroll Mixer**. Permission: `read`. Contexts: `global`.

Scrolls a mixer's track columns sideways by `x` points (positive towards the last track), as the wheel over the mixer does. The return tracks and Main stay put. It can't scroll before the first track or past the last. Acts on the view in front unless `view` names one. Changes only the view.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `x` | number | yes | Points to scroll sideways at 100%: positive towards the last track. |
| `view` | [`MixerOf`](README.md#mixerof) or null | no | Which view's mixer; the view in front if left out. |

Result: [`MixerViewState`](README.md#mixerviewstate).

### `mixer_view.state`

**Mixer View State**. Permission: `read`. Contexts: `global`.

Reports what the mixers show: whether the Session View's and the Arrangement View's mixers are shown and how far each is scrolled, and which sections (In/Out, Sends, the volume strips, the return tracks, the Performance Impact, the Devices) show. The Performance Impact values are the engine's last, one entry per track: how many of the six segments are lit and the track's share of the set's processing time. Track values (volume, pan, the activator, Solo, Arm, routing, sends, the crossfader assignment) are in the set; read them with the query tool: a track with `detail: "full"` returns them as the set saves them. Changes nothing.

Default keys: none.

Arguments: none (send `{}`).

Result: [`MixerViewState`](README.md#mixerviewstate).
