## Commands

### `perception.analyze`

**Analyze Audio**. Permission: `read`. Contexts: `global`.

Measures audio and reports numbers with units: loudness (integrated, momentary and short-term LUFS, loudness range in LU, true peak in dBTP, as ITU-R BS.1770-4 and EBU R 128 define them), sample peak and RMS in dBFS, the level in each octave band from 31.5 Hz to 16 kHz, the tempo in BPM, the key, and when transients start. Give `preview` to measure a preview, or a range (`start`, `length`, and `track`, as for `perception.preview`) to render one for the analysis, up to ten minutes. `measure` picks what to measure; left out, everything. Tempo and key are estimates from the audio, not the set's settings. A range renders as `perception.preview` does, refused likewise while the transport plays a set with a CLAP plug-in. Changes nothing in the set.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `length` | [`Ticks`](README.md#ticks) or null | no | How long the range is, in ticks (705,600 to the quarter note, so a 4/4 bar is 2,822,400). Left out, to the end of the time selection, or without one to the end of the set's last clip. |
| `measure` | array or null | no | What to measure. Left out, everything. |
| `preview` | integer or null | no | A preview to analyse, by the ID `perception.preview` gave. Left out, the range below is rendered for the analysis (up to ten minutes). |
| `start` | [`Position`](README.md#position) or null | no | Without `preview`: where the range starts, as ticks from 1.1.1 or bar.beat.sixteenth text such as `"9.1.1"`. Left out, the start of the Arrangement's time selection, or 1.1.1 without one. |
| `track` | [`TrackId`](README.md#trackid) or null | no | One track to hear on its own, as it sounds soloed: through its group tracks and the Main track, with the returns its sends reach while Solo in Place is on. Left out, the whole mix: the Main output. |

Result: [`AnalyzeResult`](README.md#analyzeresult).

### `perception.capture_view`

**Capture View**. Permission: `read`. Contexts: `global`.

Captures one of the app's views as a PNG image, as the person sees it, for a model that reads images: the whole `window`, the `arrangement` or `session` view, the `mixer`, the `browser`, the `detail` area (Clip or Device View), or the `settings` window. The view must be on screen. The image is scaled to fit `max_size` pixels. Only the agent API's `capture_view` tool returns the image, and only while the app's window is open: headless (`bl-cli mcp`) there's no window to capture. Changes nothing.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `view` | [`View`](README.md#view) | yes | The view to capture. It must be on screen: the main window shows the Arrangement or the Session View, and the browser, the mixer, and the Settings window only while they're open. |
| `max_size` | integer or null | no | The longest side of the image, in pixels, from 256 to 4,096: a larger capture is scaled down to fit. Left out, 1,568. |

Result: [`CaptureResult`](README.md#captureresult).

### `perception.preview`

**Preview Audio**. Permission: `read`. Contexts: `global`.

Renders a short audio preview of a range of the set, offline, through the engine that exports, and keeps it as a WAV file for you to listen to: the agent API's `preview` tool returns it as audio, and `uri` reads it as a resource. The range is `start` and `length` if given, otherwise the Arrangement's time selection, otherwise the whole set; it plays straight through, without the loop, and is cut to its first 30 seconds. `track` previews one track as it sounds soloed; left out, the whole mix. 16-bit stereo at 48 kHz is about 190 KB a second: a lower `sample_rate` makes it smaller. Plug-in devices render through the plug-ins the engine plays, lent to the render, so while the transport plays a set with a CLAP plug-in the preview is refused (run `transport.stop` first); otherwise rendering doesn't stop or disturb playback. The last 4 previews are kept, for `perception.analyze`. Changes nothing in the set.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `bit_depth` | one of `16`, `24`, `32` | no | Bits per sample: 16 (the default, with triangular dither), 24, or 32 (floating point). |
| `length` | [`Ticks`](README.md#ticks) or null | no | How long the range is, in ticks (705,600 to the quarter note, so a 4/4 bar is 2,822,400). Left out, to the end of the time selection, or without one to the end of the set's last clip. |
| `sample_rate` | integer or null | no | The preview's sample rate in hertz, from 8,000 to 192,000. Left out, the engine's rate. A lower rate makes a smaller file. |
| `start` | [`Position`](README.md#position) or null | no | Where the range starts: ticks from 1.1.1, or bar.beat.sixteenth text such as `"9.1.1"`. Left out, the start of the Arrangement's time selection, or 1.1.1 without one. |
| `track` | [`TrackId`](README.md#trackid) or null | no | One track to hear on its own, as it sounds soloed: through its group tracks and the Main track, with the returns its sends reach while Solo in Place is on. Left out, the whole mix: the Main output. |

Result: [`PreviewResult`](README.md#previewresult).
