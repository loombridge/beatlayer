## Commands

### `chord_lane.add_region`

**Add Chord Region**. Permission: `edit`. Contexts: `arrangement`.

Adds a region to the chord lane, as drawing in the lane does: `region` has a new `id`, a `start` and an `end` in ticks on the song's beats (1.1.1 or later, the end after the start), optionally a `scale` (`enabled`, `root` 0 is C, `name` from `song.scales`) and a `transpose` from -24 to 24 (0 by default). Regions never overlap: one that would is refused and nothing changes. A MIDI track that follows the lane (`track.set_follow_chord_lane`) plays its Arrangement clips' notes moved by the transposition of the region they start in: by that many degrees of the clip's scale where the clip's Scale Mode is on, by that many semitones where it is off. Where the region names a scale, the track's scale-aware devices take it as their current scale. Nothing in the clips changes. One undo step, `Add Chord Region`. `song` reads the regions in its `chord_lane` field.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `region` | [`ChordRegion`](README.md#chordregion) | yes | The region, with a new ID. |

Result: [`ChangeSet`](README.md#changeset).

### `chord_lane.delete_region`

**Delete Chord Region**. Permission: `destructive`. Contexts: `arrangement`.

Deletes a chord region, as selecting it and pressing Delete does. The tracks that follow the lane play the notes as written where it was. One undo step, `Delete Chord Region`. Because it removes the person's work, an agent asks first.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `region` | [`ChordRegionId`](README.md#chordregionid) | yes | The region. |

Result: [`ChangeSet`](README.md#changeset).

### `chord_lane.move_region`

**Move Chord Region**. Permission: `edit`. Contexts: `arrangement`.

Moves a chord region, or resizes it, to the new `start` and `end` in ticks, as dragging it or one of its edges does. A move that would overlap another region, start before 1.1.1 or end the region at or before its start is refused and nothing changes. One undo step, `Move Chord Region`.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `region` | [`ChordRegionId`](README.md#chordregionid) | yes | The region. |
| `start` | [`Ticks`](README.md#ticks) | yes | Where it starts: 1.1.1 or later. |
| `end` | [`Ticks`](README.md#ticks) | yes | Where it ends: after its start, and overlapping no other region. |

Result: [`ChangeSet`](README.md#changeset).

### `chord_lane.select_region`

**Select Chord Region**. Permission: `read`. Contexts: `arrangement`.

Selects the chord region `region`, as clicking it does; left out, no region is selected. The Delete key deletes the selected region. Selecting is never an undo step and changes nothing in the set. `arrangement.state` reports the region as `selected_chord_region`.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `region` | [`ChordRegionId`](README.md#chordregionid) or null | no | The region. Left out, no region is selected. |

Result: [`ArrangementState`](README.md#arrangementstate).

### `chord_lane.set_region`

**Set Chord Region**. Permission: `edit`. Contexts: `arrangement`.

Sets a chord region's scale and transposition, as its context menu does: `enabled` (whether it names a scale; false leaves the clips' own), `root` (0 is C and 11 is B), `name` (one of the names `song.scales` reads) and `transpose` (from -24 to 24, in degrees of each clip's scale where the clip's Scale Mode is on and in semitones where it is off). It leaves the values it isn't given as they were. One undo step, `Change Chord Region`.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `region` | [`ChordRegionId`](README.md#chordregionid) | yes | The region. |
| `enabled` | boolean or null | no | Whether the region names a scale: false leaves the clips' own. |
| `name` | string or null | no | The scale's name, from the scale list. |
| `root` | integer or null | no | The scale's root note: 0 (C) to 11 (B). |
| `transpose` | integer or null | no | How far the region moves the notes of the tracks that follow the lane: from -24 to 24. |

Result: [`ChangeSet`](README.md#changeset).
