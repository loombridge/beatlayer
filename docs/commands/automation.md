## Commands

### `automation.copy`

**Copy Automation**. Permission: `read`. Contexts: `arrangement`, `envelope`.

Copies the shape of the envelopes the time selection covers to the Arrangement's clipboard, for `automation.paste`: the shape over the span, with its positions from the span's start, its values as positions on each parameter's travel, and its bends. The clipboard isn't part of the set, and copying changes nothing in it.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `end` | [`Position`](README.md#position) or null | no | Where the span ends, after `start`. Left out, the time selection's end. |
| `lanes` | array or null | no | The lanes the shape is in: each a track and the parameter its automation lane shows. Left out, the automation lanes the time selection covers. |
| `start` | [`Position`](README.md#position) or null | no | Where the span starts. Left out, the time selection's start. |

Result: [`EnvelopeClipboardState`](README.md#envelopeclipboardstate).

### `automation.cut`

**Cut Automation**. Permission: `destructive`. Contexts: `arrangement`, `envelope`.

Copies the shape of the envelopes the time selection covers, as `automation.copy` does, then deletes it, as `automation.delete_range` does: the breakpoints inside the span go, and the envelope's values at the span's edges are kept, so it runs straight across the span. Because it removes the person's work, an agent asks first.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `end` | [`Position`](README.md#position) or null | no | Where the span ends, after `start`. Left out, the time selection's end. |
| `lanes` | array or null | no | The lanes the shape is in: each a track and the parameter its automation lane shows. Left out, the automation lanes the time selection covers. |
| `start` | [`Position`](README.md#position) or null | no | Where the span starts. Left out, the time selection's start. |

Result: [`AutomationResult`](README.md#automationresult).

### `automation.delete`

**Delete Automation**. Permission: `destructive`. Contexts: `global`.

Deletes all of one of a track's parameters' automation: its envelope and every breakpoint on it, as Delete Automation in the control's context menu does. The control's value stays where it is and the parameter follows it again. Nothing changes if the parameter has no automation.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `track` | [`TrackId`](README.md#trackid) | yes | The track the parameter belongs to. |
| `target` | [`AutomationTarget`](README.md#automationtarget) | yes | The parameter. |

Result: [`ChangeSet`](README.md#changeset).

### `automation.delete_breakpoint`

**Delete Automation Breakpoint**. Permission: `edit`. Contexts: `global`.

Deletes one of a track's automation breakpoints, so the segments either side of it become the one starting at the breakpoint before it, as clicking a breakpoint on an automation lane does. Deleting the last one takes the parameter's envelope with it, so the parameter follows its control again. A position with no breakpoint is refused.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `track` | [`TrackId`](README.md#trackid) | yes | The track the parameter belongs to. |
| `target` | [`AutomationTarget`](README.md#automationtarget) | yes | The parameter. |
| `at` | [`Ticks`](README.md#ticks) | yes | Where the breakpoint is. |

Result: [`ChangeSet`](README.md#changeset).

### `automation.delete_range`

**Delete Automation Range**. Permission: `destructive`. Contexts: `arrangement`, `envelope`.

Deletes the shape of the envelopes the time selection covers over the span: the breakpoints inside it go, and the envelope's values at the span's edges are kept with a breakpoint at each, so the envelope runs straight across the span and is unchanged outside it. The clips and the other envelopes stay as they are. Because it removes the person's work, an agent asks first.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `end` | [`Position`](README.md#position) or null | no | Where the span ends, after `start`. Left out, the time selection's end. |
| `lanes` | array or null | no | The lanes the shape is in: each a track and the parameter its automation lane shows. Left out, the automation lanes the time selection covers. |
| `start` | [`Position`](README.md#position) or null | no | Where the span starts. Left out, the time selection's start. |

Result: [`AutomationResult`](README.md#automationresult).

### `automation.duplicate`

**Duplicate Automation**. Permission: `edit`. Contexts: `arrangement`, `envelope`.

Result: [`AutomationResult`](README.md#automationresult).

### `automation.move_breakpoint`

**Move Automation Breakpoint**. Permission: `edit`. Contexts: `global`.

Moves one of a track's automation breakpoints from `at` to `to` and, with `value`, to that value, as dragging it on an automation lane does. `to` is 0 (1.1.1) or later and mustn't land on another breakpoint of the same envelope, and `value` is in the parameter's own units. Without `value` the breakpoint keeps its value. A position with no breakpoint is refused.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `track` | [`TrackId`](README.md#trackid) | yes | The track the parameter belongs to. |
| `target` | [`AutomationTarget`](README.md#automationtarget) | yes | The parameter. |
| `at` | [`Ticks`](README.md#ticks) | yes | Where the breakpoint is now. |
| `to` | [`Ticks`](README.md#ticks) | yes | Where it goes: 0 (1.1.1) or later, and not where another breakpoint of the same envelope already is. |
| `value` | number or null | no | The value it takes there, in the parameter's own units, or `null` (or nothing) to keep the value it has. |

Result: [`ChangeSet`](README.md#changeset).

### `automation.move_breakpoints`

**Move Automation Breakpoints**. Permission: `edit`. Contexts: `arrangement`, `envelope`.

Moves several breakpoints of one track's parameter at once, as dragging a selected breakpoint on an automation lane does: each moves `by` ticks in time and `share` of the parameter's travel in value, staying within the parameter's range, and a breakpoint the moved ones pass over is removed. `at` names the breakpoints to move, where they are now. One undo step.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `track` | [`TrackId`](README.md#trackid) | yes | The track the parameter belongs to. |
| `target` | [`AutomationTarget`](README.md#automationtarget) | yes | The parameter: a mixer control, a send, or a device parameter. |
| `at` | array of [`Ticks`](README.md#ticks) | yes | The breakpoints to move, where they are now. |
| `by` | [`Ticks`](README.md#ticks) | yes | How far to move them in time, in ticks; negative is earlier. |
| `share` | number | yes | How far to move their values, as a share of the parameter's travel: 0.1 is a tenth of the way up the control, and −0.1 a tenth down. |

Result: [`AutomationResult`](README.md#automationresult).

### `automation.paste`

**Paste Automation**. Permission: `edit`. Contexts: `arrangement`, `envelope`.

Pastes the clipboard's shape into the envelopes the time selection covers, starting at `at` (left out, the time selection's start or the insert marker) and replacing each envelope over the shape's length. Each value lands at the same position on the target parameter's travel, so a shape pastes onto another parameter. One undo step.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `at` | [`Position`](README.md#position) or null | no | Where the shape starts. Left out, the time selection's start, or the insert marker. |
| `lanes` | array or null | no | The lanes the shape is pasted into: each a track and the parameter its automation lane shows. Left out, the automation lanes the time selection covers. |

Result: [`AutomationResult`](README.md#automationresult).

### `automation.re_enable`

**Re-Enable Automation**. Permission: `edit`. Contexts: `global`.

Turns every overridden envelope in the song back on, as the Control Bar's Re-Enable Automation button does: every automated control that a hand move turned off follows its envelope again. It's one undo step, and nothing changes when no envelope is overridden. Use `automation.re_enable_for` for one parameter.

Default keys: none.

Arguments: none (send `{}`).

Result: [`ChangeSet`](README.md#changeset).

### `automation.re_enable_for`

**Re-Enable Automation for a Parameter**. Permission: `edit`. Contexts: `global`.

Turns one parameter's overridden envelope back on, as Re-Enable Automation in that control's context menu does. `track` and `target` name the parameter the same way `automation.set_breakpoint` does. Nothing changes if the parameter's envelope isn't overridden.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `track` | [`TrackId`](README.md#trackid) | yes | The track the parameter belongs to. |
| `target` | [`AutomationTarget`](README.md#automationtarget) | yes | The parameter. |

Result: [`ChangeSet`](README.md#changeset).

### `automation.select_breakpoint`

**Select Automation Breakpoint**. Permission: `read`. Contexts: `arrangement`, `envelope`.

Selects a breakpoint in a track's automation lane, as Enter or Option-click does: the lane gets the keyboard, the insert marker moves to the breakpoint, and an edit begins that ends when the selection is cleared with `at` `null` (keeping the changes) or the focus leaves; every change in between is one undo step. `at` may be a position where no breakpoint is yet, for `automation.set_breakpoint` to make one there as part of the same edit. `arrangement.state` reports the selection. Changes nothing in the set itself.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `track` | [`TrackId`](README.md#trackid) | yes | The track whose automation lane holds the breakpoint. |
| `target` | [`AutomationTarget`](README.md#automationtarget) | yes | The parameter the lane shows. |
| `at` | [`Ticks`](README.md#ticks) or null | no | The position of the breakpoint to select, or `null` to keep the edit and select none. |

Result: [`EnvelopeKeyState`](README.md#envelopekeystate).

### `automation.select_segment`

Selects a segment in a track's automation lane, as clicking near it does: its two breakpoints are drawn in the selection colour and move together when it is dragged. `at` is the breakpoint the segment starts at, or `null` to select no segment. Changes nothing in the set.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `track` | [`TrackId`](README.md#trackid) | yes | The track whose automation lane holds the segment. |
| `target` | [`AutomationTarget`](README.md#automationtarget) | yes | The parameter the lane shows. |
| `at` | [`Ticks`](README.md#ticks) or null | no | The breakpoint the segment starts at, or `null` to select no segment. |

Result: [`AutomationResult`](README.md#automationresult).

### `automation.set_breakpoint`

**Set Automation Breakpoint**. Permission: `edit`. Contexts: `global`.

Sets one of a track's automatable parameters at `at` on its envelope, adding a breakpoint there or replacing the value of the one that's there, as clicking or dragging a breakpoint on an automation lane does. `target` names the parameter: `{"type": "mixer", "param": "volume"}`, `{"type": "send", "to": <return track>}`, or `{"type": "device", "device": <device>, "param": <parameter>}`, or, on an audio track, a sound setting of its audio clips: `{"type": "clip", "param": "formants"}` (`gain` as linear gain, `transpose` in semitones, `detune` in cents, `high_quality`, `sample_offset` in sixteenths, and the warp modes' controls), which drives that setting of every audio clip on the track as it plays. A parameter with no envelope yet gets its first breakpoint and its envelope drives it from then on. Values are in the parameter's own units: volume as linear gain, pan from -1 to 1, the Track Activator 1 for muted, and a device parameter as the device's own value. `at` is 0 (1.1.1) or later. The value between two breakpoints follows the segment's shape: the straight line unless `automation.set_curve` bent it; before the first and after the last the nearest one's value holds.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `track` | [`TrackId`](README.md#trackid) | yes | The track the parameter belongs to. |
| `target` | [`AutomationTarget`](README.md#automationtarget) | yes | The parameter: a mixer control, a send, or a device parameter. |
| `at` | [`Ticks`](README.md#ticks) | yes | Where the breakpoint sits: 0 (1.1.1) or later. |
| `value` | number | yes | The value there, in the parameter's own units. |

Result: [`ChangeSet`](README.md#changeset).

### `automation.set_curve`

**Curve Automation Segment**. Permission: `edit`. Contexts: `global`.

Curves one of a track's automation segments, as holding Alt (Windows) or Option (macOS) while dragging a line segment on an automation lane does. `track` and `target` name the parameter as `automation.set_breakpoint` does, and `at` is the position of the breakpoint the segment starts at. `bend` is a signed number from -1 to 1: 0 is the straight line, the sign chooses which side the segment bows to, and its size how far. Between the two breakpoints the value is `from + (to - from) * t^(2^bend)`, `t` running from 0 at the segment's start to 1 at its end, so the value stays between the two breakpoints' values. A bend of 0 straightens the segment again, as the same drag with a double-click does. Refused when no breakpoint is at `at`, or when `at` is the last breakpoint, with no segment after it. Beatlayer's own law: Live's curved shape isn't measured yet.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `track` | [`TrackId`](README.md#trackid) | yes | The track the parameter belongs to. |
| `target` | [`AutomationTarget`](README.md#automationtarget) | yes | The parameter. |
| `at` | [`Ticks`](README.md#ticks) | yes | Where the segment starts: the breakpoint there. |
| `bend` | number | yes | The bend, from −1 to 1: 0 is the straight line, and the sign chooses which side the segment bows to. |

Result: [`ChangeSet`](README.md#changeset).

### `automation.set_envelope`

**Set Automation Envelope**. Permission: `edit`. Contexts: `global`.

Replaces one of a track's parameter's envelope with the breakpoints given, as the automation editing commands do when they write a shape over a span of time. `track` and `target` name the parameter as `automation.set_breakpoint` does, and `points` are the envelope's breakpoints in position order, each with its position in ticks, its value in the parameter's own units, and the bend of the segment starting at it. The breakpoints must be in order, no two at one position, and no position before 1.1.1; an empty list takes the parameter's automation with it. The envelope keeps driving the parameter.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `track` | [`TrackId`](README.md#trackid) | yes | The track the parameter belongs to. |
| `target` | [`AutomationTarget`](README.md#automationtarget) | yes | The parameter. |
| `points` | array of [`Breakpoint`](README.md#breakpoint) | yes | The envelope's breakpoints, in position order. Empty takes the parameter's automation with it. |

Result: [`ChangeSet`](README.md#changeset).
