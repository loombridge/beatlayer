## Commands

### `take_lane.audition`

**Audition Take Lane**. Permission: `edit`. Contexts: `arrangement`, `take-lanes`.

Switches the audition of the take `lanes` (left out, the take lanes the selection is on: the headers, the time selection or the clips selected are on them) on or off, one lane for each track: of the lanes listed on one track, the last. Left without `on`, it switches them on, or off when each is auditioned already. While a take lane is auditioned its track plays it in place of its main lane (`take_lane.set_audition`). One undo step, `Audition Take Lane`. T runs it.

Default keys:

| Shortcut | macOS | Windows | Context | Action in the reference | Binding |
|---|---|---|---|---|---|
| S-COMP-003 | `T` | `T` | `take-lanes` | Audition the selected take lane | runs it |

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `lanes` | array or null | no | The take lanes to audition; of those on one track, the last listed is the one. Left out, the take lanes the selection is on. |
| `linked` | boolean or null | no | Whether it reaches the tracks linked with the ones it names (the linked-track editing spec, R15). `true` if left out. |
| `on` | boolean or null | no | Switch them on (true) or off (false). Left out, they switch on, or off when every one of them is auditioned already. |

Result: [`LanesResult`](README.md#lanesresult).

### `take_lane.comp_sources`

**Comp Sources**. Permission: `read`. Contexts: `arrangement`.

Reports which take-lane material a track's main lane uses: a main-lane clip uses a take-lane clip over the stretch where both lie when they play the same thing there, the same data apart from the Start and End markers, the loop brace and the fades, with the same clip envelopes and the same contents at every point. A deactivated main-lane clip uses nothing. `stretches` lists each, and `unused_lanes` the take lanes none of whose material is used, which `take_lane.delete_unused` deletes.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `track` | [`TrackId`](README.md#trackid) | yes | The audio or MIDI track. |

Result: [`CompSourcesResult`](README.md#compsourcesresult).

### `take_lane.copy_to_main_lane`

**Copy Selection to Main Lane**. Permission: `edit`. Contexts: `arrangement`, `take-lanes`.

Copies a take lane's material in `start`..`end` to its track's main lane, at the same place (with `lanes`, `start` and `end` left out, it takes them from the selection: the take lanes the headers, the time selection or the clips selected are on, and the time or the clips' span; Enter runs it so): each of the lane's clips the range reaches, cut at the range's edges as Split cuts, is copied under a new ID onto the main lane, where it replaces what it covers. Where the lane has no clip in the range, the main lane is left as it was. Of several `lanes` on one track, the last listed is copied from; lanes on several tracks each copy to their own track. The copies are independent of the take-lane clips. It is one undo step, an edit, and destructive as well when it replaces or shortens a main-lane clip. A frozen track refuses it.

Default keys:

| Shortcut | macOS | Windows | Context | Action in the reference | Binding |
|---|---|---|---|---|---|
| S-COMP-002 | `Enter` | `Enter` | `take-lanes` | Copy the selected take-lane area to the main lane | runs it |

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `end` | [`Position`](README.md#position) or null | no | Where the range ends, after `start`. Left out, the selection's end. |
| `lanes` | array or null | no | The take lanes to copy from. Of those on one track, the last listed is copied from. Left out, the take lanes the selection is on: the headers selected, the lanes the time selection covers, or the lanes of the selected clips. |
| `linked` | boolean or null | no | Whether it reaches the tracks linked with the ones it names (the linked-track editing spec, R15). `true` if left out. |
| `start` | [`Position`](README.md#position) or null | no | Where the range starts, in ticks or as `bar.beat.sixteenth` text. Left out, the time selection's start, or the selected clips'. |

Result: [`CompResult`](README.md#compresult).

### `take_lane.create_clip`

**Create Clip on Take Lane**. Permission: `edit`. Contexts: `arrangement`.

Puts a new clip on a take lane, at `clip.start` for `clip.length` ticks (705,600 to the quarter note), as `clip.create` puts one on a main lane: an audio clip on an audio track's lane and a MIDI clip on a MIDI track's. `clip.id` must be a new ID the project has issued for it. It does not clear what the lane holds there. The clip is then edited by its ID with the `clip.*` commands, as a main-lane clip is.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `lane` | [`TakeLaneId`](README.md#takelaneid) | yes | The take lane. |
| `clip` | [`Clip`](README.md#clip) | yes | The clip, with a new ID. |

Result: [`ChangeSet`](README.md#changeset).

### `take_lane.delete`

**Delete Take Lane(s)**. Permission: `destructive`. Contexts: `arrangement`.

Deletes take lanes with their clips. The main lane is left as it was, and a deleted lane that was auditioned stops being. Undo restores them, but because it removes the person's work an agent asks first. On a linked track it makes the same edit on every track linked with it, in the same undo step, and the result lists everything it changed; give `linked`: false to edit only what the arguments name.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `lanes` | array of [`TakeLaneId`](README.md#takelaneid) | yes | The take lanes. |
| `linked` | boolean | no | Whether the edit reaches the tracks linked with the ones it names (the same on each); true if left out. Give false to limit it to what it names. |

Result: [`ChangeSet`](README.md#changeset).

Default keys: none.

| Name | Type | Required | Description |
|---|---|---|---|
| `tracks` | array of [`TrackId`](README.md#trackid) | yes | The audio or MIDI tracks. |

Result: [`ChangeSet`](README.md#changeset).

### `take_lane.delete_unused`

The main lane is left as it was. Undo restores them, but because it removes the person's work an agent asks first.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `tracks` | array of [`TrackId`](README.md#trackid) | yes | The audio or MIDI tracks. |

Result: [`ChangeSet`](README.md#changeset).

### `take_lane.insert`

**Insert Take Lane**. Permission: `edit`. Contexts: `arrangement`.

Adds an empty take lane to each of the audio or MIDI `tracks` (left out, the selected tracks): directly after the take lane of that track listed in `after` (left out, the take lanes whose headers are selected), or after its last take lane. Each is named `Take N`, one more than the highest number of a lane of the track named `Take` and a number, `Take 1` on a track with none. All of them are one undo step. The tracks' take lanes show afterwards, and Automation Mode is switched off to show them. The result's `lanes` are the new lanes' IDs.

Default keys:

| Shortcut | macOS | Windows | Context | Action in the reference | Binding |
|---|---|---|---|---|---|
| S-COMP-004 | `Shift+Option+T` | `Shift+Alt+T` | `arrangement` | Add a take lane | runs it |

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `after` | array of [`TakeLaneId`](README.md#takelaneid) | no | Take lanes to add the new ones directly after, for the tracks they belong to. A track with none of them gets its new lane after its last take lane. |
| `linked` | boolean or null | no | Whether it reaches the tracks linked with the ones it names (the linked-track editing spec, R15). `true` if left out. |
| `tracks` | array or null | no | The audio or MIDI tracks to add a take lane to. Left out, the selected tracks. |

Result: [`LanesResult`](README.md#lanesresult).

### `take_lane.move`

**Move Take Lane(s)**. Permission: `edit`. Contexts: `arrangement`.

Moves take lanes, which must all be on one track, to a new place among that track's take lanes, keeping their order: `index` counts from 0, the lane nearest the main lane, among the lanes that are not moved. The main lane stays first.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `lanes` | array of [`TakeLaneId`](README.md#takelaneid) | yes | The take lanes. |
| `index` | integer, at least 0 | yes | The place they take among the track's other take lanes, counted from 0 for the lane nearest the main lane. |

Result: [`ChangeSet`](README.md#changeset).

### `take_lane.move_comp_edge`

**Move Comp Edge**. Permission: `edit`. Contexts: `arrangement`.

Moves the boundary between two adjacent main-lane clips that each play a take-lane clip (`take_lane.comp_sources`) from `from` to `to`: the earlier clip's right edge and the later clip's left edge move together, each playing on what its take-lane clip plays there. The boundary goes no further than the growing clip's take-lane clip reaches, and leaves each clip at least a tick long. It is one undo step.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `track` | [`TrackId`](README.md#trackid) | yes | The audio or MIDI track. |
| `from` | [`Position`](README.md#position) | yes | Where two adjacent main-lane clips meet now. |
| `to` | [`Position`](README.md#position) | yes | Where they should meet. |
| `linked` | boolean or null | no | Whether it reaches the tracks linked with the ones it names (the linked-track editing spec, R15). `true` if left out. |

Result: [`CompResult`](README.md#compresult).

### `take_lane.replace_with_take`

**Replace with Next or Previous Take**. Permission: `edit`. Contexts: `arrangement`.

Replaces a track's main-lane material in `start`..`end` with the next take's (`direction` `next`, the take lane below) or the previous take's (`previous`, the one above). With `track`, `start`, `end` and `lane` left out it takes them from the selection, on each audio or MIDI track the selection is on, as Cmd+Down and Cmd+Up do. The take is placed as `take_lane.copy_to_main_lane` places it, skipping take lanes with no clip in the range. With `lane` given, the selection is on that take lane and the next or previous take is counted from it; left out, the selection is on the main lane, and each main-lane clip's part of the range is counted from the take lane it uses (`take_lane.comp_sources`), a part that uses none from before the first take lane. A part with no take lane left in that direction is left as it was. It is one undo step, an edit, and destructive as well when it replaces or shortens a main-lane clip. A frozen track refuses it.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `direction` | [`TakeDirection`](README.md#takedirection) | yes | Whether to take the next or the previous take. |
| `end` | [`Position`](README.md#position) or null | no | Where the range ends, after `start`. Left out, the selection's end. |
| `lane` | [`TakeLaneId`](README.md#takelaneid) or null | no | The take lane the selection is on, from which the next or previous take is counted. Left out with `track` given, the selection is on the main lane, and each of its clips counts from the take lane it uses; left out with `track`, the selection says. |
| `linked` | boolean or null | no | Whether it reaches the tracks linked with the ones it names (the linked-track editing spec, R15). `true` if left out. |
| `start` | [`Position`](README.md#position) or null | no | Where the range starts, in ticks or as `bar.beat.sixteenth` text. Left out, the time selection's start, or the selected clips'. |
| `track` | [`TrackId`](README.md#trackid) or null | no | The audio or MIDI track whose main lane is changed. Left out, each audio or MIDI track the selection is on. |

Result: [`CompResult`](README.md#compresult).

### `take_lane.set_audition`

**Audition Take Lane**. Permission: `edit`. Contexts: `arrangement`.

Switches the audition of a take lane on or off. While a take lane is auditioned, its track plays that lane's clips in place of its main lane's, from the next block; a track has at most one, so switching one on switches off the one auditioned before. Session clips are unaffected. It is saved with the set. On a linked track it makes the same edit on every track linked with it, in the same undo step, and the result lists everything it changed; give `linked`: false to edit only what the arguments name.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `lane` | [`TakeLaneId`](README.md#takelaneid) | yes | The take lane. |
| `on` | boolean | yes | Whether it is auditioned. |
| `linked` | boolean | no | Whether the edit reaches the tracks linked with the ones it names (the same on each); true if left out. Give false to limit it to what it names. |

Result: [`ChangeSet`](README.md#changeset).
