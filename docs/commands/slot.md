## Commands

### `slot.set_stop_button`

**Add Stop Button**. Permission: `edit`. Contexts: `session`.

Adds or removes a Session slot's Clip Stop button, which the person reaches through Edit ▸ Remove Stop Button (Cmd+E on macOS, Ctrl+E on Windows) and the slot's and Session clip's context menus. The button stops the track's playing clip; the track's own stop button (its status row) and Stop All Clips do the same for one or every track. A slot has one until it's removed, so a set saved before this command loads with one in every slot of every audio and MIDI track. The switch is saved with the set, and undo adds or removes the button again.

Default keys:

| Shortcut | macOS | Windows | Context | Action in the reference | Binding |
|---|---|---|---|---|---|
| S-SES-005 | `Cmd+E` | `Ctrl+E` | `session` | Add or remove a clip stop button | toggles `stop_button` |

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `track` | [`TrackId`](README.md#trackid) | yes | The track whose slot it is. |
| `scene` | [`SceneId`](README.md#sceneid) | yes | The scene whose slot it is. |
| `stop_button` | boolean | yes | Whether the slot keeps its Clip Stop button: `true` adds it, and `false` removes it. |

Result: [`ChangeSet`](README.md#changeset).
