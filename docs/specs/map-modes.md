## The behaviour

The Control Bar's MIDI switch, or Cmd-M, turns MIDI Map Mode on: every control that can be mapped to MIDI takes a blue overlay, and the Mapping Browser takes the browser's place, listing every MIDI mapping in the set. A click on a tinted control selects it, and the next note or controller that arrives on the remote input maps to it; a controller's mode, absolute or one of the relative encodings, is guessed from the messages and shown in the Status Bar's chooser, where it can be changed. The Key switch, or Cmd-K, does the same for the computer keyboard, with red overlays, the next key pressed mapping to the selected control. In the Mapping Browser each mapping's Min and Max can be edited, Invert Range swaps them, and Delete removes a mapping. Turning the switch off leaves the mode, puts the browser back, and lets the mappings act.

Nearly every control in the window can be mapped: Session slots and scene launch buttons, stop buttons, mixer controls, device parameters and macros, the Clip View's controls, the Control Bar's transport and recording controls, the crossfader. A few controls exist only for mapping and show only in the map modes: a strip below the Session grid that moves the highlighted scene and launches from it, the New button beside Session Record, the step buttons of step recording, and a scrub control between the clip's nudge buttons.

This spec covers the map modes in the window and the list of what can be mapped. What a mapping holds and what a message does to each kind of control are [remote mapping](remote-mapping.md)'s.

## Rules

### The map modes (WP-7.3)

- **R1.** The Control Bar's MIDI switch (L-CTRL-022), Cmd-M (Ctrl-M on Windows and Linux; S-MAP-001) and Options ▸ Edit MIDI Map (M-OPT-002, ticked while on) turn MIDI Map Mode on and off; the Key switch (L-CTRL-021), Cmd-K (Ctrl-K; S-MAP-002) and Options ▸ Edit Key Map (M-OPT-003) turn Key Map Mode on and off. Each switch is lit while its mode is on. (S2, S3, S11, S13)
- **R2.** One map mode is on at a time: turning one on turns the other off, and turns off any rack's Map mode ([macros](macros.md) R3), as turning a rack's Map mode on turns them off. A map mode is view state: it isn't saved with the set, isn't an undo step, and is off when a set opens. `remote.map_mode` (`read`) sets it to MIDI, Key or off. (S1, S2, S3; one at a time is Beatlayer's own)
- **R3.** While a map mode is on, every control mappable in it (R11 to R13) is drawn under an overlay, tinted with the theme's MIDI mapping colour in MIDI Map Mode and its key mapping colour in Key Map Mode (a blue and a red, Beatlayer's own shades), and a control with a mapping of that mode shows its source on its overlay: a note's name with its channel, a controller's channel and number, or a key's name. The controls that show only in the map modes (R14, R19, R20, R21, R22) show while either is on. A control that isn't mappable in the mode keeps its look and does nothing when clicked. (S2, S3, S13; the labels are Beatlayer's own)
- **R4.** A click on a tinted control selects it, outlined, instead of operating it; another click selects another, and Esc clears the selection. The selection is view state, and `remote.select` (`read`) selects a control by its ID (R24). While a map mode is on no mapping acts ([remote mapping](remote-mapping.md) R13). (S2, S3; Esc is Beatlayer's own)
- **R5.** In MIDI Map Mode, with a control selected, the next note-on, control change or pitch bend on the remote input maps to it ([remote mapping](remote-mapping.md) R1, R5), and the mapping shows at once in the Mapping Browser and on the overlay. A control change's mode is guessed from it and the messages after it ([remote mapping](remote-mapping.md) R27), and each new message may change the guess. The control stays selected: a message from another source maps that source instead. A note-on held while a second key goes down on the same channel maps the range of keys between them, on a continuous control or a radio button. Note-offs map nothing. While no input has its Remote switch on, the Status Bar says so when a control is selected. (S2, S6; the two-key range on a parameter, and the message, are Beatlayer's own)
- **R6.** On a slot, a key that goes down first is the root; while it is held, a key below it and a key above it, in either order, make a note range from the lower to the higher with that root ([remote mapping](remote-mapping.md) R33). A root released before both have gone down maps the single note. (S6)
- **R7.** In Key Map Mode, with a control selected, the next key pressed without Cmd, Ctrl or Option (Alt) maps to it, whether or not the computer MIDI keyboard is on; Esc clears the selection and maps nothing, and Delete and Backspace remove the selected control's key mapping. Keys pressed with a modifier run their shortcuts as usual, so Cmd-K leaves the mode. (S3; the reserved keys are Beatlayer's own)
- **R8.** While a map mode is on, the Mapping Browser takes the browser's place (L-OTH-007), showing every mapping of that mode, MIDI mappings in MIDI Map Mode and key mappings in Key Map Mode. While the browser is hidden the Mapping Browser is too, and Cmd-Option-B (S-VIEW-010) shows it. Each row shows, in this order, the source (a MIDI mapping's channel and its note, note range or controller, or a key's name), the path to the control (its track and device, or its view), the control's name, Min and Max; rows are in order of their source, MIDI by channel then note or controller, keys by name. Leaving the mode puts the browser back as it was. (S1, S2, S3, S13; the order of rows is Beatlayer's own)
- **R9.** In the Mapping Browser, Min and Max are number boxes in the control's own units ([remote mapping](remote-mapping.md) R4), within its range, taking the edits a number box takes, each change one undo step (`remote.set_range`); Min above Max is allowed. A row's context menu has Invert Range, which swaps them (`remote.invert_range`). Delete or Backspace deletes the selected rows, one undo step (`remote.unmap`). Clicking a row selects it and selects its control, scrolling it into view where it shows. (S1; selecting the control is Beatlayer's own)
- **R10.** In MIDI Map Mode, while the selected control or the selected row has a control-change mapping, the Status Bar shows its mode chooser at the right of the message area (L-STAT-002), listing Absolute, Absolute (14-bit) for a 14-bit pair, and the relative modes: Signed Bit, Signed Bit 2, Bin Offset and Twos Complement, each as accelerated and as Linear, a 14-bit pair offering only Absolute (14-bit); choosing one runs `remote.set_mode`, one undo step. After a learn the chooser shows the guess, and the message area says it is a guess. The switches are toggle buttons in the accessibility tree, each overlay adds its mapping to its control's description, and the Mapping Browser is a table with its column headers ([accessibility](accessibility.md) R1). `remote.state` reports the map mode, the selected control, the guess and the Mapping Browser's rows. (S4, S14; the names of the modes and the wording are Beatlayer's own)

### What can be mapped (WP-7.3b)

- **R11.** In MIDI Map Mode these controls are mappable, with the kind each takes ([remote mapping](remote-mapping.md) R3): in the Session View, every audio and MIDI track's clip slots (slot), each scene's launch button, each track's stop button and Stop All Clips (button); in the mixer, wherever it shows, each track's volume, pan (and split pan's two knobs), sends, Main's volume, pan and cue volume, and the crossfader (continuous), each track's activator (ranged switch), Solo and Arm (switch), and Monitor and its crossfade assignment, A, off or B (radio button); in the Device View, every device's parameters by their kinds (a toggle parameter a ranged switch, a choice a radio button), each device's on/off switch (ranged switch), a rack's macros, its chain selector and its chains' mixer controls; in the Clip View, the controls of the panels it shows by their kinds, and the nudge buttons (button, acting on press; [launch quantisation](launch-quantisation.md) R30); in the Control Bar, Tap Tempo, Phase Nudge Down and Up, Play, Stop, Re-Enable Automation, Capture MIDI and New (button), the Tempo field (continuous), the Metronome, Follow, Arrangement Record, MIDI Arrangement Overdub, Automation Arm, Session Record, Punch-In, the Arrangement Loop switch, Punch-Out and Draw Mode (switch), and the Quantization Menu (radio button); and the controls of R14 and R19 to R23. (S1, S4, S8, S9, S10, S12; the full list is Beatlayer's own reading of "most of the controls")
- **R12.** In Key Map Mode every control of R11 is mappable except the continuous controls, which keep their look; the crossfader's three positions (R19) are mappable. (S3, S6, S7)
- **R13.** The map mode switches, the Computer MIDI Keyboard switch, menus, text fields, the browser and the Settings window aren't mappable. A mapping to a control in the mixer is the same mapping wherever the control shows, the Session mixer, the Arrangement's track headers or its mixer. (Beatlayer's own)
- **R14.** In both map modes the relative Session mapping strip shows below the Session grid, above the track status row (L-SES-008): in each audio and MIDI track's column a Launch button, and in the Main column Scene Up and Scene Down buttons, the scene number box, Launch Scene and Cancel Launch. The strip is one slot row tall and takes its height from the slot area while it shows. (S4; its place and height are Beatlayer's own)
- **R15.** Scene Up and Scene Down highlight the scene before or after the highlighted one, stopping at the first and the last; the scene number box highlights the scene of its number, 1 to the scene count, a relative controller stepping it one scene a step; Launch Scene launches the highlighted scene as its own launch button does, Select Next Scene on Launch then moving the highlight on ([launch quantisation](launch-quantisation.md) R16); Cancel Launch drops a scene launch that is queued and hasn't started, leaving the clips already playing; a track's Launch button presses the slot at the highlighted scene in that track, as a mapped slot does ([remote mapping](remote-mapping.md) R15). The highlighted scene is the selected scene ([session view](session-view.md) R17); with none selected, Scene Down and Scene Up highlight the first. The commands are `session.highlight_scene` (`read`, a step or a number), `session.launch_highlighted_scene`, `session.cancel_scene_launch` and `session.launch_highlighted` (`read`, as launches are). (S4, S14; with none selected, Beatlayer's own)
- **R16.** While the highlighted scene changes by the strip or by a mapping, the grid scrolls so that it sits at the vertical centre of the slot area, as far as the scenes reach. (S4; scrolling only for remote changes is Beatlayer's own reading)
- **R17.** A mapped Clip View control acts on the clips the Clip View shows when the message arrives, as the control itself does on several clips, and does nothing while the Clip View shows none. (S5)
- **R18.** A mapped slot belongs to its slot: a clip moved or copied into another slot leaves its mapping behind, and a slot that becomes empty keeps its mapping. (S6)
- **R19.** In both map modes the Crossfader section shows three mapping fields over the crossfader, at its left end, its centre and its right end, each a button. When only one of the three has a mapping, each press of it moves the crossfader to its left end, or to its right end when it is at the left end already; when two or more have mappings, a press moves the crossfader to that field's position, and a release while another mapped field is held moves it back to the held field's position. (S7; the fields' place and the reading of "toggle" are Beatlayer's own)
- **R20.** In both map modes the Control Bar shows the New button just before Session Record (L-CTRL-015). Pressed, by a mapping or a click, it stops the clips of every armed track, as their stop buttons do, and highlights the first scene after the highlighted one whose armed tracks' slots are all empty, inserting a scene after the last when there is none (`session.new_take`, `edit`, one undo step when it inserts a scene). (S8; which scene it takes is Beatlayer's own reading)
- **R21.** In both map modes the MIDI Note Editor shows two step buttons, Step Back and Step Forward, just before the grid chooser in its toolbar (L-CLIP-010). Pressed, by a mapping or a click, they step as Left and Right do while step recording ([step recording](step-recording.md) R4 to R6), running `note.step_record` with the notes held on the track's input. (S8, S12; their place is Beatlayer's own reading of "beside the grid's options")
- **R22.** In MIDI Map Mode a scrub control shows between the Launch Properties panel's nudge buttons, a continuous control for a relative controller: each increment or decrement nudges the playing clip as [launch quantisation](launch-quantisation.md) R35 says. (S9)
- **R23.** Each MIDI Tool's parameters, its Auto switch, its apply button (Transform or Generate) and its Reset button are mappable, by their kinds, named by the tool and the parameter so a mapping holds whichever track's clip shows. A mapped change to a parameter acts as a drag of its control: with Auto on it applies the tool ([MIDI Tools](midi-tools.md) R17), and with a chain open it changes the tool's step and runs the chain again from it ([MIDI Tools](midi-tools.md) R28). (S12, S14)
- **R24.** `remote.targets` (`read`) lists every mappable control the set has, in MIDI Map Mode's list or Key Map Mode's, with its ID, its kind, its path and name and its range, so an agent maps controls by `remote.map` without the window; the IDs are the ones `remote.mappings` reports. (S15)
