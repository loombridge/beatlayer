## Commands

### `packages.install`

**Download Packages**. Permission: `external`. Contexts: `global`.

Downloads and installs packages by ID (`packages.list` gives them), one at a time on a thread of its own, each checked against the size and SHA-256 Beatlayer expects before it's installed. Returns at once; `packages.list` reports the progress. A package that's installed, or already downloading or waiting, isn't downloaded again. Changes nothing in the set.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `ids` | array of string | yes | The packages' IDs, as `packages.list` gives them. |

Result: [`PackagesStatus`](README.md#packagesstatus).

### `packages.list`

**Packages**. Permission: `read`. Contexts: `global`.

Reads each package of Beatlayer's manifest for this platform (the on-device models and runtimes its features download on first use): its ID, name, version, project page, what it does, download size and role, whether it's installed, queued, downloading (with its share) or removed at the next launch, and the features that need it; and the folder they install in.

Default keys: none.

Arguments: none (send `{}`).

Result: [`PackagesStatus`](README.md#packagesstatus).

### `packages.remove`

**Remove Packages**. Permission: `destructive`. Contexts: `global`.

Removes installed packages by ID: their files and record. A package whose library is loaded is removed the next time Beatlayer starts and shows as `removed_at_next_launch` until then. A feature that needs a removed package asks for it again the next time it runs. Changes nothing in the set.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `ids` | array of string | yes | The packages' IDs, as `packages.list` gives them. |

Result: [`PackagesStatus`](README.md#packagesstatus).
