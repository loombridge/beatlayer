### `clip.close_slice_dialog`

Closes the Slice to New MIDI Track dialog. Changes nothing in the set.

Arguments: none (send `{}`).

Result: [`SliceDialogStatus`](README.md#slicedialogstatus).

### `clip.create`

**Create Clip**. Permission: `edit`. Contexts: `arrangement`.

Puts a new clip on an audio or MIDI track's arrangement lane, at `clip.start` for `clip.length` ticks (705,600 to the quarter note). An audio clip names its audio file by content hash and plays it unwarped, at the file's own speed, from the moment the song reaches the clip; its optional settings (Start and End markers, loop, gain, fades) default to playing the whole file once at 0 dB with no fades. A MIDI clip carries its notes, placed from the clip's start. Audio clips go only on audio tracks and MIDI clips only on MIDI tracks. `clip.id` must be a new ID the project has issued for it.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `track` | [`TrackId`](README.md#trackid) | yes | The track. |
| `clip` | [`Clip`](README.md#clip) | yes | The clip, with a new ID. |

Result: [`ChangeSet`](README.md#changeset).

### `clip.create_in_slot`

**Create Clip in Slot**. Permission: `edit`. Contexts: `session`.

Puts a clip in a track's Session slot at `scene`, as Insert Empty MIDI Clip (Cmd+Shift+M) and dropping a clip in a slot do. Only audio and MIDI tracks hold slot clips, the slot must be empty, and the clip's data must match the track. A slot clip is a clip like an Arrangement clip, but it has no position there, so its `start` must be 0. `clip.id` must be a new ID the project has issued for it.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `track` | [`TrackId`](README.md#trackid) | yes | The track. |
| `scene` | [`SceneId`](README.md#sceneid) | yes | The scene whose slot it goes in. |
| `clip` | [`Clip`](README.md#clip) | yes | The clip, with a new ID. |

Result: [`ChangeSet`](README.md#changeset).

### `clip.crop`

**Crop Clip**. Permission: `edit`. Contexts: `arrangement`, `session`, `clip-view`.

Crops a clip to the part of it that plays, or to a span of song time: an audio clip's region is written as a new, shorter file and the clip plays it, with its Start and End markers, loop brace, and warp markers moved back so it plays exactly what it played before; a MIDI clip loses the notes that start outside the region, and writes no file. `clip` names the clip (left out, the selected one); `start` and `end` give the span to keep as song positions (left out, the region the clip's own markers hold). A span the clip goes round its loop over isn't one stretch of its file, and is refused, with a message naming Consolidate, which writes such a stretch out. An audio clip's new file goes through the processed-file writer, and the edit is one undo step when it is whole. It's an edit, and destructive as well when it removes anything: audio outside the region, or notes.

Default keys:

| Shortcut | macOS | Windows | Context | Action in the reference | Binding |
|---|---|---|---|---|---|
| S-ARR-003 | `Cmd+Shift+J` | `Ctrl+Shift+J` | `arrangement` | Crop the selected clips | runs it |
| S-SES-028 | `Cmd+Shift+J` | `Ctrl+Shift+J` | `session` | Crop the selected clip | runs it |

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `clip` | [`ClipId`](README.md#clipid) or null | no | The clip to crop. Left out, the one clip the Arrangement or the Session View has selected. |
| `end` | [`Position`](README.md#position) or null | no | Where it ends, after `start`. |
| `start` | [`Position`](README.md#position) or null | no | Where the part to keep starts in the song. Give `start` and `end` together, or neither to keep the region the clip's own Start and End markers or loop brace hold. |

Result: [`CropResult`](README.md#cropresult).

### `clip.crop_region`

**Crop Clip to Region**. Permission: `edit`. Contexts: `clip-view`.

Crops a clip to a region of its contents: an audio clip plays the file `media` names, whose frames are the region of its old file's audio, and a MIDI clip loses the notes that start outside the region, writing no file. The clip's Start and End markers, loop brace, and warp markers move back by the region's start, so it plays exactly what it played, and the clip stays where it is in the Arrangement. `from` and `to` are in the form the clip shows: seconds into an unwarped audio clip's file, or whole ticks of a warped audio clip's or a MIDI clip's contents. `clip.crop` is the command a person and an agent run: it works the region out, writes the new file through the processed-file writer, and applies this one. Used directly, it changes the clip and names a file the caller has already written.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `clip` | [`ClipId`](README.md#clipid) | yes | The clip. |
| `from` | number | yes | Where the region starts, in the form the clip shows: seconds into an unwarped audio clip's file, or whole ticks of a warped audio clip's or a MIDI clip's contents. |
| `to` | number | yes | Where it ends, after `from`, in the same form. |
| `media` | [`ContentHash`](README.md#contenthash) or null | no | The new file: the region's frames, written through the processed-file writer. `null` (or nothing) for a MIDI clip, which writes no file; an audio clip's crop must name one. |

Result: [`ChangeSet`](README.md#changeset).

**Crop Clip to Span**. Permission: `edit`. Contexts: `clip-view`.

Crops a clip to a span of song time: its edges move to the span, and it plays the part of itself the span covered, at the same moments. An audio clip plays the file `media` names, whose frames are the span's part of its old file's audio; a MIDI clip loses the notes the span didn't hold, writing no file. `clip.crop` is the command a person and an agent run: it works the span out, writes the new file through the processed-file writer, and applies this one.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `clip` | [`ClipId`](README.md#clipid) | yes | The clip. |
| `start` | [`Ticks`](README.md#ticks) | yes | Where the span starts in the song. |
| `end` | [`Ticks`](README.md#ticks) | yes | Where it ends, after `start`. |
| `media` | [`ContentHash`](README.md#contenthash) or null | no | The new file: the span's frames. `null` (or nothing) for a MIDI clip, which writes no file. |

Result: [`ChangeSet`](README.md#changeset).

### `clip.insert_warp_marker`

**Insert Warp Marker**. Permission: `edit`. Contexts: `clip-view`, `sample-editor`.

Adds a warp marker to each of the warped audio clips `clips`, which must hold files of the same length: at a `beat` of the clip's contents (ticks from its 1.1.1, negative before it), at the time in the file the map already places there, or at a `time` in the file (seconds), on the beat the map already places it. Give one of the two. Nothing moves; the audio either side stays where it is. Inserting where a marker is already changes nothing. Markers are named by their place in the map (`data.audio.warp_markers`), the first being 0. The edit is made to every clip in one undo step, or to none if it's refused for one. With `pin_neighbours` (Cmd or Ctrl held on a pseudo-warp marker) it also puts markers at the transients just before and just after the new one, read from the clip's transients (`clip.transients`) unless `transients` lists them; it works on one clip.

Default keys:

| Shortcut | macOS | Windows | Context | Action in the reference | Binding |
|---|---|---|---|---|---|
| S-SAMPLE-009 | `Cmd+I` | `Ctrl+I` | `sample-editor` | Insert a warp marker | runs it |

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `clips` | array of [`ClipId`](README.md#clipid) | yes | The warped audio clips: their files must be as long as each other's. |
| `beat` | [`Ticks`](README.md#ticks) or null | no | The beat, in ticks from the clip's 1.1.1, to put the marker on, at the time in the file the map already places there. Give this or `time`. |
| `pin_neighbours` | boolean | no | Also put markers at the transients either side of the new one (WP-4.3): Cmd (Ctrl) held on a pseudo-warp marker. Needs one clip. |
| `time` | number or null | no | The time in the file, in seconds, to put the marker at, on the beat the map already places it. Give this or `beat`. |
| `transients` | array or null | no | The clip's transients, as times in the file, that `pin_neighbours` looks among. Left out, the app uses the clip's current ones. |

Result: [`ChangeSet`](README.md#changeset).

### `clip.insert_warp_markers`

**Insert Warp Markers**. Permission: `edit`. Contexts: `clip-view`, `sample-editor`.

Puts warp markers in a range of a warped audio clip's contents, `from` to `to` (ticks from the clip's 1.1.1): at every transient of the clip in the range, or, when it holds none, at its start and its end. The transients are the clip's own (`clip.transients`) unless `transients` lists times in the file. Each marker sits on the beat the map already places its time, so nothing moves; a marker already there is left. Refused for a clip that isn't warped, or while the file's analysis is not ready and `transients` is left out. One undo step.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `clip` | [`ClipId`](README.md#clipid) | yes | The warped audio clip. |
| `from` | [`Ticks`](README.md#ticks) | yes | The start of the range, in ticks from the clip's 1.1.1. |
| `to` | [`Ticks`](README.md#ticks) | yes | The end of the range, in ticks, after `from`. |
| `transients` | array or null | no | The clip's transients, as times in the file, that the range is searched for. Left out, the app uses the clip's current ones. |

Result: [`ChangeSet`](README.md#changeset).

### `clip.set_fades`

**Set Clip Fades**. Permission: `edit`. Contexts: `arrangement`.

Sets the lengths, in seconds, of an audio clip's fade-in, from silence at the clip's start in the arrangement, and its fade-out, to silence at its end; 0 is no fade. `fade_in_curve` and `fade_out_curve`, from -1 to 1, shape each: 0, the default, is a straight line in amplitude, a positive curve bows the fade towards full level and a negative one towards silence; left out, a curve stays as it is. Short fades stop a clip that starts or ends mid-waveform from clicking: 0.004 (4 ms) is the length that Create Fades on Clip Edges gives new clips. Lengths must be finite, at least 0 and within the clip's limits: a fade-in ends no later than the fade-out begins, and a fade takes in no point where the clip goes round its loop brace. Where a crossfade begins or ends at the clip, this sets the crossfade's part inside the clip and its curve, and the clip it meets follows; if it can't (its file doesn't reach back that far), the crossfade ends and each clip keeps its own fade. Read the result back with the query tool's `clip` field `data` and the clip's `fade_in_before` and `fade_out_after`.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `clip` | [`ClipId`](README.md#clipid) | yes | The audio clip. |
| `fade_in` | number, at least 0 | yes | The fade-in's length in seconds from the clip's start: 0 for none. Where a crossfade begins at the clip's start, this is how far past the start it runs. |
| `fade_out` | number, at least 0 | yes | The fade-out's length in seconds up to the clip's end: 0 for none. Where a crossfade ends at the clip's end, this is how far before the end it begins. |

**Slice to New MIDI Track**. Permission: `edit`. Contexts: `global`, `arrangement`, `session`, `clip-view`.

Cuts an audio clip into slices on a new MIDI track. The clip is sliced over its region: from its Start marker to its End marker, or, with the loop on, from the earlier of its Start marker and its loop's start to the loop's end. `by` is a beat division (`eight_bars`, `four_bars`, `two_bars`, `one_bar`, `half`, `quarter`, `eighth`, `sixteenth` — the default — or `thirty_second`), `transients` (one slice at each of the clip's transients in the region), or `warp_markers` (one at each of its warp markers; refused for an unwarped clip). With `preserve_warped_timing` on (the default) the slices are cut from the clip's warped audio, so each sounds as it did and its note falls where it played; off, they are cut from the clip's own file, unwarped. `preset` names a slicing preset: Beatlayer's factory presets (the default makes a Drum Rack of one sampler per slice, each chain receiving a note from C1 up and playing C3; `One Sampler` makes one sampler in Slice mode) or a user preset in the User Library's Defaults/Slicing folder. The new MIDI track goes directly after the clip's track, takes the clip's name, and holds a MIDI clip with one note per slice, rising chromatically, each lasting to the next, at velocity 127. More than 128 slices are refused (64 for `One Sampler`). Slicing leaves the audio clip as it was and is one undo step.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `by` | [`SliceBy`](README.md#sliceby) or null | no | How to cut it: a beat division, `transients`, or `warp_markers`. Left out, `sixteenth` (R2). |
| `clip` | [`ClipId`](README.md#clipid) or null | no | The audio clip to slice. Left out, the one audio clip selected in either view. |
| `preserve_warped_timing` | boolean or null | no | Whether the slices are cut from the clip's warped audio, keeping the timing warping gave them. Left out, `true` (R2, R6). |
| `preset` | string or null | no | The slicing preset's name: one of Beatlayer's factory presets or a user preset in the User Library's `Defaults/Slicing/` folder (R11). Left out, the default preset. |

Result: [`SliceResult`](README.md#sliceresult).

### `clip.slide_contents`

**Slide Clip Contents**. Permission: `edit`. Contexts: `arrangement`.

Slides a warped audio clip's contents inside the clip, which stays where it is and keeps its length: `by` is how far the contents move in ticks, positive later. Its Start marker, its End marker and its loop brace move the other way through its contents by that much, so the same audio - its warp markers included - plays `by` ticks later (or earlier). Shift+Option-dragging a clip's contents in the Arrangement runs it, snapping to the grid unless Cmd is held as well. Refused for a clip that isn't warped, and for a slide that would take a marker out of the file. One undo step.

Default keys:

| Shortcut | macOS | Windows | Context | Action in the reference | Binding |
|---|---|---|---|---|---|
| S-ARR-005 | `Shift+Option+drag` | `Shift+Alt+drag` | `arrangement` | Slide a clip's contents inside the clip | runs it |

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `clip` | [`ClipId`](README.md#clipid) | yes | The audio or MIDI clip. |
| `by` | [`Ticks`](README.md#ticks) | yes | How far the contents move, in ticks: negative moves them earlier. |

Result: [`ChangeSet`](README.md#changeset).

### `clip.stretch`

**Stretch Clip**. Permission: `edit`. Contexts: `arrangement`.

Stretches a warped audio clip so its dragged `edge` (left or right) lands on the tick `at`, the other edge staying put. Its length becomes the dragged one and every beat in its contents - its warp markers, its Start and End markers and its loop brace - scales by the new length over the old about the beat at the fixed edge, so the same audio fills the new length and its tempo changes with it. Shift-dragging a warped clip's title-bar edge in the Arrangement runs it; Shift-dragging an unwarped clip's edge resizes it as a plain drag does. One undo step.

Default keys:

| Shortcut | macOS | Windows | Context | Action in the reference | Binding |
|---|---|---|---|---|---|
| S-ARR-006 | `Shift+drag the clip title bar` | `Shift+drag the clip title bar` | `arrangement` | Stretch a warped clip | runs it |

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `clip` | [`ClipId`](README.md#clipid) | yes | The warped audio clip. |
| `edge` | [`ClipEdge`](README.md#clipedge) | yes | The edge being dragged. |
| `at` | [`Ticks`](README.md#ticks) | yes | Where that edge goes, in ticks: 0 (1.1.1) or later, and past the other edge. |

Result: [`ChangeSet`](README.md#changeset).

### `clip.transients`

**Clip Transients**. Permission: `read`. Contexts: `clip-view`.

Lists an audio clip's transients: where its file starts notes and hits, found once in the background and kept by the file's content hash, with the clip's own edits applied (`clip.insert_transient`, `clip.delete_transients`, `clip.move_transient`, `clip.reset_transients`). Each has its `time` in the file in seconds, its `beat` in ticks from the clip's 1.1.1 when the clip is warped, and whether it was put in `by_hand`. `analysis_ready` says whether the file's analysis is done; until it is, only the transients put in by hand are listed, and asking starts the analysis. Changes nothing.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `clip` | [`ClipId`](README.md#clipid) | yes | The audio clip. |

Result: [`ClipTransients`](#cliptransients).

### `clip.trim_start`

**Trim Clip Start**. Permission: `edit`. Contexts: `arrangement`.

Moves a clip's left edge to `start`, keeping its end and keeping its contents where they play, as dragging the clip's left edge does: a later `start` hides the beginning of the clip, an earlier one shows more of it. An audio clip's Start marker moves by the time the edge moved (seconds under the tempo map), as Live's does, so it can't go before the start of the file; a MIDI clip's offset moves by as many ticks and stays at 0 or more. The clip can't start before 0, or at or after its end. To move a clip with its contents, use `clip.move`; to change where it ends, use `clip.set_length`.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `clip` | [`ClipId`](README.md#clipid) | yes | The clip. |
| `start` | [`Ticks`](README.md#ticks) | yes | Where its left edge goes, before its end. |

Result: [`ChangeSet`](README.md#changeset).

### `clip.warp_as_loop`

**Warp as Loop**. Permission: `edit`. Contexts: `clip-view`.

Warps a warped audio clip's whole file as a loop of 1, 2, 4, 8, 16 or 32 bars of 4/4, the number whose tempo is nearest the set's tempo at the clip's start: a warp marker at the start of the file on 1.1.1 and one at its end on the last bar's end, the Start and End markers and the loop brace on the whole file, the loop on, and that tempo as the clip's. The clip keeps its place and length in the arrangement. Refused for a clip that isn't warped, or while the file's analysis is not ready. One undo step.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `clip` | [`ClipId`](README.md#clipid) | yes | The warped audio clip. |
| `analysis` | [`FileBeats`](README.md#filebeats) or null | no | The file's length. Left out, the app reads it from the file, and refuses while the file's analysis is not ready. |

Result: [`ChangeSet`](README.md#changeset).

### `clip.warp_from_here`

**Warp From Here**. Permission: `edit`. Contexts: `clip-view`.

Warps a warped audio clip from a point on: at the selected warp marker (`marker`) or at a new one at the insert marker (`beat` or `time`, as for `clip.set_1_1_1_here`). The markers before it stay and those after it are replaced. `method` is `auto`, a marker on the first beat of every bar after the point from the tempo found there; `start_at`, the same starting from the tempo `bpm`, the set's tempo at the point unless given, which settles whether a beat is counted at double or half the speed; `straight`, which deletes the markers after the point and sets the clip's tempo to the tempo found after it; or `bpm`, which deletes them and sets the clip's tempo to `bpm`, the set's tempo at the point unless given. The file's tempo and beats come from its analysis (`analysis` gives them), so every method but `bpm` is refused while it is not ready. Refused for a clip that isn't warped. One undo step.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `clip` | [`ClipId`](README.md#clipid) | yes | The warped audio clip. |
| `method` | [`WarpFrom`](README.md#warpfrom) | yes | How the audio after the point is warped. |
| `analysis` | [`FileBeats`](README.md#filebeats) or null | no | The file's tempo and beats. Left out, the app uses the file's analysis, and refuses while it is not ready. |
| `beat` | [`Ticks`](README.md#ticks) or null | no | The Sample Editor's insert marker as a beat, in ticks from the clip's 1.1.1: a warp marker is made there, at the time the map already places it. |
| `bpm` | number or null | no | The tempo for `start_at` and `bpm`: the set's tempo at the point unless given. |
| `marker` | integer or null | no | The selected warp marker, by its place in the map, the first being 0. |
| `time` | number or null | no | The insert marker as a time in the file, in seconds: a warp marker is made there, on the beat the map already places it. |

Result: [`ChangeSet`](README.md#changeset).

### `clip.warp_selection_as_loop`

**Warp Selection as Loop**. Permission: `edit`. Contexts: `clip-view`.

Warps the part of a warped audio clip's file from `from` to `to` (seconds in the file) as a loop of 1, 2, 4, 8, 16 or 32 bars of 4/4, the number whose tempo is nearest the set's tempo at the clip's start: a warp marker at each end of the part, the Start and End markers and the loop brace on it, the loop on. The clip keeps its place and length in the arrangement. Refused for a clip that isn't warped. One undo step.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `clip` | [`ClipId`](README.md#clipid) | yes | The warped audio clip. |
| `from` | number, at least 0 | yes | The start of the part, in seconds in the file. |
| `to` | number, at least 0 | yes | The end of the part, in seconds, after `from`. |

Result: [`ChangeSet`](README.md#changeset).
