## Commands

### `arranger.add_section`

**Create Section**. Permission: `edit`. Contexts: `arrangement`.

Makes a section from `start` to `end`, or over the time selection, as dragging across the arranger track and Create Section do. The span is cut short where it would reach another section, and one that starts inside a section is refused. It is named `name`, or "Section" and the next whole number, and takes `colour`, or the palette's next swatch. The new section becomes the selected one. It moves nothing on the tracks. One undo step, `Add Section`.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `colour` | integer or null | no | Its colour, a swatch from 0 to 69. Left out, the palette's next. |
| `end` | [`Position`](README.md#position) or null | no | Where it ends, after `start`. Left out, the time selection's end. |
| `name` | string or null | no | Its name. Left out, "Section" and the next whole number. |
| `start` | [`Position`](README.md#position) or null | no | Where the section starts. Left out, the time selection's start. |

Result: [`ArrangerResult`](README.md#arrangerresult).

### `arranger.copy_section`

**Copy Section**. Permission: `edit`. Contexts: `arrangement`.

Puts a copy of a section (`section`, or the selected one) and everything inside its span at `to`, as Copy Time and Paste Time would, opening time there and leaving the original where it is. The time clipboard is left as it was. One undo step, `Copy Section`.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `to` | [`Position`](README.md#position) | yes | Where the copy goes: the position its start lands at. |
| `section` | [`SectionId`](README.md#sectionid) or null | no | The section. Left out, the first selected one. |

Result: [`ArrangerResult`](README.md#arrangerresult).

### `arranger.delete_section`

**Delete Section**. Permission: `destructive`. Contexts: `arrangement`.

Deletes a section (`section`, or the selected one) and everything inside its span from every track, closing the song up as Delete Time does, as the Delete key on a selected section does. Undo restores it, but because it removes the person's work an agent asks first. One undo step, `Delete Section`.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `section` | [`SectionId`](README.md#sectionid) or null | no | The section. Left out, the first selected one. |

Result: [`ArrangerResult`](README.md#arrangerresult).

### `arranger.duplicate_section`

**Duplicate Section**. Permission: `edit`. Contexts: `arrangement`.

Puts a copy of a section (`section`, or the selected one) and everything inside its span straight after it, as Duplicate Time does, the copy taking the same name and colour and becoming the selected section. One undo step, `Duplicate Section`.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `section` | [`SectionId`](README.md#sectionid) or null | no | The section. Left out, the first selected one. |

Result: [`ArrangerResult`](README.md#arrangerresult).

### `arranger.move_section`

**Move Section**. Permission: `edit`. Contexts: `arrangement`.

Moves a section (`section`, or the selected one) and everything inside its span on every track to `to`, as Cut Time and Paste Time at the drop would: the clips (split at the span's edges), every track's automation, the Song Tempo, the time-signature markers, the locators and the section itself, closing the gap it leaves. `to` is a position in the song as it stands before the move; one inside the section's own span changes nothing. With `with` instead of `to`, it swaps places with the section before or after it, as Move Earlier and Move Later do. The time clipboard is left as it was. One undo step, `Move Section`.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `section` | [`SectionId`](README.md#sectionid) or null | no | The section. Left out, the first selected one. |
| `to` | [`Position`](README.md#position) or null | no | Where it goes: the position its start lands at, as the song stands before the move. |
| `with` | [`Neighbour`](README.md#neighbour) or null | no | Instead of `to`, swap it with the section before or after it. |

Result: [`ArrangerResult`](README.md#arrangerresult).

### `arranger.remove_section`

**Remove Section**. Permission: `edit`. Contexts: `arrangement`.

Removes a section (`section`, or the selected one) and leaves the tracks as they are: its clips, automation, tempo, time signatures and locators stay. One undo step, `Remove Section`.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `section` | [`SectionId`](README.md#sectionid) or null | no | The section. Left out, the first selected one. |

Result: [`ArrangerResult`](README.md#arrangerresult).

### `arranger.rename_section`

**Rename Section**. Permission: `edit`. Contexts: `arrangement`.

Renames a section (`section`, or the selected one) to `name`, as Cmd-R (Ctrl-R) and a double-click do; an empty name keeps the old one. Left out, the name is typed in place. One undo step, `Rename Section`.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `name` | string or null | no | The new name. An empty name keeps the old one. Left out, the name is typed in place, as Cmd-R does. |
| `section` | [`SectionId`](README.md#sectionid) or null | no | The section. Left out, the first selected one. |

Result: [`ArrangerResult`](README.md#arrangerresult).

### `arranger.resize_section`

**Resize Section**. Permission: `edit`. Contexts: `arrangement`.

Moves a section's edges (`section`, or the selected one) to `start` and `end`, as dragging an edge does, changing only its span and nothing on the tracks. A span that would overlap another section is refused. One undo step, `Resize Section`.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `end` | [`Position`](README.md#position) or null | no | Where its right edge goes. Left out, the edge stays. |
| `section` | [`SectionId`](README.md#sectionid) or null | no | The section. Left out, the first selected one. |
| `start` | [`Position`](README.md#position) or null | no | Where its left edge goes. Left out, the edge stays. |

Result: [`ArrangerResult`](README.md#arrangerresult).

### `arranger.sections_from_locators`

**Create Sections From Locators**. Permission: `edit`. Contexts: `arrangement`.

Makes a section from each locator to the next, the last to the Arrangement's end, wherever no section is, each named after its locator. A locator inside a section makes none, and a section is cut short where it would reach another. One undo step, `Add Section`.

Default keys: none.

Arguments: none (send `{}`).

Result: [`ArrangerResult`](README.md#arrangerresult).

### `arranger.select_section`

**Select Section**. Permission: `read`. Contexts: `arrangement`.

Selects sections in the arranger track, as clicking one does, and makes their span the time selection on every track, so the …Time commands, Loop Selection and Zoom to Time Selection act on it: `replace` selects only these, `toggle` adds or removes each, `add` adds them, and `extend` selects the sections from the first selected one to the last given. Selecting is never an undo step.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `sections` | array of [`SectionId`](README.md#sectionid) | yes | The sections. |
| `mode` | [`SelectMode`](README.md#selectmode) | no | How to change the selection; `replace` if left out. `extend` selects the sections from the first selected one to the last given. |

Result: [`ArrangementState`](README.md#arrangementstate).

### `arranger.set_section_colour`

**Set Section Colour**. Permission: `edit`. Contexts: `arrangement`.

Sets the colour of a section (`section`, or the selected one) to `colour`, a swatch from 0 to 69. One undo step, `Set Section Colour`.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `colour` | integer from 0 to 255 | yes | The colour, a swatch from 0 to 69. |
| `section` | [`SectionId`](README.md#sectionid) or null | no | The section. Left out, the first selected one. |

Result: [`ArrangerResult`](README.md#arrangerresult).
