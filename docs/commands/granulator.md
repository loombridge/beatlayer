## Commands

### `granulator.capture`

**Capture**. Permission: `edit`. Contexts: `device-view`.

Starts or stops a Granulator III's capture (`action`: `start` or `stop`). A capture writes the audio of the device's sidechain Source into the device, sample for sample from the block it starts in and aligned for latency as the sidechain is, and stops by itself after Capture Length (1 to 30 s). While it fills, the device plays grains from what has been captured so far. When it ends, the captured audio becomes the device's sample as one undo step, Capture Audio, and a worker writes it to a WAV file in the project's Samples/Recorded folder, which the set references as a loaded sample. It is refused with the Source at No Input, the sidechain's External off, a set never saved (it has no project folder), no audio engine running or a capture already running. Read the capture back in the query tool's `device` result, under `capture`.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `action` | [`GranulatorCaptureAction`](README.md#granulatorcaptureaction) | yes | `start` or `stop`. |
| `device` | [`DeviceId`](README.md#deviceid) or null | no | The Granulator III. The one selected in the Device View when it is left out. |

Result: [`GranulatorCaptureResult`](README.md#granulatorcaptureresult).
