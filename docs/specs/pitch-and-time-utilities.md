- **Status:** implemented

- **Parity-matrix row:** MIDI editing: "Pitch and Time Utilities (Fit to Scale, Invert, Transpose, Add Interval, ×2, ÷2, Stretch, Set Length, Humanize, Reverse, Legato)"
- **Checked against:** the Live 12 reference manual (online edition), read 20 October 2026: chapter 8, sections 8.5, 8.5.1 and 8.5.2, and chapter 10, sections 10.5.9 and 10.5.9.1 to 10.5.9.9; the Live 12 release notes, 12.0 and 12.0.5; the UI parity reference's L-CLIP-006

## The behaviour

The Pitch and Time Utilities panel sits in the Clip View's right group of panels, beside the MIDI Tools, and holds quick edits for the selected notes. Its pitch tools transpose them, fit them to the clip's scale, turn them upside down, and add a copy of them at an interval. Its time tools stretch them by a factor, double or halve them, set their lengths, nudge their starts at random, reverse them in time and make them legato. With a clip scale, Transpose and the interval count scale degrees.

The tools act on the selected notes, or on the notes in the time selection; with nothing selected, a button acts on the whole clip, and ×2 and ÷2 then stretch the clip's loop and markers too. Transpose, Interval Size and Stretch act while they're dragged. Each edit is one undo step, and each is a registered command an agent runs.

## Rules

- **R1.** The Pitch and Time Utilities panel (L-CLIP-006), shown by the panel selector's right group ([midi-tools.md](midi-tools.md) R1), holds in this order: a display, then Transpose, Fit to Scale and Invert; Interval Size and Add Interval; Stretch, ×2 and ÷2; Duration and Set Length; Humanize Amount and Humanize; Reverse and Legato. Transpose and Interval Size are number fields, dragged up and down or typed; Stretch is a knob; Humanize Amount a slider; Duration a chooser; the rest buttons ([device-framework.md](device-framework.md) R16, R17). The display shows the clip's scale's root and name while Scale Mode is on, and is empty while it's off (Beatlayer's own). While the pointer is over a control, the Info View shows its registered description ([info-view.md](info-view.md) R4, R6). (S1, S2, S5)
- **R2.** The utilities act on the selected notes; with none selected, on the notes that start in the time selection; with neither, a button acts on every note in the clip, and Transpose, Interval Size and Stretch act on nothing ([midi-tools.md](midi-tools.md) R11's order; the sliders with nothing selected are Beatlayer's own reading). A step of Transpose, Interval Size or Invert is a step of the clip's scale in Scale Mode, a semitone otherwise, and a Drum Rack's key on a Drum Rack track, as [midi-tools.md](midi-tools.md) R8 and R9 say. (S1, S2, S6)
- **R3.** Each utility is one undo step, named Transpose, Fit to Scale, Invert, Interval, Stretch, Stretch Time by Double, Shrink Time by Half, Set Length, Humanize, Reverse or Legato (S7); a drag on Transpose, Interval Size or Stretch is one step however many frames it lasts, and Esc during it puts the notes back ([piano-roll.md](piano-roll.md) R11). A utility that would change nothing records no step. Notes a utility acted on stay selected, Add Interval selects the notes it adds, and the time selection follows the selection ([piano-roll.md](piano-roll.md) R24). (S3, S6, S7)
- **R4.** Transpose shows the target's lowest and highest notes by name, one name when they're the same, or with nothing selected the clip's (Beatlayer's own format). Dragging it, or typing a whole number n and pressing Enter, moves the target by n steps, and the field then shows the new range (`note.transpose`). A transpose that would move a note outside keys 0 to 127 is refused and changes nothing, as [piano-roll.md](piano-roll.md) R20 refuses one. (S1, S2, S6)
- **R5.** Fit to Scale, available only while the clip's Scale Mode is on, moves each target note off the scale to the nearest key of the clip's scale, the lower of two equally near ([scales.md](scales.md) R2); notes on the scale stay (`note.fit_to_scale`). While Scale Mode is off the button is disabled and the command is refused, saying why. (S1, S2)
- **R6.** Invert takes the target's lowest key L and highest H and moves each note at key k to L + H − k. In Scale Mode, when L and H are on the scale, a note on the scale goes instead to the scale note as many degrees below H as it was above L, and a note off the scale still moves to L + H − k (Beatlayer's own law for notes off the scale); when L or H is off the scale, every note moves by semitones (`note.invert`). (S2)
- **R7.** Interval Size is a whole number of steps from −36 to +36 that keeps every copy on the keyboard (the notes it would copy decide how far), 0 in a new Clip View, shown with `sd` for steps of the scale and `st` for semitones (S7). With notes selected, dragging it or typing into it adds, at once, a copy of each target note moved by the interval, and selects the copies; during one drag the copies are of the notes selected when it began, at the value the field shows. With none selected it only sets the interval. Typing a number into it and pressing Enter adds the interval at once, as Add Interval does, and puts the field back to 0 (S7). Add Interval adds a copy of each target note, or of every note in the clip with nothing selected, moved by Interval Size (`note.add_interval`). A copy that would leave keys 0 to 127 is left out, and so, on a Drum Rack track, is one that would land on a key no chain receives. Copies keep their notes' starts, lengths and values. (S1, S2, S4, S7)
- **R8.** Stretch is a knob from ÷10 to ×10 whose middle is ×1, its factor 10 to the power of 2p − 1 at a position p from 0 to 1 along its travel, shown as ×2.00 above 1 and ÷2.00 below (the law and the text are Beatlayer's own). While it is dragged, the target, as it was when the drag began, is stretched by the factor around the time selection's start: each note's distance from it and its length are multiplied by the factor, and the time selection stretches with them (S4). When the drag ends, the knob goes back to ×1 (Beatlayer's own). Typing a factor (`2`, `×2`, `/2` or `÷2`) into the knob and pressing Enter stretches by it, the notes in the time selection or with none every note (S7). Stretch doesn't change the clip's loop or markers (`note.stretch` with `factor`). (S1, S2, S3, S4, S7)
- **R9.** ×2 and ÷2 stretch the target by 2 and by ½ as R8 does, as one step each (Double and Halve). With nothing selected and no time selection, they stretch every note in the clip, its Start and End markers and its loop brace by 2 or ½ around the contents' start, and the clip's own length in the Arrangement stays as it was (`note.stretch` with `markers`; the length is Beatlayer's own). Every note keeps at least a tick. (S1, S2, S3, S7)
- **R10.** Duration offers Fit to Time Range, Grid, 1, 1/2, 1/3, 1/4, 1/6, 1/8, 1/12, 1/16, 1/24, 1/32, 1/48, 1/64, 1/96 and 1/128 (a whole note divided by the number), Grid in a new Clip View (S7). Set Length gives every target note, or every note in the clip with nothing selected, one length: Grid's is the grid step and a division's its own; Time Range ends every note at the time selection's end, and is unavailable without a time selection (Beatlayer's own reading of fitting to the time range). A note that would start at or after that end keeps its length (`note.set_length`). (S1, S2, S3, S7)
- **R11.** Humanize Amount runs from 0 % to 100 %, 10 % in a new Clip View, and typing a number into it and pressing Enter sets it and runs Humanize (S7). Humanize moves each target note, or every note in the clip with nothing selected, by a random amount up to Humanize Amount × a quarter of the grid step, earlier or later, keeping its length; a note never moves before the contents' start. The random amounts come from a seed, as [midi-tools.md](midi-tools.md) R20 says of a tool: `note.humanize` takes one, and the button draws a new one each time. (S1, S2, S7)
- **R12.** Reverse mirrors the target in time around the middle of its span: with a time selection, the time selection; with nothing selected, the clip's loop brace while Loop is on, and its Start marker to its End marker while it's off. A note that starts at s and lasts d in a span from a to b starts at a + b − (s + d) and keeps its length. A reverse that would start a note before the contents' start is refused and changes nothing (`note.reverse`). (S2, S3)
- **R13.** Legato ends each target note at the next later start among the target notes; the notes with the latest start end at the clip's loop brace's end while Loop is on, or at its End marker (the clip's end without one) while it's off, and keep their length when they start at or after it (`note.legato`). (S2)
- **R14.** Interval Size, Stretch's position, Duration and Humanize Amount are the Clip View's view state: no undo step, not saved with the set (Beatlayer's own), and `clip_view.utilities` (`read`) reads and sets them, and reads what the panel shows: the clip's scale, whether Fit to Scale and Duration's Time Range are available, the lowest and highest key Transpose shows, and how far Interval Size can go. (S6)
- **R15.** Every utility is a registered command with a schema, a description and a permission class, run by ID through the agent API with the clip and the notes named as the note commands name them ([piano-roll.md](piano-roll.md) R3), or, left out, the Clip View's: `note.transpose` (`by`, and `in` as `steps` or `semitones`, steps if left out), `note.fit_to_scale`, `note.invert`, `note.add_interval` (`by`, left out for Interval Size, and `in`), `note.stretch` (`factor`, from 0.1 to 10, instead of the stretch markers' `to`; around the time selection's start, or a `point`; with `markers`, also the Start and End markers and the loop when every note is stretched), `note.set_length` (a `length` in ticks, or `to_time_range`), `note.humanize` (`amount`, `seed`), `note.reverse` and `note.legato`, all `edit`, read back in the query tool's `clip` as `data.midi.notes` and, for `note.stretch`, its markers and loop in `data.midi`. Of these only `note.transpose` is refused with no notes selected. The panel's controls run the same commands. (S6)
