## Commands

### `mixer.arm_exclusive`

**Arm Track Exclusively**. Permission: `edit`. Contexts: `track-headers`, `session`, `arrangement`.

Arms one track and disarms every other track, in one undo step, as a click on an Arm switch does while Exclusive Arm is on (Live's default). Only audio and MIDI tracks can be armed. On a linked track it makes the same edit on every track linked with it, in the same undo step, and the result lists everything it changed; give `linked`: false to edit only what the arguments name.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `track` | [`TrackId`](README.md#trackid) | yes | The track. |
| `linked` | boolean | no | Whether the edit reaches the tracks linked with the ones it names (the same on each); true if left out. Give false to limit it to what it names. |

Result: [`ChangeSet`](README.md#changeset).

### `mixer.set_arm`

**Arm Track**. Permission: `edit`. Contexts: `track-headers`, `session`, `arrangement`.

Arms or disarms one track for recording, leaving other tracks' arm switches as they are, so it records its input when recording starts (recording arrives in Phase 2; until then the switch is only saved). Only audio and MIDI tracks can be armed. On a linked track it makes the same edit on every track linked with it, in the same undo step, and the result lists everything it changed; give `linked`: false to edit only what the arguments name.

Default keys:

| Shortcut | macOS | Windows | Context | Action in the reference | Binding |
|---|---|---|---|---|---|
| S-TRACK-013 | `C` | `C` | `track-headers` | Arm the selected tracks for recording | toggles `arm` |
| S-TRANS-007 | `Shift+F9` | `Shift+F9` | `global` | Arm recording in the Arrangement | toggles `arm` |

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `track` | [`TrackId`](README.md#trackid) | yes | The track. |
| `arm` | boolean | yes | Whether it's armed. |
| `linked` | boolean | no | Whether the edit reaches the tracks linked with the ones it names (the same on each); true if left out. Give false to limit it to what it names. |

Result: [`ChangeSet`](README.md#changeset).

### `mixer.set_crossfade_assign`

**Assign Crossfade**. Permission: `edit`. Contexts: `track-headers`, `session`, `arrangement`.

Assigns a track to a side of the crossfader, as its A and B buttons under the mixer's Crossfader section do: `a`, `b`, or `none` (neither, where every track starts). A track's sides are exclusive, so assigning one releases the other; a track assigned to neither plays through at every crossfader position. Every track but Main can be assigned, and Main carries the crossfader itself (`mixer.set_crossfader`). The assignment is saved with the set, and undo releases it.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `track` | [`TrackId`](README.md#trackid) | yes | The track; every track but Main. |
| `assign` | [`CrossfadeAssign`](README.md#crossfadeassign) | yes | `a`, `b`, or `none`. |

Result: [`ChangeSet`](README.md#changeset).

### `mixer.set_crossfader`

**Set Crossfader**. Permission: `edit`. Contexts: `session`, `arrangement`.

Sets the Main track's crossfader, as the Crossfader section's fader does. `position` runs from 0 (the A end) through 0.5 (the centre, where a new set starts) to 1 (the B end). Tracks assigned to A and B fade between the two ends on the default Constant Power curve: at the centre each side plays at -3 dB, at either end the near side plays at 0 dB, the far side is silent, and a track assigned to neither plays through at every position. The engine glides to the new position over 20 ms, so a move never clicks. The position is saved with the set.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `position` | number from 0 to 1 | yes | The position: 0 is the A end, 0.5 the centre, 1 the B end. |

Result: [`ChangeSet`](README.md#changeset).

### `mixer.set_cue_mode`

**Cue Switches**. Permission: `edit`. Contexts: `global`.

Switches Cue mode, as the Main strip's Solo/Cue button and the Options menu's Solo Switches and Cue Switches do: with `enabled` true, every track's Solo switch becomes a Cue switch (`mixer.set_solo` sets it) that feeds the Cue Out at the Cue Volume (`mixer.set_cue_volume`) instead of silencing the other tracks, and Main plays what the activators leave. A cue-switched track is heard on the Cue Out after its devices and before its volume, pan and activator. It needs a Cue Out that shares no output channel with Main Out (`routing.set_cue_out`, `routing.set_main_out`): turning it on with an overlap is refused, and an overlap made later switches it off in effect. A new set is in Solo mode. The mode is saved with the set and is no undo step.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `enabled` | boolean | yes | Whether the Solo switches are Cue switches. |

Result: [`ChangeSet`](README.md#changeset).

### `mixer.set_cue_volume`

**Set Cue Volume**. Permission: `edit`. Contexts: `global`.

Sets the Preview/Cue Volume knob on Main's strip, which scales the Cue Out in Cue mode, as a linear gain from 0 (-inf dB) to 1.995 (+6 dB); 1 (0 dB) is where a new set starts. The engine glides to the new value over 20 ms. The volume is saved with the set, and each change is one undo step.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `volume` | number from 0 to 1.9952623149688795 | yes | The gain: 1 is unity (0 dB, where a new set starts) and 0 silence, up to 1.995 (+6 dB). |

Result: [`ChangeSet`](README.md#changeset).

### `mixer.set_delay_compensation`

**Delay Compensation**. Permission: `edit`. Contexts: `global`.

Switches Delay Compensation, the Options menu item. On in a new set, it holds every path back so signals through high-latency devices reach the Main output aligned. While it's off, nothing is held back, no device's latency counts, and a track's Track Delay has no effect; the Track Delay and Hardware Latency controls are disabled, keeping their values. The setting is saved with the set, and each change is one undo step.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `enabled` | boolean | yes | Whether compensation is on. |

Result: [`ChangeSet`](README.md#changeset).

### `mixer.set_keep_monitoring_latency`

**Keep Monitoring Latency**. Permission: `edit`. Contexts: `track-headers`, `session`, `arrangement`.

Sets a track's Keep Monitoring Latency, as its Track Options do. With monitoring In or Auto, it decides whether a monitored track keeps its delay compensation while Reduced Latency When Monitoring is on: with `enabled` true (a new track's), the track is compensated with the rest of the set; off, it is given the lowest possible latency. The setting is saved only where it's off, and each change is one undo step.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `track` | [`TrackId`](README.md#trackid) | yes | The track. |
| `enabled` | boolean | yes | Whether it keeps its compensation. |

Result: [`ChangeSet`](README.md#changeset).

### `mixer.set_pan`

**Set Track Pan**. Permission: `edit`. Contexts: `session`, `arrangement`.

Sets a track's pan from -1 (fully left) through 0 (centre) to 1 (fully right). Use it to place a track in the stereo field. Panning keeps the power constant: at the centre both channels pass at 0 dB, and fully to one side that side is 3 dB louder and the other silent.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `track` | [`TrackId`](README.md#trackid) | yes | The track. |
| `pan` | number from -1 to 1 | yes | The pan position, from −1 (left) through 0 (centre) to 1 (right). |

Result: [`ChangeSet`](README.md#changeset).

### `mixer.set_pan_mode`

**Set Split Pan Mode**. Permission: `edit`. Contexts: `track-headers`, `session`, `arrangement`.

Sets a track's pan mode: `stereo` (the default) balances both channels with the one Pan control, and `split` gives each input channel its own control (`mixer.set_split_pan_left` and `mixer.set_split_pan_right`). Use it as the Pan control's context menu does. The mode is saved only where it isn't the default, and each change is one undo step.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `track` | [`TrackId`](README.md#trackid) | yes | The track. |
| `mode` | [`PanMode`](README.md#panmode) | yes | `stereo` or `split`. |

Result: [`ChangeSet`](README.md#changeset).

### `mixer.set_reduced_latency_monitoring`

**Reduced Latency When Monitoring**. Permission: `edit`. Contexts: `global`.

Switches Reduced Latency When Monitoring, the Options menu item, which is available only while Delay Compensation is on; the command refuses `enabled` true while compensation is off. With it on, a track whose input is monitored (Monitor In, or Auto while armed and not playing a clip) is given the lowest possible latency: its input isn't held back with the rest of the set, so it may be out of sync with tracks such as the returns, which stay compensated. A monitored track that keeps its monitoring latency (`mixer.set_keep_monitoring_latency`) is compensated as usual. The setting is saved with the set, and each change is one undo step.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `enabled` | boolean | yes | Whether a monitored track is given the lowest possible latency. |

Result: [`ChangeSet`](README.md#changeset).

### `mixer.set_send`

**Set Send Level**. Permission: `edit`. Contexts: `session`, `arrangement`.

Sets how much of a track's signal its send feeds to the return track `to`, as a linear gain from 0 (-inf dB, where every send starts) to 1 (0 dB). Use it to put a track through a return's effects, such as a shared reverb. Audio, MIDI, and group tracks have a send to every return; the return's Pre/Post switch (`mixer.set_send_tap`) decides whether the send takes the track's signal before or after its pan, volume, and activator.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `track` | [`TrackId`](README.md#trackid) | yes | The sending track. |
| `to` | [`TrackId`](README.md#trackid) | yes | The return track the send feeds. |
| `level` | number from 0 to 1 | yes | The level: 1 is 0 dB, 0.5 about −6 dB, and 0 sends nothing. |

Result: [`ChangeSet`](README.md#changeset).

### `mixer.set_send_tap`

**Set Sends Pre/Post**. Permission: `edit`. Contexts: `session`, `arrangement`.

Sets a return track's Pre/Post switch, which decides where every send to that return takes its signal from each sending track: `post` (the default) after the track's pan, volume, and activator, so the send follows the fader; `pre` before them, straight after the track's devices, for a mix that ignores the faders, such as a monitor mix. Only return tracks have it.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `track` | [`TrackId`](README.md#trackid) | yes | The return track. |
| `tap` | [`SendTap`](README.md#sendtap) | yes | `pre` or `post`. |

Result: [`ChangeSet`](README.md#changeset).

### `mixer.set_solo`

**Solo Track**. Permission: `edit`. Contexts: `track-headers`, `session`, `arrangement`.

Solos or unsolos one track, leaving other tracks' solo switches as they are, as a Cmd-click (Ctrl-click) on a Solo switch does; to solo one track alone, use `mixer.solo_exclusive`. While any track is soloed, only soloed tracks, the groups that hold them, and the tracks inside soloed groups are heard. Return tracks stay audible if Solo in Place is on (`mixer.set_solo_in_place`); soloing a return silences every other track's output but keeps their sends to it. In Cue mode (`mixer.set_cue_mode`) the switch is the track's Cue switch and silences nothing. Every track but Main can be soloed.

Default keys:

| Shortcut | macOS | Windows | Context | Action in the reference | Binding |
|---|---|---|---|---|---|
| S-TRACK-014 | `S` | `S` | `track-headers` | Solo the selected tracks | toggles `solo` |

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `track` | [`TrackId`](README.md#trackid) | yes | The track. |
| `solo` | boolean | yes | Whether it's soloed. |

Result: [`ChangeSet`](README.md#changeset).

### `mixer.set_solo_in_place`

**Solo in Place**. Permission: `edit`. Contexts: `global`.

Switches Solo in Place, the Options menu item. On (the default in a new set), soloing an audio, MIDI, or group track keeps the return tracks audible, so the soloed track is heard with its sends' effects; off, soloing such a track silences the returns too. It doesn't change what soloing a return does. The setting is saved with the set.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `enabled` | boolean | yes | Whether soloing a track keeps the return tracks audible. |

Result: [`ChangeSet`](README.md#changeset).

### `mixer.set_split_pan_left`

**Set Split Pan Left**. Permission: `edit`. Contexts: `track-headers`, `session`, `arrangement`.

In Split Stereo Pan Mode, sets the left input channel's position, from -1 (fully left) through 0 (centre) to 1 (fully right). Each channel is placed on the constant-power pan law, so a control fully to one side puts that channel on that side 3 dB louder. The position is an automation and modulation target, glides over 20 ms, and is saved only where it isn't the centre; each change is one undo step. It does nothing outside split mode.

Default keys: none.

| Name | Type | Required | Description |
|---|---|---|---|
| `track` | [`TrackId`](README.md#trackid) | yes | The track. |
| `pan` | number from -1 to 1 | yes | The position, from −1 (left) through 0 (centre) to 1 (right). |

Result: [`ChangeSet`](README.md#changeset).

### `mixer.set_track_delay`

**Set Track Delay**. Permission: `edit`. Contexts: `track-headers`, `session`, `arrangement`.

Sets a track's Track Delay, which shifts the track's whole output in time: positive delays the track, negative plays it early (the other paths then wait for it). `delay` names its unit, as Hardware Latency does: `{"unit": "milliseconds", "value": 10.0}` from -1000 to 1000 (kept in milliseconds when the sample rate changes) or `{"unit": "samples", "value": 480}` from -192000 to 192000 (kept in samples). The delay is saved with the set, and each change is one undo step. It is refused while Delay Compensation is off (`mixer.set_delay_compensation`), keeping its value.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `track` | [`TrackId`](README.md#trackid) | yes | The track. |
| `delay` | [`TrackDelay`](README.md#trackdelay) | yes | The delay and the unit it is in. |

Result: [`ChangeSet`](README.md#changeset).

### `mixer.set_volume`

**Set Track Volume**. Permission: `edit`. Contexts: `session`, `arrangement`.

Sets a track's volume as a linear gain: 1 is unity (0 dB), 0.5 is about -6 dB (10^(dB/20) converts decibels), 2 is about +6 dB, and 0 is silence (-inf dB). Use it to balance tracks; the Main track's volume sets the song's output level. The engine glides to the new level over 20 ms, so a change never clicks. The value must be finite and at least 0; a value above the fader's top, 1.995 (+6 dB), is stored as 1.995, and `query` reads back what is stored.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `track` | [`TrackId`](README.md#trackid) | yes | The track. |
| `volume` | number, at least 0 | yes | The gain: 1 is unity (0 dB), 0.5 about −6 dB, and 0 silence. |

Result: [`ChangeSet`](README.md#changeset).

### `mixer.solo_exclusive`

**Solo Track Exclusively**. Permission: `edit`. Contexts: `track-headers`, `session`, `arrangement`.

Solos one track and unsolos every other track, in one undo step, as a click on a Solo switch does while Exclusive Solo is on (Live's default). Use it to hear one track on its own. To unsolo, use `mixer.set_solo` with `solo` false. Every track but Main can be soloed.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `track` | [`TrackId`](README.md#trackid) | yes | The track. |

Result: [`ChangeSet`](README.md#changeset).
