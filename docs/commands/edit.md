## Commands

### `edit.go_to_step`

**Go to Step**. Permission: `edit`. Contexts: `global`.

Returns the set to the state just after the step at `index`, counted up from the set's start: 0 is the set's start, before any step, and the newest step is the number of steps there are. The steps above that row are undone and stay listed, greyed, until a new change replaces them. The jump is no step of its own.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `index` | integer, at least 0 | yes | The row, counted up from the set's start: 0 is the set's start, before any step, and the newest step is the number of steps there are. |

Result: [`ChangeSet`](README.md#changeset).

### `edit.redo`

**Redo**. Permission: `edit`. Contexts: `global`.

Redoes the step most recently undone. It fails if nothing has been undone since the last new change, because a new change discards the steps that could have been redone.

Default keys:

| Shortcut | macOS | Windows | Context | Action in the reference | Binding |
|---|---|---|---|---|---|
| S-EDIT-007 | `Cmd+Shift+Z` | `Ctrl+Y` | `global` | Redo | runs it |

Arguments: none (send `{}`).

Result: [`ChangeSet`](README.md#changeset).

### `edit.undo`

**Undo**. Permission: `edit`. Contexts: `global`.

Undoes the newest step in the undo history: the last command or gesture, however many changes it made. Use it to reverse a mistake; `edit.redo` puts the step back. It fails if there's nothing to undo.

Default keys:

| Shortcut | macOS | Windows | Context | Action in the reference | Binding |
|---|---|---|---|---|---|
| S-EDIT-006 | `Cmd+Z` | `Ctrl+Z` | `global` | Undo | runs it |

Arguments: none (send `{}`).

Result: [`ChangeSet`](README.md#changeset).
