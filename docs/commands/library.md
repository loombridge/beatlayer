## Commands

### `library.cancel`

**Cancel**. Permission: `edit`. Contexts: `global`.

Stops the library's download and takes its packages off the queue. If the library isn't installed and the Browser shows its page, the Browser goes back to All. Changes nothing in the set.

Default keys: none.

Arguments: none (send `{}`).

Result: [`LibraryState`](#librarystate).

### `library.close_credits`

**Close Library Credits**. Permission: `read`. Contexts: `global`.

Closes the Library Credits window. Changes nothing in the set.

Default keys: none.

Arguments: none (send `{}`).

Result: [`LibraryState`](#librarystate).

### `library.credits`

**Library Credits**. Permission: `read`. Contexts: `global`.

Reads the credit of each installed library item (its title, creator, licence with its link, source and changes made), by package, and the same as the text Export Credits writes. With `set`, only the library items the open set uses.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `set` | boolean | no | Give only the credits of the library items the open set uses. |

Result: [`Credits`](README.md#credits).

### `library.export_credits`

**Export Credits...**. Permission: `external`. Contexts: `global`.

Writes the credits `library.credits` gives to a text file, with `set` those of the library items the open set uses. Without a `path` a person is asked where. Writes a file outside the project.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `path` | string | no | The text file to write; a person's menu choice leaves it out and asks where. |
| `set` | boolean | no | Write only the credits of the library items the open set uses. |

Result: [`ExportedCredits`](README.md#exportedcredits).

### `library.install`

**Download Required Packages Now**. Permission: `external`. Contexts: `global`.

Downloads and installs the library's packages through the Packages manager, as `packages.install` does for the ones that aren't installed. Returns at once; `library.state` reports the progress. Changes nothing in the set.

Default keys: none.

Arguments: none (send `{}`).

Result: [`LibraryState`](#librarystate).

### `library.show_credits`

**Library Credits...**. Permission: `read`. Contexts: `global`.

Opens the Library Credits window, which lists every installed item's credit by package. Changes nothing in the set.

Default keys: none.

Arguments: none (send `{}`).

Result: [`LibraryState`](#librarystate).

### `library.state`

**Library**. Permission: `read`. Contexts: `global`.

Reads Beatlayer's own sound library: its packages for this platform (Core, Instruments, Drums, Loops), each installed or not with its size, its item count and the share downloaded, the folder they install in, how the download is going, whether the Library Credits window is open, and the library items the open set uses whose files are missing.

Default keys: none.

Arguments: none (send `{}`).

Result: [`LibraryState`](#librarystate).
