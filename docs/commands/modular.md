## Commands

### `modular.add_block`

**Add Block**. Permission: `edit`. Contexts: `device-view`.

Adds a block of type `block_type` to a Modular device's patch at `x`, `y` in its editor, with its type's default settings and no cables. The type is `oscillator`, `filter`, `envelope`, `lfo`, `amplifier`, `mixer`, `arithmetic`, `delay`, `note_in`, `note_out`, `audio_in`, `audio_out` or `sidechain_in`. `id` is the block's ID in the patch, the next free one if `null`. A patch holds at most 256 blocks. `modular.patch` reads the patch back. One undo step (Add Block).

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `device` | [`DeviceId`](README.md#deviceid) | yes | The Modular device. |
| `block_type` | string | yes | The block type's ID, such as `oscillator`. |
| `x` | number | yes | Where the block sits in the editor. |
| `y` | number | yes | Where the block sits in the editor. |
| `id` | [`BlockId`](README.md#blockid) or null | no | The new block's ID in the patch; the next free one if `null`. |

Result: [`ChangeSet`](README.md#changeset).

### `modular.connect`

**Connect Blocks**. Permission: `edit`. Contexts: `device-view`.

Joins output port `from_port` of block `from` to input port `to_port` of block `to` in a Modular device's patch. The ports must carry one type, except that control and audio join each other; an input takes one cable and an output any number; a patch holds at most 1,024 cables. A cable that would close a cycle with no Delay block in it is refused with the reason, and the patch stays as it was. `modular.patch` reads the patch back. One undo step (Connect Blocks).

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `device` | [`DeviceId`](README.md#deviceid) | yes | The Modular device. |
| `from` | [`BlockId`](README.md#blockid) | yes | The block the cable leaves. |
| `from_port` | string | yes | The output port it leaves, by ID. |
| `to` | [`BlockId`](README.md#blockid) | yes | The block it enters. |
| `to_port` | string | yes | The input port it enters, by ID. |

Result: [`ChangeSet`](README.md#changeset).

### `modular.expose`

**Change Patch Parameter**. Permission: `edit`. Contexts: `device-view`.

Makes setting `setting` of a block a patch parameter of a Modular device (`exposed` true) or stops (false). A patch parameter is one of the device's automatable parameters, 1 to 64, numbered by the slot it takes (`modular.patch` says which); its value runs from 0 to 1 across the setting's range. A patch holds at most 64. One undo step (Change Patch Parameter).

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `device` | [`DeviceId`](README.md#deviceid) | yes | The Modular device. |
| `block` | [`BlockId`](README.md#blockid) | yes | The block. |
| `setting` | string | yes | The setting's ID. |
| `exposed` | boolean | yes | Whether it is a patch parameter. |

Result: [`ChangeSet`](README.md#changeset).

### `modular.patch`

**Modular Patch**. Permission: `read`. Contexts: `device-view`.

Reports a Modular device's patch: every block with its type, place, ports (by ID and type) and settings (each with its value, default, range, unit and choices, and the patch parameter slot it is if it is one), the cables (each from a block's output port to another's input port), the patch parameters in slot order with the device parameter number each is, how many voices play, and how many blocks Beatlayer doesn't know. Changes nothing. The `modular.` commands that change the patch read back through it.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `device` | [`DeviceId`](README.md#deviceid) | yes | The Modular device. |

Result: [`PatchState`](README.md#patchstate).

### `modular.set`

**Change Block Setting**. Permission: `edit`. Contexts: `device-view`.

Sets setting `setting` of a block in a Modular device's patch to `value`: a choice's number from 0, or a number in the setting's own unit, within its range. A setting that is a patch parameter moves its parameter with it. `modular.patch` reads the patch back. One undo step (Change Block Setting).

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `device` | [`DeviceId`](README.md#deviceid) | yes | The Modular device. |
| `block` | [`BlockId`](README.md#blockid) | yes | The block. |
| `setting` | string | yes | The setting's ID, such as `cutoff`. |
| `value` | number | yes | Its value: a choice's number from 0, or a number in the setting's own unit. |

Result: [`ChangeSet`](README.md#changeset).
