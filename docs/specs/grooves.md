## The behaviour

A groove changes when a clip's notes play, and how loud, to give the clip a feel: a swing, a shuffle, the push and pull of a played part. A groove is a short pattern of note positions and velocities with five settings. Base is the grid its notes are measured against; Quantize pulls the clip's notes onto that grid first; Timing moves them towards the groove's positions; Random adds a little wandering; and Velocity applies the groove's accents. A Global Amount scales Timing, Random and Velocity for every groove in the set at once. Nothing is written into the clip while it plays: the groove is worked out as each note plays, and Commit writes it in when a person wants it fixed.

The set's grooves are in its Groove Pool, under the browser. Each clip, MIDI or audio, can use one; an audio clip only while it's warped, where the groove stretches its audio between the grid lines as warp markers would. Grooves come from files in the browser, from Beatlayer's own bundled grooves, or from a clip itself: Extract Groove(s) turns a clip's timing and loudness into a new groove. A groove dragged onto a MIDI track becomes a clip of its notes, to edit and extract again. New MIDI clips take the set's auto-load groove, which in a new set is one of Beatlayer's swing grooves at a Global Amount of 0 %, so it plays straight until the amount is raised.

Beatlayer's groove files are its own, and its bundled grooves are generated by a script in the repository; no groove from another library is copied.

## Rules

**Grooves in the set (WP-6.19)**

- **R1.** A set holds a Groove Pool: its grooves, in the order they were added. A groove has a name, a length (a positive number of ticks), its notes (each a position from 0 to before the length and a velocity from 1 to 127, no two at one position), and five parameters: Base, Quantize, Timing, Random and Velocity. The set also holds one Global Amount. (S1, S3, S5)
- **R2.** Base is one of 1/4, 1/8, 1/8T, 1/16, 1/16T and 1/32 (the steps besides 1/4 and 1/8 are Beatlayer's own list). Quantize, Timing and Random run from 0 to 100 %, Velocity from −100 to +100 %, and the Global Amount from 0 to 130 %. (S3)
- **R3.** Every MIDI or audio clip, in the Arrangement or in a Session slot, uses at most one groove of its set's pool, its Clip Groove, or none, which is a new clip's unless R20 gives it one. `clip.set_groove` (`edit`) sets the clips it names, or the selected clips, to a groove of the pool or to none, as one undo step (S10). A groove no clip uses is inactive. A clip copied, duplicated or moved within the set keeps its groove. (S1, S2, S7, S10)
- **R4.** A groove file is Beatlayer's own: a JSON file with a schema version and the extension `.blgroove`, holding the groove's name, length, notes and parameters. It's written whole or not at all, and a file that breaks R1 or R2 doesn't load. (S5; the format is Beatlayer's own)
- **R5.** `groove.load` (`external`, since it reads a file) adds the groove a file holds to the end of the pool with the parameters it holds, and with `clips` sets those clips to it, in one undo step, Load Groove (Beatlayer's own name). `groove.rename` (`edit`) renames a groove; `groove.delete` (`destructive`) takes it out of the pool and sets every clip that used it to none; `groove.set` (`edit`) sets any of a groove's parameters, keeping those it leaves out; `groove.set_global_amount` (`edit`) sets the Global Amount. Each is one undo step, a parameter's named Change "<parameter>". A change reaches a playing clip from the next block. (S2, S3)
- **R6.** A groove is laid along a clip's contents from their start, where its notes count from ([MIDI clips](midi-clips.md)), repeating every groove length. Its grid lines are the Base's, counted from the same start. At each grid line, the groove's offset is the position of the groove note nearest the line, if one lies within half a Base step of it, less the line's position, and that note's velocity is the line's groove velocity; a line with no groove note that near has an offset of 0 and no groove velocity. (S3; counting from the contents' start is Beatlayer's own)
- **R7.** On a MIDI clip, a note starting at `p` in the clip's contents plays at `q + T·A·D(q)`, where `q = p + Q·(L − p)`, `L` is the grid line nearest `p`, `Q` is Quantize, `T` is Timing, `A` is the Global Amount, and `D` is the groove's displacement: its offset at each grid line (R6), changing in a straight line between neighbouring lines. A note on a grid line therefore moves by `T·A` of the line's offset; Quantize at 100 % puts every note on its line first; and with Quantize, Timing and the Global Amount at 100 % a note lands on its groove note's position. With Timing, Random and Velocity at 0 the groove only quantises (S6). A note's whole movement from `q` is held to less than half a Base step either way. (S3, S6; the straight line between lines and the half-step limit are Beatlayer's own)
- **R8.** Random moves each note further, by `R·A` times a random number from −1 to 1 times a quarter of the Base step, where `R` is Random: a new number for each note each time it plays, so notes that start together drift apart (S3). The numbers come from a generator seeded from the clip's ID and started again whenever the transport starts, so a render plays the same every time and at any block size. (S3; the quarter step and the seeding are Beatlayer's own)
- **R9.** On a MIDI clip, a note's velocity changes by `V·A·(g − ḡ)`, where `V` is Velocity, `g` the groove velocity at the grid line nearest the note's start and `ḡ` the mean velocity of the groove's notes, rounded and held to 1 to 127: with Velocity above 0 the note is louder where the groove is louder, below 0 quieter there (S3). A line with no groove velocity leaves the note's velocity alone. The note's velocity deviation applies afterwards ([MIDI clips](midi-clips.md) R6). (S3; the law is Beatlayer's own)
- **R10.** The Global Amount scales Timing, Random and Velocity for every groove in the set, and not Quantize; at 100 % each plays as set. (S3)
- **R11.** A grooved note keeps its length, its note-off moving with its start, and its expressions ([MPE](mpe.md) R4). It plays inside the stretch of the clip it belongs to: moved before the clip's start, or the start of the loop pass it's in, it starts there; moved to or past the end of its pass, it starts one tick before that end. Its chance is rolled as for any note ([MIDI clips](midi-clips.md) R5). (S3; holding notes inside their pass is Beatlayer's own)
- **R12.** On a warped audio clip the groove moves the audio, in every warp mode, Re-Pitch included (S13): the clip's beats play through R7's displacement, with Random drawn for each grid line each pass in place of each note, so the audio between neighbouring grid lines stretches as it does between warp markers (S8). Quantize first moves each of the clip's transients ([warping](warping.md) R23), as audio quantise moves warp markers ([warping](warping.md) R49), its share of the way to its nearest grid line, the audio between neighbouring transients stretching to follow. Each line's whole movement is held to less than half a Base step, so the lines keep their order. On an unwarped clip a groove is kept and changes nothing. (S1, S8, S13; moving the transients for Quantize is Beatlayer's own)
- **R13.** On a warped audio clip, Velocity sets the clip's gain from each grid line to the next to `1 + V·A·(g − ḡ) ÷ 127`, held at 0 or above, gliding to each new gain over 1 ms; from a line with no groove velocity the gain is 1. (S7; the law and the glide are Beatlayer's own)
- **R14.** A groove changes only when a clip's notes play and how loud, or where its audio plays and how loud. The clip's own envelopes, its controller envelopes and its launch are untouched, and its notes and warp markers in the set stay as they are until a Commit (R16). (S3, S4; the envelopes are Beatlayer's own)
- **R15.** A clip's groove, a groove's parameters and the Global Amount reach the engine as node data, never as a new program, and act from the next block. Playing a groove allocates nothing, takes no lock and doesn't block on the audio thread, and a render is the same at any block size. (S16)
- **R16.** `groove.commit` (`edit`) writes a clip's groove into it and sets its groove to none, in one undo step, Commit Groove (S4, S7). A MIDI clip's notes move to where they play with the groove and take the velocities they play at, Random drawn once from the command's `seed` or a new seed. A warped audio clip gets a warp marker at each grid line and moved transient where R12 puts it, over the part of its contents that plays, and, while the groove's Velocity is above 0, a Volume clip envelope stepping through R13's gains, replacing any Volume clip envelope it had (S7). Given a groove and no clips, it commits every clip that uses the groove. (S4, S7; the seed and committing a groove's every clip are Beatlayer's own)
- **R17.** `groove.extract` (`edit`) makes a groove of each clip it names, or each selected clip, at the end of the pool, in one undo step, Extract Groove (Beatlayer's own name), from the part of the clip that plays: its loop brace while its loop is on, otherwise its Start to its End marker, the groove as long as that part (S5). From a MIDI clip, a groove note at each note's start with its velocity, the loudest of notes that start together. From an audio clip, a groove note at each of its transients ([warping](warping.md) R23, R24), in the clip's beats through its warp map (an unwarped clip's at the set's tempo where the clip starts), with a velocity from the audio's peak level in the 20 ms after it: the loudest peak 127, the others by their level, 48 dB below it at 1. The groove is named after the clip, "Groove" when the clip has no name, with Base 1/16, Quantize 0 %, Timing 100 %, Random 0 % and Velocity 0 %. (S5; the audio's level scale, the name and the parameters are Beatlayer's own)
- **R18.** `groove.to_clip` (`edit`) makes a MIDI clip of a groove on a MIDI track at a position: a note on C3 (key 60) at each groove note with its velocity, each a sixteenth long or as long as the gap to the next note, whichever is shorter; the clip one groove long, looping, named after the groove; one undo step. (S5; the key and the lengths are Beatlayer's own)
- **R19.** `groove.save` (`external`) writes a groove with its current parameters to a groove file at `path`, or as `<name>.blgroove` in the User Library's Grooves folder ([browser](browser.md) R3), and refuses a file already there unless `replace` is true, as [MIDI clips](midi-clips.md) R19 does. (S3, S9)
- **R20.** A set holds an Auto Load Groove switch and its auto-load groove, one of the pool's. While the switch is on, a MIDI clip made new, empty or by recording (Insert MIDI Clip, drawing a clip, a recording), uses the auto-load groove; a clip made by copying, pasting, importing a file or making a clip of a groove keeps its own. `groove.set_auto_load` (`edit`) sets the switch and the groove, one undo step. Deleting the auto-load groove leaves none, and nothing is auto-loaded. (S12; which clips count as new is Beatlayer's own)
- **R21.** The Global Amount reaches every device with each block, so a device whose own groove follows it, as the Arpeggiator's does (S11; [arpeggiator](arpeggiator.md) R19), reads it there. (S11)
- **R22.** The set saves its pool, each groove's notes and parameters, the Global Amount, Auto Load Groove and its groove, and each clip's groove. A set saved before grooves loads with an empty pool, a Global Amount of 100 % and Auto Load Groove off, and a clip naming a groove that isn't in the pool loads with none. (S16)
- **R23.** Every action here is a registered command with a schema, a description and a permission class (D17), each that isn't `read` naming its readback: `groove.pool` (`read`) reports each groove with its parameters, whether it's active and which clips use it, the Global Amount, and Auto Load Groove and its groove; the query tool's `song` holds the same under its saved `grooves`, and its `clip` the clip's `groove`. (S16)

**The Groove Pool, the browser and the bundled grooves (WP-6.20)**

- **R24.** The Groove Pool shows in the lower part of the browser column, the browser above it shrinking to make room (L-GRV-001), while View ▸ Groove Pool (M-VIEW-022, Cmd+Option+6, S-VIEW-017) and the Browser Config Menu's Groove Pool item (L-CTRL-001) are ticked; either switches it. Navigate ▸ Groove Pool (M-NAV-007, Option+6, S-FOCUS-007) moves the keyboard focus to it, showing it (I-FOCUS-002). Showing and focusing it are view state, never an undo step (`view.toggle_groove_pool` and `focus.groove_pool`, `read`). (S2, S14, S15)
- **R25.** Under the column headers Groove Name, Base, Quantize, Timing, Random and Velocity (L-GRV-002), the pool has a row for each groove in pool order: its name, its hot-swap, save and commit buttons, then its five fields (L-GRV-003). Its footer holds the section's name at the left and the Global Amount at the right (L-GRV-005). An empty pool shows "Drop Clips or Grooves Here" in its middle (L-GRV-004). An inactive groove's fields are drawn grey and still edit. (S2, S3, S15)
- **R26.** Each field edits its parameter as a value control does, dragged, stepped with the arrow keys or typed, Base chosen from its list, and runs `groove.set`, one undo step for each gesture; the footer's Global Amount runs `groove.set_global_amount` the same way. Clicking a groove's name selects it; Cmd+R (Ctrl+R) renames it in place and Delete deletes it (`groove.rename`, `groove.delete`). (S3; the selection and its keys are Beatlayer's own)
- **R27.** A row's save button runs `groove.save` into the User Library's Grooves folder; its hot-swap button makes the groove the browser's hot-swap target (R32); its commit button commits the groove into every clip that uses it (`groove.commit` with the groove). (S3, S15; the commit button's reach is Beatlayer's own)
- **R28.** Dropping clips from the Session or the Arrangement on the pool extracts a groove from each (`groove.extract`, I-DROP-010), and dropping a groove file loads it (`groove.load`). A groove dragged from the pool or the browser onto a clip becomes the clip's groove, loaded first if it isn't in the pool, in one undo step; dragged onto a MIDI track's lane, or the drop area below the tracks, which makes a new MIDI track, it becomes a clip of its notes there (`groove.to_clip`, I-DROP-017). (S2, S5, S15)
- **R29.** The Main Properties panel's groove controls (L-CLIP-004) are the Clip Groove chooser, listing None and then the pool's grooves in pool order and showing the groove of the clip the Clip View shows, with the Hot-Swap Groove and Commit buttons beside it. Choosing runs `clip.set_groove` for every clip the Clip View shows (S10); Hot-Swap Groove makes the clip's groove the browser's hot-swap target (R32); Commit runs `groove.commit` for those clips. (S7, S10, S15)
- **R30.** The Control Bar shows the Global Amount field while the pool holds a groove, everything to its right moving 40 points right, and hides it while the pool is empty (L-CTRL-008). It edits the Global Amount as the pool's footer does. (S3, S12, S15)
- **R31.** The pool's footer also holds the Auto Load Groove switch and a hot-swap button that makes the auto-load groove the browser's hot-swap target (R32), after the section's name (L-GRV-006; their place is Beatlayer's own); the switch runs `groove.set_auto_load`. (S12)
- **R32.** While a groove is the hot-swap target (a clip's, a pool groove's, or the auto-load groove), the browser shows its Grooves label, and loading a groove file with Enter or a double-click replaces the target: the file's groove takes the old groove's place in the pool, and every clip that used the old one, and the auto-load setting if it named it, uses the new one (S7). Each load is one undo step, Hot-Swap Groove (Beatlayer's own name). The hot-swap ends as a device's does: its button again, Esc, or the hot-swap bar's close button ([drum racks](drum-racks.md) R19). Starting and ending it is view state (`groove.hot_swap`, `read`). (S1, S7, S12)
- **R33.** The browser's Grooves label (L-BRW-004) lists Beatlayer's bundled grooves (R36) and the groove files in the User Library's Grooves folder, by name; groove files show in every place and in search as the browser lists files ([browser](browser.md) R6, R9). Enter or a double-click on a groove, with no hot-swap target, loads it into the pool without applying it (`groove.load`). (S2, S9, S15)
- **R34.** Extract Groove(s), in the Edit menu (M-EDIT-037) and in a clip's context menu in the Session and the Arrangement (C-CLIP-SES-007, C-CLIP-ARR-009), runs `groove.extract` for the selected clips, and is disabled while no clip is selected. (S5, S15)
- **R35.** The pool reaches assistive technology as a table: each row a groove, each field a value control with its name and value, each button named for what it does, and the footer's Global Amount and Auto Load Groove; Tab moves between a row's fields and Up and Down between rows once the pool has the focus. (S14)
- **R36.** Beatlayer's bundled grooves are its own: Swing 8ths and Swing 16ths at 55 %, 60 %, 65 %, 70 % and 75 %, and Straight 8ths and Straight 16ths, each one 4/4 bar long. A swing of `s` % puts the second step of each pair of steps at `s` % of the pair's length; a straight groove has every step on its line. Every groove's on-beat steps have velocity 127 and the others 100; its Base is its steps' (1/8 or 1/16), Quantize 0 %, Timing 100 %, Random 0 % and Velocity 0 %. They're named as listed, "Swing 16ths 60" and so on. (S16; the list, the accents and the names are Beatlayer's own)
- **R37.** A script in the repository generates the bundled grooves' files; the packaged app carries them, read-only, where the Grooves label finds them, and a test checks that the files shipped are the script's output. (S16)
- **R38.** The factory default set has Swing 16ths 60 in its pool as its auto-load groove, with Auto Load Groove on and the Global Amount at 0 %, so a new set's MIDI clips carry a groove that changes nothing until the Global Amount is raised. (S12; the groove chosen is Beatlayer's own)
