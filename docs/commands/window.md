## Commands

### `window.close`

**Close Window**. Permission: `read`. Contexts: `global`, `dialog`, `settings`.

Closes the frontmost secondary window, such as the Settings window. The main window stays open; quit to close it. From the keyboard or the File menu it acts only while a secondary window is in front, as in Live, where Close Window is disabled with only the main window open.

Default keys:

| Shortcut | macOS | Windows | Context | Action in the reference | Binding |
|---|---|---|---|---|---|
| S-FILE-009 | `Cmd+W` | `Ctrl+W` | `global` | Close the frontmost window | runs it |
| S-VIEW-020 | `Esc` | `Esc` | `dialog` | Close the frontmost window or dialog | runs it |
| S-SET-007 | `Esc` | `Esc` | `settings` | Close the Settings window | runs it |

Arguments: none (send `{}`).

Result: nothing (`null`).
