## Commands

### `sync.state`

**Sync Status**. Permission: `read`. Contexts: `global`.

Reports the state of MIDI clock. Sent: how many output ports have Sync on, whether clock is going out now (the song plays, past any count-in), whether the lower sync lamp beside the Control Bar's tempo is lit, and how many Timing Clocks the audio engine has sent, stamped late and dropped since it started. Received: how many input ports have Sync on, whether EXT is available and on, the input that leads, whether usable clocks arrive, whether the upper sync lamp is lit, the smoothed incoming tempo, and how many Timing Clocks arrived and were set aside as glitches. For an input set to MIDI Timecode: the last whole time with its rate, whether it runs, and the song position it gives. Changes nothing. Set a port's Sync switch and its options with `midi.set_port`, and EXT with `transport.set_external_sync`.

Default keys: none.

Arguments: none (send `{}`).

Result: [`SyncState`](#syncstate).
