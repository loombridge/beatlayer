## Commands

### `agent.approve_client`

**Allow Agent**. Permission: `external`. Contexts: `settings`.

Allows the agent called `client` to connect to the agent server, as answering Allow when it first connects does, and makes it its own token. Its approval and its autonomous mode belong to that token, not to its name: a client that connects with the agent's token isn't asked about again, and one that connects with the server's token is asked each time and is never autonomous, whatever name it gives. The approval is kept for the next start. It changes what agents may do, so only a person can run it, in the Settings window: the agent API refuses it.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `client` | string | yes | The agent's name, as it gives it when it connects. |

Result: [`AgentServerState`](README.md#agentserverstate).

### `agent.forget_client`

**Forget Agent**. Permission: `edit`. Contexts: `settings`.

Withdraws the approval of the agent called `client`, so the person is asked again the next time it connects. Its sessions end. It changes what agents may do, so only a person can run it, in the Settings window: the agent API refuses it.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `client` | string | yes | The agent's name, as it gives it when it connects. |

Result: [`AgentServerState`](README.md#agentserverstate).

### `agent.new_client_token`

**New Agent Token**. Permission: `external`. Contexts: `settings`.

Replaces the own token of the allowed agent called `client` with a new random one, so a client configured with the old one can no longer speak for that agent until it's given the new one: requests carrying the old one are refused. Use it if the agent's token may have leaked. It changes what agents may do, so only a person can run it, in the Settings window: the agent API refuses it.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `client` | string | yes | The agent's name, as it gives it when it connects. |

Result: [`AgentServerState`](README.md#agentserverstate).

### `agent.new_token`

**New Token**. Permission: `external`. Contexts: `settings`.

Replaces the agent server's token with a new random one, so agents configured with the old token can no longer connect until they're given the new one, which the Settings window shows. Use it if the token may have leaked. It changes what agents may do, so only a person can run it, in the Settings window: the agent API refuses it.

Default keys: none.

Arguments: none (send `{}`).

Result: [`AgentServerState`](README.md#agentserverstate).

### `agent.set_autonomous`

**Autonomous**. Permission: `external`. Contexts: `settings`.

Switches autonomous mode for the allowed agent called `client`. With it on, the agent runs destructive commands (deleting, discarding, overwriting, or placing clips over others) and external ones (files outside the project, devices, other applications) without asking the person first; with it off, as it starts, each one waits for the person's confirmation. It applies only to requests that carry the agent's own token. It changes what agents may do, so only a person can run it, in the Settings window: the agent API refuses it.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `client` | string | yes | The agent's name, as it gives it when it connects. |
| `on` | boolean | yes | Whether it runs destructive and external commands without asking. |

Result: [`AgentServerState`](README.md#agentserverstate).

### `agent.set_server`

**Agent Server**. Permission: `external`. Contexts: `settings`.

Switches the agent server on or off, or moves it to another port. While it's on, agent clients on this computer reach the agent API over Streamable HTTP at `http://127.0.0.1:<port>/mcp`, each request carrying a token as a bearer token: an allowed agent's own token, or the server's token, with which a client is asked about each time it connects. Requests from web pages are refused. Switching it on the first time makes the server's token. The setting is kept for the next start. It changes what agents may do, so only a person can run it, in the Settings window: the agent API refuses it.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `on` | boolean or null | no | Whether the server runs. |
| `port` | integer or null | no | The port to listen on, from 1024 to 65535. |

Result: [`AgentServerState`](README.md#agentserverstate).
