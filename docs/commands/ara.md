## Commands

### `ara.state`

**ARA Plug-In State**. Permission: `read`. Contexts: `global`.

Reports what each running ARA plug-in's document holds and has done: the devices bound to it and the tracks they render, how many region sequences, audio sources and audio modifications it has, each playback region with its place in the file and on the timeline in seconds, how many edit cycles the set has been given in, how many audio readers it opened and how much it read (never from the audio thread), the files it couldn't be given, and whether it restored its archive. A track with an ARA plug-in leaves its clips to it; the plug-in follows every clip edit, undo and redo as document edits. Changes nothing.

Default keys: none.

Arguments: none (send `{}`).

Result: [`AraState`](#arastate).
