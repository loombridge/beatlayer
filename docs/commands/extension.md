## Commands

### `extension.describe`

**Describe Extension**. Permission: `read`. Contexts: `global`.

Reads the extension `id`: its manifest (name, version, author, licence and description), each component with its kind, world version, imports and memory, whether it is on and its last failure, and the commands it may call.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `id` | string | yes | The extension's ID, as `extension.list` gives it. |

Result: [`ExtensionDescription`](README.md#extensiondescription).

### `extension.install`

**Install Extension**. Permission: `external`. Contexts: `global`.

Installs the extension package at `path` (a `.blext` file: a ZIP holding `extension.toml` and its WebAssembly components) into the User Library's `Extensions` folder, switched on. The whole package is checked first and nothing is kept if any check fails: an unsafe path, a manifest that doesn't parse or lacks a field, a world version this Beatlayer doesn't accept, a component that is missing, isn't valid, doesn't export its kind's world or imports more than its world gives it, or an extension of the same ID at an equal or later version. The reason comes back as the error. A later version of an installed extension replaces it. Returns the installed extensions. It is `external` because it reads a file outside the project.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `path` | string | yes | The path of the `.blext` package to install. |

Result: [`ExtensionList`](#extensionlist).

### `extension.list`

**Extensions**. Permission: `read`. Contexts: `global`.

Reads each installed extension: its ID, name and version, what its components do, whether it is on, and why a component of it was stopped, if one was; and the User Library folder they are installed in.

Default keys: none.

Arguments: none (send `{}`).

Result: [`ExtensionList`](#extensionlist).

### `extension.remove`

**Remove Extension**. Permission: `destructive`. Contexts: `global`.

Removes the extension `id` (`extension.list` gives the IDs): its folder in the User Library and its compiled code. Returns the installed extensions.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `id` | string | yes | The extension's ID, as `extension.list` gives it. |

Result: [`ExtensionList`](#extensionlist).

### `extension.set_enabled`

**Switch Extension On or Off**. Permission: `edit`. Contexts: `global`.

Switches the extension `id` on or off. The choice is kept in the preferences. Switching an extension on also clears the failure that stopped it. Returns the installed extensions.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `id` | string | yes | The extension's ID, as `extension.list` gives it. |
| `enabled` | boolean | yes | Whether it is on. |

Result: [`ExtensionList`](#extensionlist).
