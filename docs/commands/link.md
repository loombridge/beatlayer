## Commands

### `link.set_audio`

**Link Audio**. Permission: `external`. Contexts: `global`.

Switches Link Audio, as Settings' Link page and the Link menu do: on, with Link on, every track with an audio output is offered to the other apps in the session as a channel, and the channels they offer can be an audio track's input (`routing.set_input` with the `link_audio` input). It sends audio over the network, so it is external. It does nothing while Link is off, and keeps its state. `on` left out switches to the other state. It is a preference kept between starts, not part of the set. `link.state` reports it.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `on` | boolean or null | no | Whether it's on; left out, it switches to the other state. |

Result: [`Switched`](README.md#switched).

### `link.set_audio_latency`

**Link Audio Latency**. Permission: `edit`. Contexts: `global`.

Sets the input latency of audio that arrives from the other apps in the Link session, in milliseconds from 0 to 200 (20 at first), as Settings' Link page's Latency does: incoming audio plays on the beat it was sent on, that much later, and more of it is buffered. It is a preference kept between starts, not part of the set. `link.state` reports it.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `ms` | number | yes | The latency, in milliseconds, from 0 to 200; a value outside that range is brought into it. |

Result: [`AudioLatency`](README.md#audiolatency).

### `link.set_audio_name`

**Link Audio Name**. Permission: `edit`. Contexts: `global`.

Sets the name other apps in the Link session see this app by, as Settings' Link page's Name does. An empty name is the computer's name, which a new install has. It is a preference kept between starts, not part of the set. `link.state` reports it.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `name` | string | yes | The name other peers see this app by; empty for the computer's name. |

Result: [`AudioName`](README.md#audioname).

### `link.set_enabled`

**Link**. Permission: `external`. Contexts: `global`.

Switches Link, as the Control Bar's Link toggle does: on, the app joins the Link session on its networks or starts one, and shares tempo, beat and phase with the other apps in it. It talks on the network, so it is external. With no session to join, switching it on changes neither the tempo nor the song position; where a session exists, the song takes its tempo and phase. While it is on, a tempo change from a peer becomes the set's tempo and overrides tempo automation, the count-in doesn't play, and a start waits for the session's phase. `on` left out switches to the other state. It is a preference kept between starts, not part of the set. `link.state` reports it.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `on` | boolean or null | no | Whether it's on; left out, it switches to the other state. |

Result: [`Switched`](README.md#switched).

### `link.set_show_toggle`

**Show Link Toggle**. Permission: `edit`. Contexts: `global`.

Shows or hides the Control Bar's Link toggle and its menu, as Settings' Link page's Show Link Toggle does. Hiding it leaves Link as it is. `on` is whether it shows; left out, it switches to the other state. It is a preference kept between starts, not part of the set. `link.state` reports it.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `on` | boolean or null | no | Whether it's on; left out, it switches to the other state. |

Result: [`Switched`](README.md#switched).

### `link.set_start_stop_sync`

**Link Start Stop Sync**. Permission: `edit`. Contexts: `global`.

Switches Start Stop Sync: with it on, the app's starts and stops go to the Link session and a peer's reach the app, with the peers that have it on too. Switching it on while the session plays doesn't start the song. `on` left out switches to the other state. It is a preference kept between starts, not part of the set. `link.state` reports it.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `on` | boolean or null | no | Whether it's on; left out, it switches to the other state. |

Result: [`Switched`](README.md#switched).

### `link.set_sync_to_incoming_audio`

**Sync to Incoming Audio**. Permission: `edit`. Contexts: `global`.

Switches Sync to Incoming Audio, as Settings' Link page does: with it on, and Link Audio on, Beatlayer delays its own playback by the latency so that the audio it monitors from other apps in the session lines up with its own clips. Only one of the session's apps should have it on. `on` left out switches to the other state. It is a preference kept between starts, not part of the set. `link.state` reports it.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `on` | boolean or null | no | Whether it's on; left out, it switches to the other state. |

Result: [`Switched`](README.md#switched).

### `link.state`

**Link Status**. Permission: `read`. Contexts: `global`.

Reports Link: whether it is on, how many other peers are in the session, the session's tempo, the quantum (the global launch quantisation's length at the play position, in quarter notes) and how far the session is through it, whether the session plays, whether Start Stop Sync is on, whether the Control Bar shows the Link toggle, and whether a start waits for the session's phase and how many seconds until it begins. Also Link Audio: whether it is on, the name other peers see this app by, the latency in milliseconds, whether Sync to Incoming Audio is on, and the peers with Link Audio on, each with its name, whether audio is arriving from it, the audio buffered from it in milliseconds, and its channels. Changes nothing. Switch Link with `link.set_enabled`, Start Stop Sync with `link.set_start_stop_sync` and Link Audio with `link.set_audio`.

Default keys: none.

Arguments: none (send `{}`).

Result: [`LinkState`](#linkstate).
