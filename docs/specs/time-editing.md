## The behaviour

Locators mark places in the Arrangement to play from. They sit in the scrub area above the tracks. The Set Locator button above the track headers adds one where the song is playing, on the global launch quantisation's grid, or at the insert marker while the song is stopped; with a locator selected the same button reads Delete Locator. Clicking a locator jumps there, on the grid while the song plays, and the Previous and Next Locator buttons under Set jump from one to the next. A locator can be dragged, nudged, renamed, given info text, and deleted, and its context menu loops the song from it to the next locator or makes it the song start time, the place Play starts from. A click in the scrub area plays from that point, on the same grid.

The …Time commands change the song's length. Delete Time removes the selected span of time from every track, so what follows closes up; Cut Time copies it first. Insert Silence opens up empty time on every track. Copy Time copies the selected time from every track, and Paste Time opens up time and puts that material in it. Duplicate Time puts a copy of the selected time straight after it. Unlike Cut, Copy, Paste, Duplicate and Delete, which act on the selected clips or the material on the selected tracks ([arrangement-editing.md](arrangement-editing.md)), these act on every track at once: their clips, their automation, the song's tempo and time-signature changes, and the locators. Holding Shift with Cut, Copy, Paste, Duplicate or Delete runs the …Time command instead.

This spec covers locators, the song start time, the scrub area's click, and the …Time commands. The transport's own rules for the song start time and a quantised jump are [transport.md](transport.md)'s (R21, R22). Undo steps named in code type, such as `Add Locator`, are Beatlayer's own names.

## Rules

**Locators (WP-6.24)**

- **R1.** A set holds any number of locators. Each has a stable ID, a position in ticks from 1.1.1 on, a name, and info text, and no two share a position. The set saves them; a set saved before locators loads with none, and a locator before 1.1.1 or a second one at a position doesn't load. (S2, S11)
- **R2.** Each locator is drawn in the scrub area (L-ARR-003) at its position, with its name, and a selected locator in the selection colour; the look is Beatlayer's own. Assistive technology reads each locator on screen as a button named for it, its value its position as bars, beats and sixteenths, and whether it's selected. (S1, S10)
- **R3.** The Set Locator button (L-ARR-010) adds a locator: while the song plays or records, at the line of the global launch quantisation nearest the playhead, or at the playhead itself while quantisation is off or None ("nearest" is Beatlayer's own); while stopped, at the start of the time selection, or at the insert marker with none. Add Locator in the scrub area's context menu (C-TIME-022) adds one where the scrub area was right-clicked, on the editing grid while snapping is on, and Create ▸ Add Locator (M-CREATE-016) adds one as the button does. Each is one undo step, `Add Locator`. A new locator is named with the next whole number, one more than the highest any locator is named with ("1" in a set with none; Beatlayer's own), becomes the only selected locator, and, while Tab moves the focus, takes the keyboard focus. Adding at a position that has a locator adds nothing and selects that one. (S1, S2, S9, S10)
- **R4.** While a locator is selected, the Set Locator button reads Delete Locator and deletes the selected locators, and so do Create ▸ Delete Locator (the same item as Add Locator, M-CREATE-016) and the Delete key in the Arrangement: one undo step, `Delete Locator`. (S1, S2, S10)
- **R5.** Clicking a locator selects it alone, clearing the clip selection and the time selection (Beatlayer's own), and jumps to it: while the song plays, playback jumps to it at the next line of the global launch quantisation ([transport.md](transport.md) R22); while stopped, the insert marker moves there. Double-clicking a locator while stopped selects it and starts playback from it. Selecting is view state, not an undo step. (S1, S2, S10)
- **R6.** The Previous Locator and Next Locator buttons, under Set Locator (L-ARR-010), jump as R5 does to the nearest locator before or after the current position: the playhead while the song plays, the insert marker while it's stopped. With no locator before it, Previous jumps to 1.1.1; with none after it, Next jumps to the Arrangement's end, the end of its last clip on any track, or 1.1.1 when it has none (Beatlayer's own). Neither selects a locator. (S1, S2)
- **R7.** Dragging a locator moves it, and every other selected locator by the same distance, snapping as a clip's start does ([arrangement-editing.md](arrangement-editing.md) R4, R22), with Cmd (Alt on Windows) doing the opposite of the grid's setting ([arrangement-editing.md](arrangement-editing.md) R4); no locator goes before 1.1.1, and a move that would put two locators at one position leaves them where they were. While locators are selected, Left and Right move them one grid step. Each drag or key press is one undo step, `Move Locator`. (S2, S10)
- **R8.** Rename (Cmd-R, Edit ▸ Rename, M-EDIT-024) renames the selected locator in place: Return keeps the typed name and Esc drops it, and an empty name keeps the old one. Edit Info Text (Edit ▸ Edit Info Text, M-EDIT-025, and the locator's context menu, C-TIME-025) sets its info text, as [info-view.md](info-view.md) R10 says, which the Info View shows while the pointer is over it. Each is one undo step. (S2, S10)
- **R9.** Loop to Next Locator, in a locator's context menu (C-TIME-023), sets the loop brace from that locator to the next one and switches the Arrangement loop on, as one undo step, as Loop Selection does ([arrangement-editing.md](arrangement-editing.md) R18). It's disabled on the last locator (Beatlayer's own). (S2, S10)
- **R10.** Set Song Start Time Here, in a locator's context menu and in the loop brace's (C-TIME-023), ticked on the one that holds the song start time, makes that locator, or the loop brace's start, the song start time; choosing it where it's ticked clears it. The song start time follows its locator or the brace's start as they move, and deleting its locator clears it. The set saves it, a set saved before it loads with none, and each change is one undo step. Play starts from it while it's set ([transport.md](transport.md) R21). The locator, or the brace's start, that holds it is drawn in the theme's song start colour. (S2, S4, S9)
- **R11.** Clicking the scrub area (I-CLICK-012), away from a locator, plays from the clicked point, on the editing grid while snapping is on (the snapping is Beatlayer's own): while the song plays, playback jumps there at the next line of the global launch quantisation ([transport.md](transport.md) R22); while stopped, playback starts there. It resumes Follow, as it does now ([arrangement-view.md](arrangement-view.md) R10). (S3, S10)
- **R12.** Option-Left and Option-Right (Ctrl on Windows, S-A11Y-001) move the insert marker to the previous or next clip edge on the selected tracks or locator, whichever is nearer ([arrangement-editing.md](arrangement-editing.md) R12). The locators are in the Arrangement's Tab order ([accessibility.md](accessibility.md) R10): Tab reaching a locator selects it, Enter jumps to it as R5 does, and Delete deletes it as R4 does. (S6, S10)
- **R13.** Every action here is a registered command with a schema, a description written for a model, and a permission class, run headless with explicit locator IDs and positions in ticks or as bars, beats and sixteenths, or, with those left out, on the selection, as keys and menus run them: `locator.add`, `locator.move`, `locator.rename`, `locator.set_info_text`, `locator.loop_to_next` and `song.set_start_time` are `edit`; `locator.delete` is `destructive`; `locator.select`, `locator.jump`, `locator.jump_previous` and `locator.jump_next` are `read`, as the transport's playback commands are ([transport.md](transport.md) R19), and are refused with the reason while the audio engine is off. The query tool's song reads them back (`settings.locators`, `settings.song_start`), and `arrangement.state` reports the selected locators (`selected_locators`). (S11)

**The …Time commands (WP-6.24b)**

- **R14.** The …Time commands act on a span of time on every track of the set, whichever tracks are selected: the time selection's span (the span of the selected clips when clips are selected), or the clipboard's length for Paste Time. On every track they act on the clips of its Arrangement lane and its take lanes and on its automation envelopes, the Main track's Song Tempo envelope among them; across the song they act on the time-signature markers and the locators, and on the song start time when it's on a locator. The Session View's slots, the loop brace, and the envelopes inside clips (other than as a split clip's parts keep them, [clip-envelopes.md](clip-envelopes.md) R7) are left as they are (the loop brace is Beatlayer's own). They act the same whether Lock Envelopes is on or off (Beatlayer's own; [automation-editing.md](automation-editing.md) R10). (S5, S8)
- **R15.** Delete Time (Cmd-Shift-Delete, Edit ▸ Delete Time, M-EDIT-022) removes the span from every track. A clip that crosses an edge of the span is split there, each part playing what it played ([arrangement-editing.md](arrangement-editing.md) R8, R16); the parts inside the span are deleted; and every clip, breakpoint, time-signature marker and locator at or after the span's end moves earlier by its length, so what was either side closes up. An envelope keeps its shape up to the span's start and from there takes the shape it had from the span's end on, stepping between the two values over one tick where they differ; the Song Tempo envelope steps at the span's start with two breakpoints at one position ([musical-time.md](musical-time.md)). Time-signature markers and locators inside the span are deleted, and the signature in force at the span's end stays in force from its start, a marker being placed there where it differs from the one before. These closing-up details are Beatlayer's own. It's `destructive`, one undo step, `Delete Time`, and leaves the insert marker at the span's start with no time selected. (S5, S8)
- **R16.** Cut Time (Cmd-Shift-X, Edit ▸ Cut Time, M-EDIT-018) puts the span on the clipboard as Copy Time does (R18), then deletes it as Delete Time does: `destructive`, one undo step, `Cut Time`. (S5, S8)
- **R17.** Insert Silence (Cmd-I with the Arrangement focused, the Create menu) inserts, at the time selection's start, as much empty time as the selection is long, on every track: a clip that crosses that point is split there, and every clip, breakpoint, time-signature marker and locator at or after it moves later by that length; each envelope, the tempo and the signature hold across the inserted time the value they had at the point. Reading the manual's chosen amount as the selection's length, the holding values, and refusing Insert Silence with no time selected are Beatlayer's own. It's an `edit`, one undo step, `Insert Silence`, and the inserted span becomes the time selection. In the Create menu it takes Insert Scene's place (M-CREATE-005) while the Arrangement has the focus (Beatlayer's own). (S5, S7, S10)
- **R18.** Copy Time (Cmd-Shift-C, Edit ▸ Copy Time, M-EDIT-019) puts the span's material from every track on the clipboard, replacing what it held: each track's clips and parts of clips inside the span, as Copy takes them ([arrangement-editing.md](arrangement-editing.md) R11), by the track they came from; each track's envelopes over the span; the Song Tempo over it; the time-signature markers and locators inside it; and its length. It's `read` and never an undo step. (S5, S8)
- **R19.** Paste Time (Cmd-Shift-V, the Edit menu's item M-EDIT-020) inserts the clipboard's length of time on every track at the time selection's start, or at the insert marker with none, as Insert Silence inserts time (R17), and puts the clipboard's material in the opened span. Material from Copy Time or Cut Time goes back onto the tracks it came from, with their envelopes, the tempo, the time-signature markers and the locators (a track deleted since gets nothing, and a locator's name comes with it); clips from Copy or Cut go where Paste puts them ([arrangement-editing.md](arrangement-editing.md) R11). Where Paste Time puts each kind of clipboard is Beatlayer's own, and so is dropping the time-signature marker that the opened time pushed to the span's end when it only restates the signature in force there, which Delete Time put at the span's start, so Cut Time then Paste Time at one place gives the markers back. It's an `edit`, one undo step, `Paste Time`, and the pasted span becomes the time selection. With nothing on the clipboard it's unavailable. (S5, S8)
- **R20.** Duplicate Time (Cmd-Shift-D, Edit ▸ Duplicate Time, M-EDIT-021) puts a copy of the span's material from every track straight after the span, as Copy Time and Paste Time at the span's end would, leaving the clipboard as it was: an `edit`, one undo step, `Duplicate Time`. The copy becomes the time selection, so pressing it again lays down another (Beatlayer's own). (S5, S8)
- **R21.** In the Arrangement, Shift held with Cut, Copy, Paste, Duplicate or Delete (S-EDIT-015) runs Cut Time, Copy Time, Paste Time, Duplicate Time or Delete Time: the same keys as S-ARR-015 to S-ARR-019, so the keymap marks S-EDIT-015 bound by those five commands. (S7)
- **R22.** The Edit menu's items M-EDIT-018 to M-EDIT-022, the Create menu's Insert Silence, and the time selection's context menu (C-TIME-018) run these commands and show their keys; each is disabled while there's no span to act on, and Paste Time while the clipboard is empty. In the time selection's menu the five …Time items follow Duplicate, between separators (Beatlayer's own, as menus.md doesn't place them). (S5, S10)
- **R23.** After any …Time command no two clips on a track overlap ([arrangement-editing.md](arrangement-editing.md) R6), no two breakpoints of an envelope or two locators share a position, and undo returns the set exactly as it was before the command. (S11)
- **R24.** The commands are `arrangement.insert_silence`, `arrangement.cut_time`, `arrangement.copy_time`, `arrangement.paste_time`, `arrangement.duplicate_time` and `arrangement.delete_time`, registered with schemas, descriptions and permission classes as R15 to R20 give them, run headless with an explicit span (or position, for Paste Time) in ticks or as bars, beats and sixteenths, or with those left out on the selection, as keys and menus run them. They read back through the query tool's tracks (`clips`, `automation`) and song (`settings`), and `arrangement.copy_time` reports what the clipboard holds. (S11)

**The scrub area's hold, Shift-click and Permanent Scrub Areas (WP-6.59)**

- **R25.** Holding the mouse button on a point of the scrub area (I-CLICK-013) loops playback over a span from the line of the global launch quantisation at or before the point, one quantisation step long (a bar while quantisation is off or None; Beatlayer's own), starting playback if it's stopped, as [transport.md](transport.md) R23 says; releasing the button ends the loop, and playback carries on from where it is (Beatlayer's own). The Arrangement loop and its brace are left as they are. (S12, S14)
- **R26.** Permanent Scrub Areas (Settings ▸ Display & Input, L-SET-010) is on in a new install and kept between launches (`settings.set_permanent_scrub_areas`, `edit`, read back by `settings.state` as `permanent_scrub_areas`). While it's on, a click and a hold in the scrub area act as R11 and R25 say; while it's off, a click there places the insert marker as a click in a lane does and starts nothing (Beatlayer's own), and a hold loops nothing. (S12, S14)
- **R27.** Shift-click in the scrub area or in the beat-time ruler (I-CLICK-014) scrubs whatever the setting: it plays from the clicked point as R11 says, and a Shift-hold loops as R25 says. In the beat-time ruler a Shift-click doesn't scroll or zoom. (S12, S14)
- **R28.** The scrub gestures run `transport.scrub` (`read`, a playback command, refused without an engine): a point, and whether the button is held, so an agent can play from a point or loop there and stop looping. (S11)

**The time-signature lane and fragmentary bars (WP-6.61)**

- **R29.** The time-signature lane (L-ARR-004) shows just under the beat-time ruler while the set has a time-signature change after 1.1.1, and is hidden otherwise. Each marker is drawn at its position with its signature (`3/4`), a selected marker in the selection colour, and a bar cut short by a marker drawn hatched in the lane. Assistive technology reads each marker as a button named for its signature, its value its position. (S13, S14)
- **R30.** Create ▸ Insert Time Signature Change (M-CREATE-017, which reads Add Time Signature Change and is disabled while the Arrangement doesn't have the focus) and Insert Time Signature Change in the scrub area's context menu (C-TIME-022) add a marker at the insert marker with the signature in force there, select it, and open its value for typing as R31 does; one undo step, `Insert Time Signature Change` (Beatlayer's own name). At a position that has a marker, it selects that one. (S13, S14)
- **R31.** Clicking a marker selects it, clearing other selections. Edit ▸ Edit Time Signature, the item of that name in the scrub area's context menu, and Cmd-R open the selected marker's signature for typing: a numerator from 1 to 99 and a denominator of 1, 2, 4, 8 or 16, with a slash, comma, full stop or spaces between them ([musical-time.md](musical-time.md)); Return sets it and Esc drops it, and a signature outside those ranges is refused. One undo step. (S13, S14)
- **R32.** Dragging a marker moves it, snapping as a clip's start does ([arrangement-editing.md](arrangement-editing.md) R4, R21), and Left and Right move a selected marker one grid step; Delete and Edit ▸ Delete delete it. Each is one undo step. The marker at 1.1.1 can't be moved or deleted, and a marker can't land on another ([musical-time.md](musical-time.md)). (S13)
- **R33.** While the set has time-signature changes, the Control Bar's numerator and denominator fields show the signature in force at the play position (the playhead while playing, the insert marker while stopped) and change that signature: the marker in force there takes the new value, as one undo step (Beatlayer's reading of S13). They show an automation LED in their upper left corner while the set has changes. This replaces [control-bar-transport.md](control-bar-transport.md) R7's fields that can't be set over changes. (S13, S14)
- **R34.** Right-clicking a hatched bar opens the fragmentary bar's menu (C-TIME-024). Delete Fragmentary Bar Time deletes the short bar's span from every track as Delete Time does (R15), so the marker after it falls on a bar line; Complete Fragmentary Bar inserts, at the short bar's start, the time it lacks of a whole bar in its signature, on every track as Insert Silence does (R17). Each is one undo step (`Delete Fragmentary Bar Time`, `Complete Fragmentary Bar`, Beatlayer's own names); the first is `destructive`. (S13, S14)
- **R35.** The …Time commands and moves of markers keep fragmentary bars as they fall: Beatlayer never completes or removes one unless a person or agent runs R34's commands. (S13)
- **R36.** These are registered commands an agent reaches: the markers' own `song.set_time_signature_change`, `song.move_time_signature_change` and `song.delete_time_signature_change`; `arrangement.select_time_signature_change` (`read`, view state, reported by `arrangement.state`); `arrangement.delete_fragmentary_bar_time` (`destructive`) and `arrangement.complete_fragmentary_bar` (`edit`), which take the short bar's position and read back by the query tool's song (`settings.time_signatures`) and tracks. (S11)
- **R37.** Separate Stems to New Audio Tracks (C-TIME-028) follows Crop Clip in the time selection's menu on a selection holding audio on audio tracks ([stem separation](stem-separation.md) R22, R25). (Beatlayer's own place)
