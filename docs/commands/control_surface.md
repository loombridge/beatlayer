## Commands

### `control_surface.dump`

**Dump Control Surface Setup**. Permission: `external`. Contexts: `global`.

Sends a row's surface's setup to the row's output, as the row's Dump button does. It works while the surface declares a setup to send and the output is present (`can_dump` in `control_surface.list`), and fails otherwise. Changes nothing in the set. Sends messages to a device outside Beatlayer.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `row` | integer from 0 to 255 | yes | The row, from 1 to 6. |

Result: [`DumpResult`](README.md#dumpresult).

### `control_surface.list`

**List Control Surfaces**. Permission: `read`. Contexts: `global`.

Lists the six rows of the Control Surfaces table (Settings, Tempo & MIDI): each row's surface by ID and name, its input and output by name with whether each is present, whether the surface runs, waits for a port to appear or is stopped with an error (`state` and `error`), whether Dump is enabled, and, for a running surface, what it reports of itself: its ring and its own mode. Changes nothing.

Default keys: none.

Arguments: none (send `{}`).

Result: [`ListResult`](README.md#listresult).

### `control_surface.set`

**Set Control Surface**. Permission: `external`. Contexts: `global`.

Sets a row of the Control Surfaces table, as its choosers do: the surface by ID (`control_surface.surfaces`), the input and the output by name (`midi.ports`), any of them; `null` is None, and what is left out stays. A port a row names is open while the row names it, whatever its Track, Sync and Remote switches say, and a port serves one row: naming one another row uses is refused, naming that row. A port that isn't present is kept by name and the surface starts when it appears. The surface starts when its row has it and its input is present, and its output where it needs one; it stops, sending the controller its goodbye, when the row changes, its input goes away or Beatlayer quits. Choosing a surface again restarts one that stopped with an error. The rows are kept for the next start, and are not part of the set or an undo step. Opens and closes devices outside Beatlayer and sends them messages.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `row` | integer from 0 to 255 | yes | The row, from 1 to 6. |
| `input` | string or null | no | The input's name from `midi.ports`, or `null` for None. A port that isn't present is kept by name. Left out, it stays as it is. |
| `output` | string or null | no | The output's name, or `null` for None. Left out, it stays as it is. |
| `surface` | string or null | no | The surface's ID from `control_surface.surfaces`, or `null` for None. Left out, it stays as it is; given again, a surface that stopped with an error starts again. |

Result: [`RowInfo`](README.md#rowinfo).

### `control_surface.surfaces`

**Control Surfaces**. Permission: `read`. Contexts: `global`.

Lists every control surface the table's chooser offers, with the ID `control_surface.set` takes, whether it needs an output, whether a device can be locked to it, the size of its ring and whether it has a setup for Dump. Changes nothing.

Default keys: none.

Arguments: none (send `{}`).

Result: [`SurfacesResult`](README.md#surfacesresult).
