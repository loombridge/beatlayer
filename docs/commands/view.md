## Commands

### `view.clip_envelope`

**Clip View Envelope**. Permission: `read`. Contexts: `clip-view`, `envelope`.

Chooses the parameter whose envelope the Clip View's Envelopes tab shows and edits, as its device and control choosers do: `target` is a control of the shown clip's track's mixer, one of its sends, or a parameter of a device in its chain, named as `clip.set_envelope_breakpoint` names it; `null` shows none. Changes only the view, so it's no undo step. Editing the envelope is done by the `clip.*envelope*` commands. The result says which parameter shows.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `target` | [`AutomationTarget`](README.md#automationtarget) or null | no | The parameter of the shown clip's track whose envelope the Envelopes tab shows, or `null` to show none. |

Result: [`ClipViewState`](README.md#clipviewstate).

### `view.clip_tab`

**Clip View Tab**. Permission: `read`. Contexts: `clip-view`, `note-editor`, `sample-editor`, `envelope`.

Chooses the tab the Clip View shows for its clip: `notes` (the MIDI Note Editor, Option+Shift+1), `envelopes` (the clip's envelopes, Option+Shift+2) or `mpe` (the Expression Editor, for a MIDI clip only, Option+Shift+3). Left out, `tab` goes on to the next tab and round to the first after the last (Option+Tab). The Clip View shows the clip most recently selected, in the Arrangement or in a Session slot. Changes only the view, so it's no undo step and isn't saved with the set. The result says which tab shows.

Default keys:

| Shortcut | macOS | Windows | Context | Action in the reference | Binding |
|---|---|---|---|---|---|
| S-CLIPMODE-001 | `Option+Tab` | `Ctrl+Tab` | `sample-editor` | Switch between the Sample and Envelopes tabs | runs it |
| S-CLIPMODE-002 | `Option+Tab` | `Ctrl+Tab` | `clip-view` | Cycle the Notes, Envelopes and MPE tabs | runs it |
| S-CLIPMODE-003 | `Option+Shift+1` | `Alt+Shift+1` | `clip-view` | Show the Content Editor (the Sample or Notes tab) | fixes `tab` = `"notes"` |
| S-CLIPMODE-004 | `Option+Shift+2` | `Alt+Shift+2` | `clip-view` | Show the Envelope Editor (the Envelopes tab) | fixes `tab` = `"envelopes"` |
| S-CLIPMODE-005 | `Option+Shift+3` | `Alt+Shift+3` | `clip-view` | Show the Expression Editor (the MPE tab) | fixes `tab` = `"mpe"` |

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `tab` | [`ClipTab`](README.md#cliptab) or null | no | The tab to show. Left out, the Clip View goes on to the next one. |

Result: [`ClipViewState`](README.md#clipviewstate).

### `view.close_plug_in_windows`

**Close All Plug-in Windows**. Permission: `read`. Contexts: `global`.

Closes every open plug-in editor window at once, as View ▸ Close All Plug-in Windows does. It closes editors only: floating native device windows stay as they are, so it changes nothing in the set, isn't an undo step, and is in the read class. It has no key. Returns how many editor windows it closed.

Default keys: none.

Arguments: none (send `{}`).

Result: [`ClosedPlugInWindows`](README.md#closedpluginwindows).

### `view.draw_mode`

**Draw Mode**. Permission: `read`. Contexts: `global`.

Switches Draw Mode (B; Options ▸ Draw Mode), which changes what a click in the MIDI Note Editor's note area does: with it on, clicking empty grid adds a note one grid step long, and clicking a note removes it; with it off, clicking selects. Changes nothing in the set and isn't an undo step. The result says whether it's on.

Default keys:

### `view.fold_notes`

**Fold to Notes**. Permission: `read`. Contexts: `clip-view`, `note-editor`.

Folds or unfolds the MIDI Note Editor (F, View ▸ Fold to Notes): while it's folded, the editor shows only the key rows that hold notes, one under the next, and not the empty rows between them. `clip` names the clip; left out, the one the editor shows. `folded` says which way; left out, it switches. Folding changes nothing in the set and isn't an undo step: it's saved with the set beside the song, so it's there again when the set is reopened. The result says whether the editor is folded now.

| `folded` | boolean or null | no | Fold (true) or unfold (false); switches if left out. |

Result: [`ClipViewState`](README.md#clipviewstate).

### `view.fold_scale`

**Fold to Scale**. Permission: `read`. Contexts: `clip-view`, `note-editor`.

Folds or unfolds the MIDI Note Editor to the clip's scale (G, View ▸ Fold to Scale, the toolbar's Scale button): while it's folded, the editor shows only the key rows of the clip's scale and the rows that hold notes, one under the next. With Fold to Notes on too, a row shows only if each fold that is on shows it. It works only while the clip's Scale Mode is on, and turning Scale Mode off shows every row until it is on again. `clip` names the clip; left out, the one the editor shows. `folded` says which way; left out, it switches. Folding changes nothing in the set and isn't an undo step: it's saved with the set beside the song. The result lists the clips folded to their scale in `scale_folds`.

### `view.lane`

**Note Editor Lane**. Permission: `read`. Contexts: `clip-view`, `note-editor`.

### `view.lanes`

**Expression Lanes**. Permission: `read`. Contexts: `clip-view`, `note-editor`.

Shows, hides and swaps the MIDI Note Editor's expression lanes (`velocity`, `chance`, `release_velocity`, always in that order from the top), and holds Randomize's amounts. With `lane`: `show` shows or hides it as the Lane Selector does (left out, it switches), `swap` hides it and shows in its place the first hidden lane after it, going round to the first (Swap Lane in the lane header's menu), and `amount` sets its Randomize amount, 0 to 127, or 0 to 100 (a percentage) for `chance`. `all` is the Show/Hide All Expression Editors switch: `false` hides every lane and `true` shows them again as they were. A new editor shows the Velocity lane alone, with every amount 0. Changes only the view, so it's no undo step and isn't saved with the set. The result is the Clip View's state, which lists the lanes shown.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `all` | boolean or null | no | The Show/Hide All Expression Editors switch: `false` hides every lane and `true` shows them again as they were; left out, nothing changes. |
| `amount` | integer or null | no | With `lane`: set its Randomize amount, 0 to 127, or 0 to 100 (a percentage) for `chance`. |
| `lane` | [`NoteField`](README.md#notefield) or null | no | The lane the other fields but `all` act on: `velocity`, `chance` or `release_velocity` (`velocity_deviation` is the Velocity lane). |
| `show` | boolean or null | no | With `lane`: show it (`true`) or hide it (`false`); left out, the Lane Selector's choice, which switches it. Showing a lane makes it the active lane. |
| `swap` | boolean or null | no | With `lane`: hide it and show in its place the first hidden lane after it, going round to the first (the lane header's Swap Lane). |

Result: [`ClipViewState`](README.md#clipviewstate).

### `view.mpe_grid`

**MPE Grid**. Permission: `read`. Contexts: `note-editor`.

Switches the MPE tab's own grid for a clip (Cmd+4, Ctrl+4 on Windows, while the tab has the focus). With it on, a breakpoint or segment being moved snaps to its neighbours' positions, and a new breakpoint near a grid line lands on the line. It is off in a new clip, saved with the set, and neither the Arrangement's grid nor an undo step. The result is the Clip View's state, whose `mpe.grid` says whether it is on.

| `on` | boolean or null | no | Switch the grid on or off; left out, it switches. |

Result: [`ClipViewState`](README.md#clipviewstate).

### `view.mpe_lanes`

**MPE Lanes**. Permission: `read`. Contexts: `clip-view`, `note-editor`.

Shows, hides, swaps and resizes the lanes of the Clip View's MPE tab (`slide`, `pressure`, `velocity`, `release_velocity`, always in that order from the top, with `pitch_bend` first on a track whose instrument is a Drum Rack). With `lane`: `show` switches its selector toggle (left out, it switches), `swap` switches it off and the first lane after it that is off on, and `height` sets its height in points. `visible` is the triangle: `false` hides the lanes and their toggles, `true` shows them again; `all` switches every toggle on and shows the lanes, as the triangle does with Option held or with every toggle off. A new set shows Slide and Pressure. Changes only the view: no undo step, and it is saved with the set. The result is the Clip View's state, whose `mpe` lists the lanes.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `all` | boolean or null | no | `true` switches every toggle on and shows the lanes, as the triangle clicked with Option does. |
| `height` | number or null | no | With `lane`: its height in points, 8 to 400. |
| `lane` | [`MpeLane`](README.md#mpelane) or null | no | The lane the `show`, `swap` and `height` fields act on: `slide`, `pressure`, `velocity` or `release_velocity`; `pitch_bend` too for `height`. |
| `show` | boolean or null | no | With `lane`: switch its toggle on (`true`) or off (`false`); left out, it switches. |
| `swap` | boolean or null | no | With `lane`: switch it off and the first lane after it that is off on, going round (the lane header's swap). |
| `visible` | boolean or null | no | The triangle: `false` hides the lanes and their toggles, `true` shows them again. Left out, nothing changes. |

Result: [`ClipViewState`](README.md#clipviewstate).

### `view.note_spelling`

**Note Spelling**. Permission: `edit`. Contexts: `global`, `clip-view`, `note-editor`.

Chooses how the note editor spells keys (the piano ruler's context menu): `sharps`, `flats`, `sharps_and_flats`, `auto` (flats when the clip's scale has a root of F, B♭, E♭, A♭, D♭ or G♭) or `note_numbers`. A seven-note scale that is on spells its own keys with one letter a degree, and the choice names the keys outside it. The rows, the Root Note choosers follow the choice. It is one choice for every editor, sharps in a new install and kept between launches as a preference; it isn't part of the set and is never an undo step. The result reads it in `note_spelling`.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `spelling` | [`NoteSpelling`](README.md#notespelling) | yes | How the note editor spells keys. |

Result: [`ClipViewState`](README.md#clipviewstate).

### `view.set_zoom`

**Zoom**. Permission: `edit`. Contexts: `global`, `settings`.

Sets the interface zoom to `percent`, a whole percentage from 50 to 200, as the Zoom setting on the Settings window's Display & Input page does: every window's panes, controls, and text scale together and keep their places, and the main window grows if it's smaller than its minimum size at that zoom (as far as the screen allows). The result's `zoom` is the new zoom as a factor, 1.5 for 150%. The zoom is kept for the next start. Changes nothing in the set and isn't an undo step. With the second window open it acts on the window `window` names, `main` or `second`, and on the window with the focus without it.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `percent` | integer from 50 to 200 | yes | The interface zoom as a whole percentage, from 50 to 200; 100 is the size layout.md measures Live at. |
| `window` | [`WindowName`](README.md#windowname) or null | no | The window to zoom, `main` or `second`; `second` while the second window is closed sets the zoom it opens at. Left out, the window with the focus. |

Result: [`ViewResult`](README.md#viewresult).

### `view.state`

**View State**. Permission: `read`. Contexts: `global`.

Reports what the view commands switch: the main view (Arrangement or Session), whether the browser and the Info View show, full-screen mode and the zoom (`view.toggle_session_arrangement`, `view.toggle_browser`, `view.toggle_info_view`, `view.full_screen`, `view.set_zoom`), the Clip View with Draw Mode, the lane, Fold and the selected notes (`view.toggle_clip_view`, `view.draw_mode`, `view.lane`, `view.fold_notes`), the detail area under `detail`: which of the Clip View and the Device View show, the Clip View's height and where the focus is (`view.toggle_clip_view`, `view.toggle_device_view`, `view.show_detail_views`, `view.switch_detail_view`, `view.toggle_detail_area`, `view.expand_clip_view`, `view.set_detail_height`, `focus.clip_view`, `focus.device_view`), the assistant's panel, the Undo History (`view.toggle_undo_history`), the Save History (`view.toggle_save_history`), whether plug-in windows are shown (`view.toggle_plug_in_windows`), the second window under `second_window`: whether it is open, its main view, browser, full-screen mode, zoom, frame and detail area (`view.toggle_second_window`, and the commands above with `window` set to `second`), and `focused_window`, `main` or `second`, the window the commands that act on one window act on without `window`. Changes nothing. The Arrangement's own view is in `arrangement.state`, the Mixer's in `mixer_view.state`, the Session View's in `session.state` and the Device View's in `device_view.state`.

Default keys: none.

Arguments: none (send `{}`).

Result: [`ViewState`](#viewstate).

### `view.switch_detail_view`
