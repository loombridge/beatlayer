## Commands

### `cv.calibrate`

**Calibrate**. Permission: `external`. Contexts: `device-view`.

Calibrates a CV Instrument against the oscillator patched to its Pitch output, whose sound must come back on its Audio From: with Gate high, it writes each whole volt from -2 V to +5 V on Pitch in turn, holds each for 250 ms and measures the returning pitch over the last 150 ms with the Tuner's detector, then fits the octaves the oscillator rises per volt and its frequency at 0 V by least squares on the logarithm of frequency, keeping each step's error so Pitch's law corrects it. The detector reads 41 Hz to 2 kHz, so the steps it cannot read, or that do not rise like an oscillator's, are left out of the fit and the keys beyond them follow the fitted line; three steps are needed. The calibration is stored in the device as one undo step and saves with the set; the result gives the fit, each step's error in cents and the pitch each step gave. It takes about two seconds and notes reaching the device meanwhile are ignored. It is refused while Pitch is No Output, Audio From is No Input or no audio engine runs, and fails, changing nothing, when too few steps give a steady pitch, saying which was the first. Read the result back in the query tool's `device` result, under `cv`.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `device` | [`DeviceId`](README.md#deviceid) or null | no | The CV Instrument. The one selected in the Device View when it is left out. |

Result: [`Calibrated`](README.md#calibrated).

### `cv.clear_calibration`

**Clear Calibration**. Permission: `edit`. Contexts: `device-view`.

Takes a CV Instrument's calibration away, so Pitch writes one volt to the octave from key 60 at 0 V again. One undo step; it does nothing to a device that holds none.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `device` | [`DeviceId`](README.md#deviceid) or null | no | The CV Instrument. The one selected in the Device View when it is left out. |

Result: [`CalibrationCleared`](README.md#calibrationcleared).

### `cv.set_calibration`

**Set CV Calibration**. Permission: `edit`. Contexts: `device-view`.

Stores a calibration in a CV Instrument, or takes it away with a null `calibration`: the line fitted to the oscillator patched to Pitch (`octaves_per_volt`, `hz_at_zero_volts`) and the `steps` it was fitted to, each a `volts`, the `hz` measured and its `error_cents`, which Pitch's law corrects. `cv.calibrate` measures and stores one; this command only writes what it is given, and one undo step. Read it back in the query tool's `device` result, under `cv`.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `device` | [`DeviceId`](README.md#deviceid) | yes | The device. |
| `calibration` | [`CvCalibration`](README.md#cvcalibration) or null | no | The calibration, or none to clear it. |

Result: [`ChangeSet`](README.md#changeset).
