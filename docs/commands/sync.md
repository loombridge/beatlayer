## Commands

### `sync.state`

**Sync Status**. Permission: `read`. Contexts: `global`.

Reports the state of MIDI clock: how many output ports have Sync on, whether clock is going out now (the song plays, past any count-in), whether the lower sync lamp beside the Control Bar's tempo is lit, and how many Timing Clocks the audio engine has sent, stamped late and dropped since it started. Changes nothing. Set an output's Sync switch and its options with `midi.set_port`.

Default keys: none.

Arguments: none (send `{}`).

Result: [`SyncState`](#syncstate).
