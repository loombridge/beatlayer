## Commands

### `remote.input`

**Remote Input**. Permission: `edit`. Contexts: `global`.

Applies a MIDI message (`bytes`) or a computer key (`key`, pressed and released unless `pressed` says which) as if it came from the remote input, so a mapping is tried without a controller. A message a mapping takes runs its control's command as a hand move does and never reaches a track; one no mapping takes does nothing here. The effect is the control's own and reads back as the control's command does.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `bytes` | array or null | no | One short MIDI message: a status byte and its data bytes, such as `[176, 20, 64]` for controller 20 at 64 on channel 1. |
| `key` | string or null | no | A computer key, named as the keymap names keys. |
| `pressed` | boolean or null | no | With `key`: true presses it, false releases it. Left out, it is pressed and released. |

Result: [`InputResult`](README.md#inputresult).

### `remote.invert_range`

**Invert Range**. Permission: `edit`. Contexts: `global`.

Swaps the Min and Max of the mapping with `source`, as the Mapping Browser's Invert Range does. One undo step.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `source` | [`RemoteSource`](README.md#remotesource) | yes | The mapping's source. |

Result: [`MappingInfo`](README.md#mappinginfo).

### `remote.map`

**Map**. Permission: `edit`. Contexts: `global`.

Maps a source to a control, as a click on the control in a map mode and a message do. The control must be in the set. A source maps one control and a control has one MIDI mapping and one key mapping: mapping a source that maps another control moves it, and mapping a control that has a mapping of that kind replaces it. Min and Max start at the bottom and top of the control's range, a radio button's first and last options, or for a track activator or a device's on/off switch the controller values 64 and 127; a controller maps in Absolute mode (14-bit for a 14-bit source) unless `mode` says otherwise. `kind` is the control's own except for a device parameter's, which comes from its description. The mapping is saved with the set and the change is one undo step.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `source` | [`RemoteSource`](README.md#remotesource) | yes | Where the messages come from. |
| `target` | [`RemoteTarget`](README.md#remotetarget) | yes | The control they drive. |
| `kind` | [`ControlKind`](README.md#controlkind) or null | no | The control's kind. Left out, the control's own: a device parameter's comes from its description. |
| `max` | number or null | no | The top of the range. Left out, the top of the control's range. |
| `min` | number or null | no | The bottom of the range, in the control's own units. Left out, the bottom of the control's range (R4). |
| `mode` | [`RemoteMode`](README.md#remotemode) or null | no | How a controller is read. Left out: Absolute, or Absolute (14-bit) for a 14-bit source. |

Result: [`MappingInfo`](README.md#mappinginfo).

### `remote.map_mode`

**Map Mode**. Permission: `read`. Contexts: `global`.

Turns MIDI Map Mode (`midi`) or Key Map Mode (`key`) on, or both off, as the Control Bar's switches, Cmd-M and Cmd-K do; with `toggle` a mode that is on already turns off. One map mode is on at a time: turning one on turns the other and any rack's Map mode off. While one is on every mappable control is tinted, a click selects instead of operating, no mapping acts, and the Mapping Browser lists the mode's mappings. View state: it isn't saved with the set and isn't an undo step, and it is off when a set opens. Read back in `remote.state`.

Default keys:

| Shortcut | macOS | Windows | Context | Action in the reference | Binding |
|---|---|---|---|---|---|
| S-MAP-001 | `Cmd+M` | `Ctrl+M` | `global` | Turn MIDI Map Mode on or off | fixes `mode` = `"midi"`; fixes `toggle` = `true` |
| S-MAP-002 | `Cmd+K` | `Ctrl+K` | `global` | Turn Key Map Mode on or off | fixes `mode` = `"key"`; fixes `toggle` = `true` |

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `mode` | [`MapMode`](README.md#mapmode) | yes | The mode to turn on, or `off`. |
| `toggle` | boolean | no | With `midi` or `key`: turn the mode off when it is on already, as the switches and their keys do. |

Result: [`StateResult`](README.md#stateresult).

### `remote.mappings`

**MIDI and Key Mappings**. Permission: `read`. Contexts: `global`.

Lists the set's MIDI and key mappings: each mapping's source (a note, a range of notes with its root, a controller, a 14-bit controller, pitch bend, or a computer key), the control it drives by IDs with its path and name, the control's kind, Min, Max and mode. The other remote commands name a mapping by the source reported here. Changes nothing.

Default keys: none.

Arguments: none (send `{}`).

Result: [`MappingsResult`](README.md#mappingsresult).

### `remote.select`

**Select Control to Map**. Permission: `read`. Contexts: `global`.

Selects the control `target` names, as a click on its overlay does in a map mode, so the next note, controller or pitch bend on the remote input (MIDI Map Mode) or the next key (Key Map Mode) maps to it; with no `target` the selection clears, as Esc does. Needs a map mode on, and the control must be one the mode maps: Key Map Mode takes no continuous control. View state, read back in `remote.state`.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `target` | [`RemoteTarget`](README.md#remotetarget) or null | no | The control to select. Left out, the selection clears. |

Result: [`StateResult`](README.md#stateresult).

### `remote.set_mode`

**Set Mapping Mode**. Permission: `edit`. Contexts: `global`.

Sets how a controller mapping reads its values: `absolute`, `absolute14` for a 14-bit controller, or `relative` with an `encoding` (`signed_bit`, `signed_bit2`, `bin_offset` or `twos_complement`) and whether it is `accelerated`. Only a controller reads relative; a 14-bit controller reads only `absolute14`. One undo step.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `source` | [`RemoteSource`](README.md#remotesource) | yes | The mapping's source, a controller. |
| `mode` | [`RemoteMode`](README.md#remotemode) | yes | How its values are read. |

Result: [`MappingInfo`](README.md#mappinginfo).

### `remote.set_range`

**Set Mapping Range**. Permission: `edit`. Contexts: `global`.

Sets the Min and Max of the mapping with `source`, in the control's own units: a continuous control's value, a radio button's option numbers from 0, or a ranged switch's controller values from 0 to 127. Min above Max turns the control round. One undo step.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `source` | [`RemoteSource`](README.md#remotesource) | yes | The mapping's source. |
| `min` | number | yes | The bottom of the range, in the control's own units. |
| `max` | number | yes | The top of the range. Min above Max is allowed. |

Result: [`MappingInfo`](README.md#mappinginfo).

### `remote.state`

**Remote Control State**. Permission: `read`. Contexts: `global`.

Reports the map mode that is on, the selected control, the mode guessed for the controller being learned, whether an input has its Remote switch on, and the Mapping Browser's rows: the mode's mappings in order of their source. Also the remote input's counts (messages taken, dropped, unmapped, applied and refused, and feedback messages sent to outputs with Remote on), when each of its indicator lamps last lit (the remote pair's two and the key indicators' upper one) and whether each is lit now, and the takeover state of each absolute controller mapping on a continuous control (following, or waiting with the controller's last position). Changes nothing.

Default keys: none.

Arguments: none (send `{}`).

Result: [`StateResult`](README.md#stateresult).

### `remote.targets`

**Mappable Controls**. Permission: `read`. Contexts: `global`.

Lists every control of the set that a map mode maps, so an agent maps controls with `remote.map` without the window: each one's `target` ID (the same ID `remote.mappings` reports), its kind, its path and name, and its range. They are the Session View's slots, scene launch buttons, stop buttons and the relative Session mapping strip, the mixer's controls (a control that shows in several places is listed once), every device's parameters and a rack's macros by their kinds, the Control Bar's controls, the crossfader's three fields, the Clip View's controls and the step buttons. `mode` gives Key Map Mode's list, which has no continuous controls; left out, it is the map mode that is on. Changes nothing.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `mode` | [`MapMode`](README.md#mapmode) or null | no | Whose list: `midi` for MIDI Map Mode's, `key` for Key Map Mode's, which leaves out the continuous controls. Left out, the map mode that is on, or MIDI Map Mode's with none on. |

Result: [`TargetsResult`](README.md#targetsresult).

### `remote.unmap`

**Delete Mapping**. Permission: `edit`. Contexts: `global`.

Deletes a mapping: the one with `source`, or the MIDI or key mapping (`via`) of the control `target`. Deleting nothing is not an error and reports 0. One undo step.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `source` | [`RemoteSource`](README.md#remotesource) or null | no | The mapping's source. |
| `target` | [`RemoteTarget`](README.md#remotetarget) or null | no | The control whose mapping goes. |
| `via` | [`Via`](README.md#via) | no | With `target`: its MIDI mapping or its key mapping. MIDI if left out. |

Result: [`UnmapResult`](README.md#unmapresult).
