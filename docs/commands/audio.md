## Commands

### `audio.configure`

**Configure Audio Device**. Permission: `external`. Contexts: `settings`.

Changes any of the audio driver type, input and output devices, sample rate, buffer size, and output channels, and applies them straight away without a restart. Fields left out keep their values. If the device refuses the new settings, the previous ones are restored and the error is returned. Changing the sample rate can change the device's own setting for other apps too. The settings are kept for the next start.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `buffer_size` | integer or null | no | The buffer size in frames, or 0 for the device's default. |
| `driver` | string or null | no | The driver type: an ID from `audio.devices`, such as `coreaudio`, `wasapi`, `asio`, `jack`, `alsa`, or `null`. Changing it resets the devices to the driver's defaults unless they're given too. |
| `driver_error_compensation_ms` | number or null | no | Driver Error Compensation in milliseconds: kept to two decimals and within -1000 to 1000. A positive value moves new recordings earlier. Changing it doesn't restart the audio stream. |
| `input_device` | string or null | no | The input device: an ID from `audio.devices`, or `none` for no input. |
| `output_channels` | integer or null | no | Output channels to open, or 0 for all the device has. |
| `output_device` | string or null | no | The output device: an ID from `audio.devices`, or `default` for the system's default output device. |
| `sample_rate` | integer or null | no | The sample rate in hertz, or 0 for the device's current rate. |

Result: [`AudioStatus`](#audiostatus).

### `audio.devices`

**List Audio Devices**. Permission: `read`. Contexts: `settings`.

Lists the driver types this computer offers and, for the chosen one, its input and output devices with the sample rates, buffer sizes, and channels each accepts. Changes nothing.

Default keys: none.

Arguments: none (send `{}`).

Result: [`AudioDevices`](#audiodevices).

### `audio.set_test_tone`

**Test Tone**. Permission: `external`. Contexts: `settings`.

Plays or stops the Audio settings' test tone, a sine wave on every output channel for checking that the device works, and sets its level (Tone Volume, -60 to 0 dBFS; -36 on a new install) and frequency (Tone Frequency, 20 Hz to 20 kHz; 440 Hz on a new install). Fields left out keep their values; the level and frequency are kept for the next start. The tone stops when the Settings window closes. Set a low level before switching it on: a loud tone can hurt ears and speakers.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `frequency_hz` | number or null | no | The tone's frequency in hertz, from 20 to 20,000 (Tone Frequency). Values outside the range are brought within it. |
| `on` | boolean or null | no | Whether the test tone plays. |
| `volume_db` | number or null | no | The tone's level in dBFS, from -60 to 0 (Tone Volume). Values outside the range are brought within it. |

Result: [`TestToneState`](README.md#testtonestate).

### `audio.status`

**Audio Status**. Permission: `read`. Contexts: `global`.

Reports whether the audio engine is on, the driver and devices in use, the sample rate and buffer size the device actually runs at, the CPU load of audio processing, and any device error. Changes nothing.

Default keys: none.

Arguments: none (send `{}`).

Result: [`AudioStatus`](#audiostatus).

### `audio.toggle_engine`

**Audio Engine On**. Permission: `external`. Contexts: `global`.

Switches the audio engine off, closing the audio device, or on again, reopening it with the current settings. While it's off, nothing plays and the CPU meter reads OFF.

Default keys:

| Shortcut | macOS | Windows | Context | Action in the reference | Binding |
|---|---|---|---|---|---|
| S-ENGINE-001 | `Cmd+Option+Shift+E` | `Ctrl+Alt+Shift+E` | `global` | Turn the audio engine on or off | runs it |

Arguments: none (send `{}`).

Result: [`SwitchResult`](README.md#switchresult).
