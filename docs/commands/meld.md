## Commands

### `meld.clear_modulation`

**Clear Modulation**. Permission: `edit`. Contexts: `device-view`.

Clears every route of one of Meld's engines, as the X button of its Matrix tab does: `engine` is `A` or `B`. The engine's routes are those into its own destinations and those from its own modulators into a global destination; the shared sources' routes into a global destination stay. Each cleared slot's amount goes back to 0 %. The device is a Meld, by ID or the selected one. One undo step (Clear Modulation); the device's `matrix` reads back the result.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `engine` | string | yes | The engine whose routes to clear, `A` or `B`. |
| `device` | [`DeviceId`](README.md#deviceid) or null | no | The Meld; the selected device if left out. |

Result: [`ModulationCleared`](README.md#modulationcleared).

### `meld.copy_modulation`

**Copy Modulation**. Permission: `edit`. Contexts: `device-view`.

Copies the routes of one of Meld's engines to the other, as the Copy to A and Copy to B buttons of its Matrix tab do: `engine` is `A` to copy engine A's routes to engine B, or `B` to copy B's to A. Each route into one of the engine's own destinations (a global destination, Mixer Drive or Volume, belongs to neither) is written for the other engine's matching destination, from the other engine's matching source, with the same amount; the other engine's routes into those destinations are replaced, and its routes into other destinations stay. The shared sources (Velocity, Pitch and the rest) stay as they are. The device is a Meld, by ID or the selected one. It is refused, changing nothing, when the other engine's routes and the copy would need more than the matrix's sixty-four slots. One undo step (Copy Modulation); the device's `matrix` reads back the result.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `engine` | string | yes | The engine to copy from, `A` or `B`; its routes go to the other. |
| `device` | [`DeviceId`](README.md#deviceid) or null | no | The Meld; the selected device if left out. |

Result: [`ModulationCopied`](README.md#modulationcopied).
