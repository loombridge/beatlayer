## Commands

### `clip_view.focus_mode`

**Focus Mode**. Permission: `read`. Contexts: `note-editor`, `note-selection`.

Switches Focus Mode (N, or the Focus button): a tap switches it, and holding N switches it while it's held. It acts while the note editor shows several clips: with it on, edits, drawing and the filters reach the foreground clip alone, and the others show grey. It is off when the app starts and isn't saved or an undo step. `on` says which way; left out, it switches. The result is the Clip View's state.

Default keys:

| Shortcut | macOS | Windows | Context | Action in the reference | Binding |
|---|---|---|---|---|---|
| S-NOTE-040 | `N` | `N` | `note-editor` | Toggle Focus Mode for multi-clip editing (momentary while held) | runs it |

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `on` | boolean or null | no | Whether Focus Mode ends up on; left out, it switches. |

Result: [`ClipViewState`](README.md#clipviewstate).

### `clip_view.foreground`

**Foreground Clip**. Permission: `read`. Contexts: `note-editor`, `note-selection`.

Makes one of the clips the note editor shows the foreground clip, as clicking its note or its loop bar does: the expression lanes and the footer edit its notes alone, and with Focus Mode on it is the active clip. Changes only the view: it isn't saved with the set and isn't an undo step. The result is the Clip View's state.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `clip` | [`ClipId`](README.md#clipid) | yes | The shown clip to make the foreground clip. |

Result: [`ClipViewState`](README.md#clipviewstate).

### `clip_view.invert_selection`

**Invert Selection**. Permission: `read`. Contexts: `note-editor`, `note-selection`.

Selects every note in the clip's span that was not selected and deselects those that were, as Edit ▸ Invert Selection does (Cmd-Shift-A, Ctrl-Shift-A on Windows). The time selection follows the new selection. It needs a clip that holds notes, is never an undo step, and changes nothing in the set.

### `clip_view.note_filters`

**Note Filters**. Permission: `read`. Contexts: `note-editor`, `note-selection`.

Find and Select Notes. Shows or hides the filter bar (`visible`, or `toggle`, as Cmd-Shift-F does), chooses the filter whose controls it shows (`shown`), and sets the controls and Invert of any filter (`pitch`, `time`, `chance`, `condition`, `count`, `duration`, `scale`, `velocity`). Setting a control, or Invert, switches that filter on, and while any filter is on the selection is the notes in the clip's span that every filter that is on lets through, worked out again each time, with the time selection following it. `select` presses the Select button of each filter it lists: it is switched on and the notes are selected again. `off` switches filters off, keeping their settings; a click in the note area switches all eight off. Time's Start, Length and Repeat are in beats of the clip's time signature, to a hundredth, Start from 1; a Repeat of `null` is one bar. Duration's Min and Max are in beats too, a Max of `null` being the clip's span. Chance is in percent. Moving Min past Max takes Max with it, and the other way round. The settings belong to the editor: they are kept while the app runs, every filter is switched off when the editor shows another clip, and none of it is saved with the set or is an undo step. The result is every filter's settings and the selected notes.

Default keys:

| Shortcut | macOS | Windows | Context | Action in the reference | Binding |
|---|---|---|---|---|---|
| S-NOTE-037 | `Cmd+Shift+F` | `Ctrl+Shift+F` | `note-editor` | Show or hide the note filters | fixes `toggle` = `true` |

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `chance` | [`ChanceArgs`](README.md#chanceargs) or null | no | Chance controls. |
| `clip` | [`ClipId`](README.md#clipid) or null | no | The MIDI clip. Left out, the one the Clip View shows. |
| `condition` | [`ConditionArgs`](README.md#conditionargs) or null | no | Condition controls. |
| `count` | [`CountArgs`](README.md#countargs) or null | no | Count controls. |
| `duration` | [`DurationArgs`](README.md#durationargs) or null | no | Duration controls. |
| `off` | array of [`NoteFilter`](README.md#notefilter) | no | Filters to switch off, keeping their settings. |
| `pitch` | [`PitchArgs`](README.md#pitchargs) or null | no | Pitch controls. |
| `scale` | [`ScaleArgs`](README.md#scaleargs) or null | no | Scale controls. |
| `select` | array of [`NoteFilter`](README.md#notefilter) | no | Filters whose Select button is pressed: each is switched on, and the notes are selected again. |
| `shown` | [`NoteFilter`](README.md#notefilter) or null | no | Chooses the filter whose controls the bar shows. |
| `time` | [`TimeArgs`](README.md#timeargs) or null | no | Time controls. |
| `toggle` | boolean | no | Switches the bar, as Cmd-Shift-F does; `visible` wins if both are given. |
| `velocity` | [`VelocityArgs`](README.md#velocityargs) or null | no | Velocity controls. |
| `visible` | boolean or null | no | Shows or hides the filter bar. |

Result: [`NoteFiltersResult`](README.md#notefiltersresult).

### `clip_view.quantize_settings`

**Quantize Settings**. Permission: `read`. Contexts: `note-editor`, `note-selection`, `sample-editor`.

Reads or changes the Clip View's Quantize settings, the values `note.quantize`, `clip.quantize_audio` and Cmd-U use when their arguments leave them out: `grid`, the spacing between the quantise grid's lines in ticks (positive; left unset, it follows the note or sample editor's editing grid), `target`, whether quantise moves note starts or note ends, and `amount`, how far each note moves toward its grid line as a percentage from 0 to 100. Fields left out keep their values, and the result reports all of them. The settings belong to the view, like Draw Mode: changing them changes nothing in the set and is no undo step.

Default keys:

| Shortcut | macOS | Windows | Context | Action in the reference | Binding |
|---|---|---|---|---|---|
| S-SAMPLE-002 | `Cmd+Shift+U` | `Ctrl+Shift+U` | `sample-editor` | Open the quantise settings | runs it |

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `amount` | integer or null | no | How far each note moves toward its grid line, from 0 to 100 percent. |
| `grid` | [`Ticks`](README.md#ticks) or null | no | The quantise grid's line spacing in ticks; must be positive. A new view follows the Clip View's editing grid until one is set. |
| `target` | [`QuantizeTarget`](README.md#quantizetarget) or null | no | What quantise moves toward the grid. |

Result: [`QuantizeSettings`](README.md#quantizesettings).

### `clip_view.sample_editor`

**Sample Editor State**. Permission: `read`. Contexts: `clip-view`, `sample-editor`.

Reports what the Clip View's Sample Editor shows for the audio clip it shows: whether the clip is warped, the selected warp markers (by their place in the clip's warp map), whether the Start marker is selected, the selected transients (by their times in the file), the insert marker, the time selection, and the span shown. Changes nothing.

Default keys: none.

Arguments: none (send `{}`).

Result: [`SampleEditorState`](README.md#sampleeditorstate).

### `clip_view.sample_view`

**Zoom Sample Editor**. Permission: `read`. Contexts: `clip-view`, `sample-editor`.

Changes the part of the file the Sample Editor shows: `selection` zooms to the time selection (Z, remembering the view before), `back` goes back to the view before the last zoom (X, a step at a time), `whole` fits the whole file across the editor (W), `height` switches fitting the waveform to the editor's height (H), and `span` shows `start` to `end`, in seconds in the file or, with `ticks`, in ticks of a warped clip's contents, and `scroll` does the same without remembering the view before, as dragging the ruler or the wheel does (scrolling pauses Follow until playback starts or stops); `page` is Follow turning the page, which doesn't pause it. Changes only the view.

Default keys:

| Shortcut | macOS | Windows | Context | Action in the reference | Binding |
|---|---|---|---|---|---|
| S-SAMPLE-007 | `Z` | `Z` | `sample-editor` | Zoom to the clip selection | fixes `show` = `"selection"` |
| S-SAMPLE-008 | `X` | `X` | `sample-editor` | Zoom back from the clip selection | fixes `show` = `"back"` |
| S-SAMPLE-013 | `W` | `W` | `sample-editor` | Fit the content to the editor's width | fixes `show` = `"whole"` |
| S-SAMPLE-014 | `H` | `H` | `sample-editor` | Fit the content to the editor's height | fixes `show` = `"height"` |

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `clip` | [`ClipId`](README.md#clipid) or null | no | The audio clip. Left out, the one the Sample Editor shows. |
| `end` | number or null | no | With `span`, where the view ends, after `start`. |
| `show` | [`SampleViewChange`](README.md#sampleviewchange) or null | no | What to change. |
| `start` | number or null | no | With `span`, where the view starts: seconds in the file, or ticks of a warped clip's contents with `ticks`. |
| `ticks` | boolean | no | Whether `start` and `end` are ticks of a warped clip's contents instead of seconds in the file. |

Result: [`SampleEditorState`](README.md#sampleeditorstate).

### `clip_view.select_loop_bars`

**Select Loop Bars**. Permission: `read`. Contexts: `note-editor`, `note-selection`.

Selects the loop bars above the note editor of the given clips, in place of the selected ones, or with `toggle` adds each to the selection or takes it out, as Cmd-click does (Ctrl-click on Windows). The last clip given becomes the foreground clip. With Focus Mode on only one bar can be selected. Changes only the view: it isn't an undo step. The result is the Clip View's state.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `clips` | array of [`ClipId`](README.md#clipid) | no | The clips whose loop bars to select; empty selects none. |
| `toggle` | boolean | no | Add them to the selected bars, or take out those already selected, as Cmd-click does, instead of replacing the selection. |

Result: [`ClipViewState`](README.md#clipviewstate).

### `clip_view.select_notes`

**Select Notes**. Permission: `read`. Contexts: `note-editor`, `note-selection`.

Selects notes in the Clip View's MIDI Note Editor, as clicking a note or dragging a marquee over them does: `replace` selects only these, `toggle` adds or removes each (Cmd-click, Ctrl-click on Windows). Notes are named by their place in the clip's notes in order, by start and then pitch, so place 0 has the earliest start, and of notes that start together the lowest pitch. With no notes named, `select` chooses them instead: `nearest` (the note whose start is nearest the insert marker), `previous` and `next` (the previous or next note in the clip's order), `same_pitch_previous` and `same_pitch_next` (the previous or next note at the selected note's pitch), `all` (every note in the clip's span, as Cmd-A does), or `key` (every note at a pitch, as clicking a key in the piano ruler does). `add` adds to the selection instead of replacing it, as Shift with the note-jump keys does. Selecting is never an undo step and changes nothing in the set.

Default keys:

| Shortcut | macOS | Windows | Context | Action in the reference | Binding |
|---|---|---|---|---|---|
| S-NOTE-001 | `Cmd+A` | `Ctrl+A` | `note-editor` | Select all notes | fixes `select` = `"all"` |
| S-EDIT-009 | `Cmd+A` | `Ctrl+A` | `global` | Select everything in the focused view | fixes `select` = `"all"` |

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `add` | boolean | no | Add to the selection instead of replacing it, as Shift with the note-jump keys does. |
| `clip` | [`ClipId`](README.md#clipid) or null | no | The MIDI clip. Left out, the one the Clip View shows (the Arrangement's selected clip). |
| `clips` | array or null | no | The clips, each with its notes, in place of `clip` and `notes` (Spec: multi-clip-editing R18). Left out with `clip` and `notes`, the selected notes of every clip shown, or of the active clip alone in Focus Mode. |
| `mode` | [`NoteSelectMode`](README.md#noteselectmode) | no | How to change the selection; `replace` if left out. |
| `notes` | array of integer, at least 0 | no | The notes, by their place in the clip's notes in order (by start, then pitch). Empty with `replace` clears the selection, and empty with `select` chooses the notes `select` names. |
| `select` | [`NoteSelection`](README.md#noteselection) or null | no | What to select when `notes` is empty: the notes the keyboard reaches (Option with the arrows), every note in the clip's span (Cmd-A), or the notes at a pitch (a key in the piano ruler). |

Result: [`ClipViewState`](README.md#clipviewstate).

### `clip_view.select_time`

**Select Time**. Permission: `read`. Contexts: `clip-view`, `sample-editor`, `note-editor`, `note-selection`.

Makes a time selection in the editor from `start` to `end`, in seconds in the file or, with `ticks`, in ticks of a warped clip's contents; with neither the selection is cleared. Dragging across the waveform runs this. In the MIDI Note Editor `start` and `end` are ticks of the clip's contents, and the selection is drawn across the note area and the lanes. Never an undo step, and changes nothing in the set.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `clip` | [`ClipId`](README.md#clipid) or null | no | The audio clip. Left out, the one the Sample Editor shows. |
| `end` | number or null | no | Where the selection ends, after `start`. |
| `start` | number or null | no | Where the selection starts. Give neither `start` nor `end` to clear the selection. |
| `ticks` | boolean | no | Whether `start` and `end` are ticks of a warped clip's contents instead of seconds in the file. |

Result: [`SampleEditorState`](README.md#sampleeditorstate).

### `clip_view.select_transients`

**Select Transients**. Permission: `read`. Contexts: `clip-view`, `sample-editor`.

Selects transients of an audio clip in the Sample Editor, as clicking a transient's pseudo-warp marker does: `replace` selects only these, `toggle` adds or removes each. A transient is named by its time in the file in seconds, as `clip.transients` lists it. Delete Transient acts on the selected transients. Selecting is never an undo step and changes nothing in the set.

| `mode` | [`NoteSelectMode`](README.md#noteselectmode) | no | How to change the selection; `replace` if left out. |

Result: [`SampleEditorState`](README.md#sampleeditorstate).

### `clip_view.select_warp_markers`

**Select Warp Markers**. Permission: `read`. Contexts: `clip-view`, `sample-editor`.

Selects warp markers of an audio clip in the Sample Editor, as clicking one does: `replace` selects only these, `toggle` adds or removes each (Cmd-click, Ctrl-click on Windows). A marker is named by its place in the clip's warp map (`data.audio.warp_markers`), the first being 0. With `start_marker` the clip's Start marker is selected too. The marker edits (`clip.move_warp_markers`, `clip.delete_warp_markers`) take their markers by place and act on these when the app runs them from a key. Selecting is never an undo step and changes nothing in the set.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `markers` | array of integer, at least 0 | yes | The markers, by their place in the clip's warp map, the first being 0. Empty with `replace` clears the selection. |
| `clip` | [`ClipId`](README.md#clipid) or null | no | The audio clip. Left out, the one the Sample Editor shows. |
| `mode` | [`NoteSelectMode`](README.md#noteselectmode) | no | How to change the selection; `replace` if left out. |
| `start_marker` | boolean | no | Whether the clip's Start marker is selected too, as clicking it in the marker strip does; Shift with the arrow keys then moves the clip's region with it. With `toggle` it switches the Start marker's selection. Not selected if left out. |

Result: [`SampleEditorState`](README.md#sampleeditorstate).

### `clip_view.set_insert_marker`

**Set Insert Marker**. Permission: `read`. Contexts: `clip-view`, `sample-editor`, `note-editor`, `note-selection`.

Puts the editor's insert marker, the point the editor's commands act at, at a `time` in the file in seconds or at a `beat` of a warped clip's contents in ticks from its 1.1.1; with neither it is taken away. Clicking the waveform runs this, on the nearest grid line while snapping is on. In the MIDI Note Editor the marker is a `beat` of the clip's contents in ticks from their beginning, and it stays inside the clip's span. Never an undo step, and changes nothing in the set.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `beat` | [`Ticks`](README.md#ticks) or null | no | Where to put the marker, as a beat of a warped clip's contents in ticks from its 1.1.1. |
| `clip` | [`ClipId`](README.md#clipid) or null | no | The audio clip. Left out, the one the Sample Editor shows. |
| `time` | number or null | no | Where to put the marker, as a time in the file in seconds. Give this or `beat`; give neither to take the marker away. |

Result: [`SampleEditorState`](README.md#sampleeditorstate).

### `clip_view.set_preview`

**MIDI Note Editor Preview**. Permission: `edit`. Contexts: `global`, `clip-view`, `note-editor`, `note-selection`.

Sets the MIDI Note Editor's Preview switch (`on`), the one above the piano ruler and Options ▸ MIDI Note Editor Preview: with it on, clicking a key, drawing, clicking and keyboard-selecting a note, and dragging notes to a new pitch play into the clip's track, and an armed track can be step-recorded. Left out, `on` flips the switch. It is one switch for every MIDI clip, off in a new install and kept between launches as a preference; it is never an undo step and changes nothing in the set. Switching it off ends the previews sounding.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `on` | boolean or null | no | Whether Preview is on. Left out, the switch flips. |

Result: [`ClipViewState`](README.md#clipviewstate).

### `clip_view.step_input_mode`

**Step Input Mode**. Permission: `edit`. Contexts: `global`, `clip-view`, `note-editor`, `note-selection`.

Gets the editor ready for step recording: arms the track of the clip the Clip View shows (as the track's arm button does), moves the keyboard focus to the Clip View, and switches the computer MIDI keyboard to the other state. It is a command, not a switch, and is available while the editor shows a MIDI clip. Arming is an undo step, as arming is.

Default keys:

| Shortcut | macOS | Windows | Context | Action in the reference | Binding |
|---|---|---|---|---|---|
| S-NOTE-044 | `Cmd+Shift+B` | `Ctrl+Shift+B` | `note-editor` | Turn Step Input Mode on or off | runs it |

Arguments: none (send `{}`).

Result: [`ClipViewState`](README.md#clipviewstate).
