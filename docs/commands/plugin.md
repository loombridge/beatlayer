## Commands

### `plugin.configure`

**Configure Plug-In**. Permission: `edit`. Contexts: `device-view`.

Opens or closes a plug-in device's Plug-In Configure Mode (manual 24.1.2): while it is on, a parameter moved in the plug-in's own window joins the device's list of configured parameters, the ones its panel knobs and the automation and clip-envelope choosers show. `on` sets it, or switches it if left out. Configure mode itself is view state: it isn't an undo step and isn't saved with the set (the list is). Returns the Device View's state.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `device` | [`DeviceId`](README.md#deviceid) or null | no | The device; the selected one if left out. |
| `on` | boolean or null | no | Turn configure mode on (true) or off (false); switches if left out. |

Result: [`DeviceViewState`](README.md#deviceviewstate).

### `plugin.configure_param`

**Configure Plug-In Parameter**. Permission: `edit`. Contexts: `device-view`.

Adds one of a plug-in's parameters to the device's list of configured parameters, the ones its panel knobs and the automation and clip-envelope choosers show (manual 24.1.2). `index` places it in the list, or the end if left out; one already in the list moves there. One undo step, and the list is saved with the set. Returns `device.parameters`, each marked configured or not.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `param` | [`ParamId`](README.md#paramid) | yes | The parameter to add. |
| `device` | [`DeviceId`](README.md#deviceid) or null | no | The device; the selected one if left out. |
| `index` | integer or null | no | Where it goes in the list; at the end if left out. |

Result: [`DeviceParameters`](README.md#deviceparameters).

### `plugin.export_list`

**Export the Set's Plug-In List**. Permission: `external`. Contexts: `global`.

Writes the set's plug-in list to a text file, as the list's Export… button does: the set's name and the date, a header line, and one line per plug-in with its name, format, vendor, version, preset names, tracks, and `Missing` where this computer doesn't have it, separated by tabs. `path` is the file to write it to; left out, the app asks where to save it. The file is written outside the set, so an agent asks first. Returns the file written.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `path` | string or null | no | The file to write the list to. Left out, the app asks where to save it, as the list's Export… button does. |

Result: [`ExportedList`](README.md#exportedlist).

### `plugin.info`

**Plug-In Info**. Permission: `read`. Contexts: `device-view`.

Reports what a plug-in device's plug-in is doing: its ID and file, whether it's running, the latency it reports in frames, what went wrong if anything, whether its editor window can open, is open, and is shown (a hidden window stays open), and its parameters' values as it reports them. Changes nothing.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `device` | [`DeviceId`](README.md#deviceid) or null | no | The device; the selected one if left out. |

Result: [`PluginInfo`](#plugininfo).

### `plugin.list`

**List Plug-Ins in the Set**. Permission: `read`. Contexts: `global`.

Lists every plug-in the set uses, grouped by plug-in: its format, its identifier, name, the file the set says it came from, its vendor and version when the scanner knows them, the devices and tracks that use it, the preset names its devices hold, and whether this machine has it (missing when the scanner hasn't seen it, or says why it is blocklisted). Changes nothing.

Default keys: none.

Arguments: none (send `{}`).

Result: [`SetPluginList`](README.md#setpluginlist).

### `plugin.load`

**Load Plug-In**. Permission: `external`. Contexts: `global`, `device-view`.

Loads a plug-in from its file or bundle (`path`: a `.clap` file, or a `.vst3` bundle or module) and adds it as a device, as `device.add` adds one: to the selected track (or `track`), at `index` or where its role goes, selected, one undo step (Insert Device). `plugin` picks one of the file's plug-ins by its ID (CLAP's, or a VST3 class ID); the first if left out. Its parameters become the device's, which `device.parameters` lists and `device.set_param` and automation change. The plug-in's code runs inside Beatlayer, so load only plug-ins you trust. The scanner (`plugin.scan`) lists the plug-ins on this machine; this command still loads one by its path.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `path` | string | yes | The plug-in's file or bundle (`.clap`, or `.vst3` for VST3). |
| `index` | integer or null | no | Where it goes in the chain; as `device.add` places it if left out. |
| `plugin` | string or null | no | Which of the file's plug-ins, by its ID; the first if left out. |
| `track` | [`TrackId`](README.md#trackid) or null | no | The track; the selected track if left out. |

Result: [`PluginLoaded`](README.md#pluginloaded).

### `plugin.load_au`

**Load Audio Unit**. Permission: `external`. Contexts: `global`, `device-view`.

Loads the Audio Unit with the given component description — its `type`, `subtype`, and `manufacturer`, four characters each, such as Apple's `aufx`, `dely`, `appl` for AUDelay — and adds it as a device, as `device.add` adds one: to the selected track (or `track`), at `index` or where its role goes, selected, one undo step (Insert Device). Its parameters become the device's, which `device.parameters` lists and `device.set_param` and automation change; its own state is saved with the set. Audio Units are macOS only: on Windows and Linux this fails with that reason. Its own editor window opens from `plugin.show_window`, as a CLAP plug-in's does, and a change made in it is one undo step. The unit's code runs inside Beatlayer, so load only units you trust.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `type` | string | yes | The component's type, four characters: `aufx` for an effect, `aumu` or `augn` for an instrument, `aumi` for a MIDI effect. |
| `subtype` | string | yes | The component's subtype, four characters, such as `dely` for Apple's AUDelay. |
| `manufacturer` | string | yes | The component's manufacturer, four characters, such as `appl` for Apple's units. |
| `index` | integer or null | no | Where it goes in the chain; as `device.add` places it if left out. |
| `track` | [`TrackId`](README.md#trackid) or null | no | The track; the selected track if left out. |

Result: [`PluginLoaded`](README.md#pluginloaded).

### `plugin.move_configured_param`

**Move Plug-In Parameter**. Permission: `edit`. Contexts: `device-view`.

Moves one entry of a plug-in device's configured list from `from` to `to` (manual 24.1.2), the order its panel knobs and the choosers show. One undo step. Returns `device.parameters`, each marked configured or not.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `from` | integer, at least 0 | yes | Where the parameter is now, 0 for the first. |
| `to` | integer, at least 0 | yes | Where it goes, 0 for the first. |
| `device` | [`DeviceId`](README.md#deviceid) or null | no | The device; the selected one if left out. |

Result: [`DeviceParameters`](README.md#deviceparameters).

### `plugin.rescan`

**Rescan Plug-Ins**. Permission: `external`. Contexts: `global`, `device-view`.

Scans the plug-ins in `paths` (or each format's system plug-in folders) again, ignoring the cache and clearing the blocklist for them, as the Rescan button does. Returns `plugin.scan`'s report; with `background`, returns at once and the browser lists what was found when the scan is done.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `background` | boolean | no | Scan the system folders in the background and return at once, with an empty report, as the Settings window's Rescan button does; the browser lists what was found when it's done. |
| `paths` | array or null | no | The files or folders to scan; each format's system plug-in folders if left out. |

Result: [`PluginScan`](#pluginscan).

### `plugin.scan`

**Scan Plug-Ins**. Permission: `external`. Contexts: `global`, `device-view`.

Finds the plug-ins installed on this machine and describes each one: its format, its file, its identifier, name, vendor, version, and role in a chain. Scans the files or folders in `paths` for every hosted format, or, when `paths` is left out, the system plug-in folders of CLAP and of the formats the Plug-Ins settings switch on (`plugin.settings`: `vst3_system_folders`, and on macOS `use_audio_units_v2`). The app also runs this at start, in the background, and when one of those switches turns on. Each one is loaded in a separate process with a timeout, so a plug-in that crashes or hangs is put on a blocklist with the reason instead of taking Beatlayer down; a file whose size and modification time are unchanged is answered from the cache. Reads plug-in files outside the project, so an agent asks first.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `background` | boolean | no | Scan the system folders in the background and return at once, with an empty report, as the Settings window's Rescan button does; the browser lists what was found when it's done. |
| `paths` | array or null | no | The files or folders to scan; each format's system plug-in folders if left out. |

Result: [`PluginScan`](#pluginscan).

### `plugin.set_mpe`

**Set MPE Mode**. Permission: `edit`. Contexts: `device-view`.

Switches a plug-in device's MPE Mode, the item of its title bar menu (`on`). On, the plug-in gets each note's pitch, slide and pressure as its format takes them: CLAP note expressions, VST3 note expression, or MPE MIDI (an Audio Unit gets MPE MIDI, each note on a channel of its own in the zone the MPE/Multi-channel Settings name). Off, it gets only each note's pressure, as polyphonic key pressure. Off in a new device; saved with the set, the device's presets and its default preset. One undo step (Change MPE Mode). `plugin.info` reports it. A device that isn't a plug-in has no MPE Mode.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `device` | [`DeviceId`](README.md#deviceid) | yes | The device, which must be a plug-in. |
| `on` | boolean | yes | Whether MPE Mode is on. |

Result: [`ChangeSet`](README.md#changeset).

### `plugin.set_mpe_settings`

**Set MPE/Multi-channel Settings**. Permission: `edit`. Contexts: `device-view`.

Sets the MPE/Multi-channel Settings of a plug-in device, the dialog its title bar menu opens: `settings` gives the `mode` (`zone` or `multi_channel`); for a zone its `zone` (`lower`, master channel 1, or `upper`, master channel 16) and `channels` (its note channels, 1 to 15); for multi-channel mode the `first` and `last` channel, 1 to 16. What it leaves out takes the new settings' value: the lower zone with 15 note channels. They shape only the MPE MIDI the device is sent. One undo step (Change MPE Settings); saved with the device; `plugin.info` reports them.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `device` | [`DeviceId`](README.md#deviceid) | yes | The device, which must be a plug-in. |
| `settings` | [`MpeSettings`](README.md#mpesettings) | yes | The settings. |

Result: [`ChangeSet`](README.md#changeset).

### `plugin.set_panel_param`

**Set Plug-In Panel Parameter**. Permission: `edit`. Contexts: `device-view`.

Sets which of a plug-in device's own parameters a panel knob shows (D19): `index` is the knob, 0 for the first and up to seven, and `param` the parameter, or null to restore the knob to the plug-in's parameter at that place. The mapping is remembered per plug-in, so another device of the same plug-in keeps it, and it changes only the view: it isn't an undo step. Returns the Device View's state.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `index` | integer, at least 0 | yes | The knob, 0 for the first (leftmost) and up to [`PANEL_KNOBS`] − 1. |
| `device` | [`DeviceId`](README.md#deviceid) or null | no | The device; the selected one if left out. |
| `param` | [`ParamId`](README.md#paramid) or null | no | The parameter it shows, from the plug-in's own; `null` restores the knob to the plug-in's parameter at that place. |

Result: [`DeviceViewState`](README.md#deviceviewstate).

### `plugin.set_window`

**Set Plug-In Window Place**. Permission: `read`. Contexts: `device-view`.

Records where a plug-in device's editor window sits and how big it is, in points (`frame`): its place is saved with the set beside the document, so moving or resizing a window is never an undo step. A plug-in window reopens where it was left. Returns `plugin.info`'s report.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `frame` | [`WindowFrame`](README.md#windowframe) | yes | Where its window sits and how big it is, in points. |
| `device` | [`DeviceId`](README.md#deviceid) or null | no | The device; the selected one if left out. |

Result: [`PluginInfo`](#plugininfo).

### `plugin.settings`

**Plug-In Settings**. Permission: `edit`. Contexts: `global`.

Reads or changes how the browser shows plug-ins (IMP-07): `hidden` is the plug-ins to hide, as `format/plugin_id` keys; `show_hidden` whether hidden plug-ins still show; and `format_preference` the format to prefer when a plug-in exists in several. Also the Plug-In Sources switches of Settings ▸ Plug-Ins: `use_audio_units_v2`, `use_audio_units_v3` and `vst3_system_folders`, all off in a new install; the browser lists a format's plug-ins only while its switch is on (CLAP has none and is always listed), and turning one on scans that format in the background. Fields left out are unchanged. Returns the settings. A set that uses a hidden plug-in still loads it.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `format_preference` | [`PluginFormat`](README.md#pluginformat) or null | no | The format to prefer when a plug-in exists in several. |
| `hidden` | array or null | no | The hidden plug-ins to remember, as `format/plugin_id` keys (IMP-07); empty hides none. |
| `show_hidden` | boolean or null | no | Whether the browser shows hidden plug-ins. |
| `use_audio_units_v2` | boolean or null | no | Use Audio Units v2 (Settings ▸ Plug-Ins): scan and list Audio Units on macOS. Turning it on scans them. |
| `use_audio_units_v3` | boolean or null | no | Use Audio Units v3 (Settings ▸ Plug-Ins). Kept; app-extension Audio Units aren't scanned yet. |
| `vst3_system_folders` | boolean or null | no | Use VST3 Plug-In System Folders (Settings ▸ Plug-Ins): scan and list the VST3 plug-ins in the format's system folders. Turning it on scans them. |

Result: [`PluginSettings`](#pluginsettings).

### `plugin.show_mpe_settings`

**MPE Settings…**. Permission: `read`. Contexts: `global`, `device-view`.

Opens or closes the MPE/Multi-channel Settings dialog, from a plug-in's title bar menu, or from MIDI To once MPE is its channel: give a plug-in or External Instrument `device`, or a MIDI `track` whose MIDI To is a port set to MPE. Opens unless `shown` says which. The dialog's controls run `plugin.set_mpe_settings`, `routing.set_midi_output` and `device.set_external`. It changes only the view: it isn't an undo step. Returns the dialog's state.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `device` | [`DeviceId`](README.md#deviceid) or null | no | The plug-in or External Instrument device; the selected device if neither this nor `track` is given. |
| `shown` | boolean or null | no | Open (true) or close (false) the dialog; opens if left out. |
| `track` | [`TrackId`](README.md#trackid) or null | no | A MIDI track, for its MIDI To. |

Result: [`MpeSettingsDialog`](README.md#mpesettingsdialog).

### `plugin.show_window`

**Show Plug-In Window**. Permission: `read`. Contexts: `device-view`.

Opens or closes a plug-in device's editor, as the device's title bar button does; switches unless `shown` says which. On Windows and Linux the editor opens in a window Beatlayer owns, with the plug-in's own view embedded into it; on macOS, and for a plug-in that won't embed, in a floating window of the plug-in's own. An open window follows View ▸ Plug-In Windows and Auto-Hide Plug-In Windows, which hide and show it without closing it. It changes only the view: it isn't an undo step. Returns `plugin.info`'s report.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `device` | [`DeviceId`](README.md#deviceid) or null | no | The device; the selected one if left out. |
| `shown` | boolean or null | no | Open (true) or close (false) the window; switches if left out. |

Result: [`PluginInfo`](#plugininfo).

### `plugin.unconfigure_param`

**Unconfigure Plug-In Parameter**. Permission: `edit`. Contexts: `device-view`.

Removes one parameter from a plug-in device's configured list (manual 24.1.2). A parameter that has automation, a clip envelope, or a MIDI, key or Macro mapping is refused, naming what it has, as Live warns before deleting one; `force` removes it anyway. One undo step. Returns `device.parameters`, each marked configured or not.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `param` | [`ParamId`](README.md#paramid) | yes | The parameter to remove. |
| `device` | [`DeviceId`](README.md#deviceid) or null | no | The device; the selected one if left out. |
| `force` | boolean | no | Remove it even when it has automation, a clip envelope, or a mapping (the warning accepted). |

Result: [`DeviceParameters`](README.md#deviceparameters).
