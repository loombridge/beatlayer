## Commands

### `video.frame_at`

**Video Frame At**. Permission: `read`. Contexts: `global`.

Gives the frame a video clip plays at a song position `at`, in ticks: the `movie_time` in seconds that the clip's warp map gives for it, the `frame` index shown then (the last frame at or before the time) and when it starts, `frame_time`. Without `clip` it asks the video clip whose picture shows at `at`, the playing one on the bottom-most track; with none playing every field but `clip` is `null` and the picture is black. Moving a warp marker changes which frame plays when. With `movie_time` and a `clip` instead of `at` it gives the frame at that time in the movie, as for a warp marker being dragged. Fails if the clip isn't a video clip or its movie can't be read. Changes nothing.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `at` | [`Ticks`](README.md#ticks) or null | no | The song position, in ticks. Give this or `movie_time`. |
| `clip` | [`ClipId`](README.md#clipid) or null | no | The video clip. Left out with `at`, the one whose picture shows there: the playing video clip on the bottom-most track. |
| `movie_time` | number or null | no | A time in the movie, in seconds, as a warp marker's `time` is: the frame there, whichever song position plays it. Give this or `at`; it needs `clip`. |

Result: [`FrameAt`](README.md#frameat).

### `video.set_window`

**Set Video Window**. Permission: `read`. Contexts: `global`.

Shows or hides the Video Window (`shown`), places and sizes it (`frame`), puts it in full screen or brings it back (`full_screen`, on the screen it is on) and sets its size to the movie's own (`original_size`). A view command: it changes no set and is no undo step. Showing needs a video clip in the Arrangement. Returns what `video.window_state` does.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `frame` | [`WindowFrame`](README.md#windowframe) or null | no | Where the window is and how big: the left and top of its frame and the size of its picture, in points. Kept in the preferences. |
| `full_screen` | boolean or null | no | Put the window in full screen on the screen it is on, or bring it back. |
| `original_size` | boolean | no | Set the window's size to the size of the picture of the movie it shows, one point to a pixel, keeping its place. |
| `shown` | boolean or null | no | Show (`true`) or hide the window. Showing needs a video clip in the Arrangement. |

Result: [`WindowState`](README.md#windowstate).

### `video.window_state`

**Video Window State**. Permission: `read`. Contexts: `global`.

Reads the Video Window: whether it shows, whether the set has a video clip to show, where it is and how big (kept in the preferences, the same in every set), whether it is in full screen, and the frame it shows now, as `video.frame_at` gives it. Changes nothing.

Default keys: none.

Arguments: none (send `{}`).

Result: [`WindowState`](README.md#windowstate).
