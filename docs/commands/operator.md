## Commands

### `operator.copy_oscillator`

**Copy Oscillator**. Permission: `edit`. Contexts: `device-view`.

Copies every setting of one Operator oscillator to another, as the menu's Copy Oscillator settings does: `from` and `to` from 0 for A to 3 for D. Its controls, envelope and drawn partials are copied, and the device's `params` and `partials` read back the result. One undo step (Copy Oscillator).

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `from` | integer from 0 to 255 | yes | The oscillator to copy from, 0 for A to 3 for D. |
| `to` | integer from 0 to 255 | yes | The oscillator that takes its settings. |
| `device` | [`DeviceId`](README.md#deviceid) or null | no | The Operator; the selected device if left out. |

Result: [`OscillatorCopied`](README.md#oscillatorcopied).

### `operator.play_by_key`

**Play By Key**. Permission: `edit`. Contexts: `device-view`.

Sets an Operator's filter frequency to 466 Hz and Freq < Key to 100 %, as the filter frequency's menu item Play By Key does. The device's `params` read back the result. One undo step (Play By Key).

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `device` | [`DeviceId`](README.md#deviceid) or null | no | The Operator; the selected device if left out. |

Result: [`OperatorChanged`](README.md#operatorchanged).

### `operator.set_envelope_levels`

**Set All Envelope Levels**. Permission: `edit`. Contexts: `device-view`.

Sets the Initial, Peak, Sustain and, where it has one, End levels of an Operator envelope (`A` to `D`, `Filter`, `Pitch` or `LFO`) to `maximum`, `minimum` or `middle`, as the menu's Set All Envelope Levels does. An oscillator's levels run from silence to 0 dB with the middle at -6 dB; the others' from -100 % to 100 % with the middle at 0 %. The device's `params` read back the result. One undo step (Set All Envelope Levels).

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `envelope` | string | yes | The envelope: `A`, `B`, `C`, `D`, `Filter`, `Pitch` or `LFO`. |
| `to` | [`EnvelopeLevel`](README.md#envelopelevel) | yes | Maximum, minimum or middle. |
| `device` | [`DeviceId`](README.md#deviceid) or null | no | The Operator; the selected device if left out. |

Result: [`OperatorChanged`](README.md#operatorchanged).

### `operator.set_harmonics`

**Set Harmonics Editor**. Permission: `read`. Contexts: `device-view`.

Sets the harmonics editor's options, as the menu's Even Only, Odd Only and Normalize do: a drag across the partials sets the even ones only, the odd ones only (each switching the other off), and with Normalize on (the default) scales the levels so the loudest is 1. Returns the options. It changes only the view: it isn't an undo step.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `device` | [`DeviceId`](README.md#deviceid) or null | no | The Operator; the selected device if left out. |
| `even_only` | boolean or null | no | Whether a drag sets the even partials only. |
| `normalize` | boolean or null | no | Whether a drag scales the levels so the loudest is 1. |
| `odd_only` | boolean or null | no | Whether a drag sets the odd partials only. |

Result: [`HarmonicsView`](README.md#harmonicsview).
