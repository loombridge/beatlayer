## Commands

### `song.add_locator`

**Add Locator**. Permission: `edit`. Contexts: `arrangement`.

Adds a locator at a position, as the Set Locator button and Add Locator do. A locator with no name of its own is named with the next whole number. Two locators never share a position: adding one where another is leaves that one as it is. One undo step, `Add Locator`.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `locator` | [`Locator`](README.md#locator) | yes | The locator, with a new ID. |

Result: [`ChangeSet`](README.md#changeset).

### `song.delete_locator`

**Delete Locator**. Permission: `destructive`. Contexts: `arrangement`.

Deletes a locator, as the Delete Locator button and the Delete key do. A song start time on it goes with it. One undo step, `Delete Locator`. Because it removes the person's work, an agent asks first.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `locator` | [`LocatorId`](README.md#locatorid) | yes | The locator. |

Result: [`ChangeSet`](README.md#changeset).

### `song.delete_tempo_breakpoint`

**Delete Tempo Breakpoint**. Permission: `edit`. Contexts: `global`.

Deletes the tempo breakpoint at `at` from the Main track's Song Tempo envelope, joining its neighbours with a straight segment. The first breakpoint, at 1.1.1, can't be deleted; `at` there is refused. A position with no breakpoint is refused too.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `at` | [`Ticks`](README.md#ticks) | yes | Where the breakpoint is. |

Result: [`ChangeSet`](README.md#changeset).

### `song.delete_time_signature_change`

**Delete Time Signature Change**. Permission: `edit`. Contexts: `global`, `arrangement`.

Deletes the time-signature marker at `at`, so the signature before it runs on through that position. The first marker, at 1.1.1, can't be deleted; `at` there is refused. A position with no marker is refused too.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `at` | [`Ticks`](README.md#ticks) | yes | Where the marker is. |

Result: [`ChangeSet`](README.md#changeset).

### `song.loop_to_next_locator`

**Loop to Next Locator**. Permission: `edit`. Contexts: `arrangement`.

Sets the Arrangement's loop brace from a locator to the next one and switches the loop on, as the locator's context menu does. The last locator has none after it, and is refused. One undo step, `Loop to Next Locator`.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `locator` | [`LocatorId`](README.md#locatorid) | yes | The locator. |

Result: [`ChangeSet`](README.md#changeset).

### `song.move_locator`

**Move Locator**. Permission: `edit`. Contexts: `arrangement`.

Moves a locator to a new position, as dragging it does. A locator can't go before 1.1.1, and a move that would put two locators at one position changes nothing. One undo step, `Move Locator`.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `locator` | [`LocatorId`](README.md#locatorid) | yes | The locator. |
| `to` | [`Ticks`](README.md#ticks) | yes | Where it goes: 0 (1.1.1) or later, and not where another locator already is. |

Result: [`ChangeSet`](README.md#changeset).

### `song.move_tempo_breakpoint`

**Move Tempo Breakpoint**. Permission: `edit`. Contexts: `global`.

Moves the tempo breakpoint at `at` to `to`, keeping its tempo, as dragging one along the Main track's Song Tempo envelope does. Both are tick positions, `to` is 0 (1.1.1) or later, and it mustn't land on another breakpoint. The first breakpoint, at 1.1.1, can't move; `at` there is refused.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `at` | [`Ticks`](README.md#ticks) | yes | Where the breakpoint is now. |
| `to` | [`Ticks`](README.md#ticks) | yes | Where it goes: 0 (1.1.1) or later, and not where another breakpoint already is. |

Result: [`ChangeSet`](README.md#changeset).

Default keys: none.

Arguments:

### `song.scales`

**Scale List**. Permission: `read`. Contexts: `global`.

Reports the scale list: every scale a set can use, in the order the Scale Name chooser shows them, with each scale's steps above the root in semitones. The names are the ones `clip.set_scale` and `song.set_scale` take. Changes nothing. Use it to read the scales a set has before setting one.

Default keys: none.

Arguments: none (send `{}`).

Result: [`ScaleList`](README.md#scalelist).

### `song.set_lock_envelopes`

**Lock Envelopes**. Permission: `edit`. Contexts: `global`.

Switches Lock Envelopes, the switch above the track headers and the Options menu item. Off (the default in a new set), editing the Arrangement's clips carries their tracks' envelopes over the clips' spans with them: moving, copying, cutting, deleting, duplicating and pasting clips take the envelopes over the same spans. On, the envelopes stay where they are in the song and the clips move on their own. The setting is saved with the set, and each change is one undo step.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `enabled` | boolean | yes | Whether the envelopes stay where they are. |

Result: [`ChangeSet`](README.md#changeset).

### `song.set_scale`

**Set Scale**. Permission: `edit`. Contexts: `global`.

Sets the set's current scale: whether its Scale Mode is on (`enabled`), its root note (`root`, 0 is C and 11 is B) and its scale (`name`, one of the names `song.scales` reads). It leaves the values it isn't given as they were. The current scale is what the Control Bar's scale controls show, what the clips made next take, and what a device or a tool reads where no clip plays. It is one undo step, named "Change Scale", and the set is saved with it.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `enabled` | boolean or null | no | Whether the set's Scale Mode is on. |
| `name` | string or null | no | The scale's name, from the scale list. |
| `root` | integer or null | no | The root note: 0 (C) to 11 (B). |

Result: [`ChangeSet`](README.md#changeset).

### `song.set_start`

**Set Song Start Time**. Permission: `edit`. Contexts: `arrangement`.

Sets where the song starts: at a locator, or at the loop brace's start. Choosing it where it is set clears it, so the song starts at the insert marker again. While it is set, Play starts the song there instead of at the insert marker. One undo step, `Set Song Start Time`.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `start` | [`SongStart`](README.md#songstart) or null | no | Where the song starts; nothing clears it. |

Result: [`ChangeSet`](README.md#changeset).

### `song.set_start_time`

**Set Song Start Time**. Permission: `edit`. Contexts: `arrangement`.

Sets where the song starts: at a locator, or at the loop brace's start, as Set Song Start Time Here does. The song start time follows its locator or the brace as they move, and deleting the locator clears it. `null` clears it, so the song starts at the insert marker again. While it is set, Play starts the song there instead of at the insert marker.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `clear` | boolean | no | Whether the song start time is cleared, so the song starts at the insert marker again. |
| `locator` | [`LocatorId`](README.md#locatorid) or null | no | The locator the song starts at. Left out, the selected one: the song starts there, or stops starting there if it already does. |
| `loop_brace` | boolean | no | Whether the song starts at the loop brace's start. |

Result: [`LocatorResult`](README.md#locatorresult).

### `song.set_tempo`

**Set Tempo**. Permission: `edit`. Contexts: `global`.

Replaces the song's tempo map. To give the whole song one tempo, send a single constant segment at tick 0; add segments to change or ramp the tempo at given positions. Tempos are quarter notes per minute, from 1 to 1,000. Clips and notes keep their positions in ticks, so a new tempo changes when they sound, not where they sit in bars.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `tempo` | [`TempoMap`](README.md#tempomap) | yes | The new tempo map. |

Result: [`ChangeSet`](README.md#changeset).

### `song.set_tempo_breakpoint`

**Set Tempo Breakpoint**. Permission: `edit`. Contexts: `global`.

Sets the tempo at `at` on the Main track's Song Tempo envelope, adding a breakpoint there or replacing the one that's there, as dragging a breakpoint does. Tempos are quarter notes per minute, from 1 to 1,000, and `at` is 0 (1.1.1) or later. A breakpoint between two others splits the segment there, keeping the neighbours. Clips and notes keep their positions in ticks, so a new tempo changes when they sound, not where they sit in bars. Use `song.set_tempo` to replace the whole map at once.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `at` | [`Ticks`](README.md#ticks) | yes | Where the breakpoint sits: 0 (1.1.1) or later. |
| `bpm` | [`Bpm`](README.md#bpm) | yes | The tempo there, as quarter notes per minute. |

Result: [`ChangeSet`](README.md#changeset).

### `song.set_time_signature_change`

**Set Time Signature Change**. Permission: `edit`. Contexts: `global`, `arrangement`.

Sets the time-signature marker at `at` to `signature`, adding one when there's none, as Create > Insert Time Signature Change and the marker's numerator and denominator fields do. The marker sits anywhere at 0 (1.1.1) or later and always starts a new bar there, so a change before the previous bar is full cuts it short. Numerators run 1 to 99 and denominators are 1, 2, 4, 8, or 16. Use `song.set_time_signatures` to replace the whole map.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `at` | [`Ticks`](README.md#ticks) | yes | Where the marker sits: 0 (1.1.1) or later. |
| `signature` | [`TimeSignature`](README.md#timesignature) | yes | The signature from there on. |

Result: [`ChangeSet`](README.md#changeset).

### `song.set_time_signatures`

**Set Time Signatures**. Permission: `edit`. Contexts: `global`.

Replaces the song's time-signature map. To give the whole song one meter, send a single change at tick 0, such as 4/4; add changes to switch meter at given positions, each of which starts a new bar. Numerators run from 1 to 99 and denominators are 1, 2, 4, 8, or 16. It changes how positions are counted in bars and beats, not where clips sit in ticks.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `time_signatures` | [`TimeSignatureMap`](README.md#timesignaturemap) | yes | The new time-signature map. |

Result: [`ChangeSet`](README.md#changeset).

### `song.unfollow_tempo_automation`

**Unfollow Tempo Automation**. Permission: `edit`. Contexts: `global`.

Makes every clip that leads the tempo a follower and writes the tempo they set into the Main track's Song Tempo envelope as ordinary breakpoints, so the song plays exactly as it did and the envelope becomes editable. One undo step, and changes nothing when no clip leads.

Default keys: none.

Arguments: none (send `{}`).

Result: [`ChangeSet`](README.md#changeset).
