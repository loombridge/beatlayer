## Commands

### `link.set_enabled`

**Link**. Permission: `external`. Contexts: `global`.

Switches Link, as the Control Bar's Link toggle does: on, the app joins the Link session on its networks or starts one, and shares tempo, beat and phase with the other apps in it. It talks on the network, so it is external. With no session to join, switching it on changes neither the tempo nor the song position; where a session exists, the song takes its tempo and phase. While it is on, a tempo change from a peer becomes the set's tempo and overrides tempo automation, the count-in doesn't play, and a start waits for the session's phase. `on` left out switches to the other state. It is a preference kept between starts, not part of the set. `link.state` reports it.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `on` | boolean or null | no | Whether it's on; left out, it switches to the other state. |

Result: [`Switched`](README.md#switched).

### `link.set_show_toggle`

**Show Link Toggle**. Permission: `edit`. Contexts: `global`.

Shows or hides the Control Bar's Link toggle and its menu, as Settings' Link page's Show Link Toggle does. Hiding it leaves Link as it is. `on` is whether it shows; left out, it switches to the other state. It is a preference kept between starts, not part of the set. `link.state` reports it.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `on` | boolean or null | no | Whether it's on; left out, it switches to the other state. |

Result: [`Switched`](README.md#switched).

### `link.set_start_stop_sync`

**Link Start Stop Sync**. Permission: `edit`. Contexts: `global`.

Switches Start Stop Sync: with it on, the app's starts and stops go to the Link session and a peer's reach the app, with the peers that have it on too. Switching it on while the session plays doesn't start the song. `on` left out switches to the other state. It is a preference kept between starts, not part of the set. `link.state` reports it.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `on` | boolean or null | no | Whether it's on; left out, it switches to the other state. |

Result: [`Switched`](README.md#switched).

### `link.state`

**Link Status**. Permission: `read`. Contexts: `global`.

Reports Link: whether it is on, how many other peers are in the session, the session's tempo, the quantum (the global launch quantisation's length at the play position, in quarter notes) and how far the session is through it, whether the session plays, whether Start Stop Sync is on, whether the Control Bar shows the Link toggle, and whether a start waits for the session's phase and how many seconds until it begins. Changes nothing. Switch Link with `link.set_enabled` and Start Stop Sync with `link.set_start_stop_sync`.

Default keys: none.

Arguments: none (send `{}`).

Result: [`LinkState`](#linkstate).
