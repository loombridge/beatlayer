## Commands

### `track.add_take_lane`

**Add Take Lane**. Permission: `edit`. Contexts: `arrangement`.

Adds a take lane under an audio or MIDI track's main lane, after the lanes it has, or at `index` among them (0 is the lane nearest the main lane). `lane.name` names it and `lane.clips` are the clips it holds, each with a `name`, a `start` and `length` in ticks (705,600 to the quarter note), and `data`: audio as `clip.create` takes it, or tagged `audio` or `midi`. The lane and its clips are given IDs when `id` is left out. A lane holds clips of its track's kind. The track plays only its main lane, or the take lane that is auditioned in its place (`take_lane.set_audition`); recording adds a lane for every take and copies the latest to the main lane. Read the lanes back with the query tool's `track` `take_lanes`.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `track` | [`TrackId`](README.md#trackid) | yes | The audio or MIDI track. |
| `lane` | [`NewTakeLane`](README.md#newtakelane) | yes | The lane and its clips. |
| `index` | integer or null | no | Where among the track's take lanes the new one goes, counted from 0 for the lane nearest the main lane. Left out, after the last. |

Result: [`ChangeSet`](README.md#changeset).

### `track.bounce_in_place`

**Bounce Track in Place**. Permission: `destructive`. Contexts: `arrangement`, `session`, `track-headers`.

Renders the selected tracks to audio and replaces each with an audio track holding it: no devices, the track's name with " (Bounce)" after it, its volume, pan, sends, activator, solo, output routing, and mixer automation, and its clips playing the bounced audio. `tracks` names them (left out, the selected tracks). A group is bounced as one track, after its mixer. The files go into Samples/Processed/Bounce. It is destructive, since it deletes the track's devices and clips, and undoing it gives the source track back exactly.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `channels` | [`Channels`](README.md#channels) | no | How many channels the bounced files hold. |
| `tracks` | array or null | no | The tracks to bounce. Left out, the selected tracks. |

Result: [`BounceResult`](README.md#bounceresult).

### `track.bounce_to_new_track`

**Bounce to New Track**. Permission: `edit`. Contexts: `arrangement`, `session`, `track-headers`.

Renders the selected clips, or the time selection on the selected tracks, to audio on a new track directly after each source track, and switches the source material off. `tracks` names the source tracks (left out, the selected ones), `clips` the clips to bounce (left out, the selected clips, or the time selection), and `start` and `end` the time selection. The new track takes its source's name with " (Bounce)" after it, its colour, and its mixer settings, and the files go into Samples/Processed/Bounce. It is an edit.

### `track.create`

**Insert Track**. Permission: `edit`. Contexts: `global`.

Creates an empty track: audio (holds audio clips), MIDI (holds MIDI clips), group (holds other tracks), or return (receives sends). It starts at unity volume and centre pan, with no devices or clips. Audio, MIDI, and group tracks go at `index` among the top-level tracks, or inside the group `parent`; return tracks go at `index` among the returns. `id` must be a new ID the project has issued for it. The Main track always exists and can't be created.

Default keys:

| Shortcut | macOS | Windows | Context | Action in the reference | Binding |
|---|---|---|---|---|---|

| S-TRACK-002 | `Cmd+Shift+T` | `Ctrl+Shift+T` | `global` | Insert a MIDI track | fixes `kind` = `"midi"` |
| S-TRACK-003 | `Cmd+Option+T` | `Ctrl+Alt+T` | `global` | Insert a return track | fixes `kind` = `"return"` |

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `id` | [`TrackId`](README.md#trackid) | yes | The new track's ID. |
| `kind` | [`TrackKind`](README.md#trackkind) | yes | Its kind. |
| `name` | string | yes | Its name. |
| `index` | integer, at least 0 | yes | Where it goes in its list, from 0 to the list's length. |
| `parent` | [`TrackId`](README.md#trackid) or null | no | The group to put it in, or `null` (or nothing) for the top level. |

Result: [`ChangeSet`](README.md#changeset).

### `track.freeze`

**Freeze Track**. Permission: `edit`. Contexts: `arrangement`, `session`, `track-headers`.

Renders the selected tracks to audio and plays that instead of their devices: an audio or MIDI track's Arrangement from 1.1.1 to the end of its last tail, and each Session clip on its own, taken after the devices and before the mixer. `tracks` names them (left out, the selected tracks). A group renders its tracks through their mixers and devices and, for each return they send to, the sum of those sends; a return renders from 1.1.1 to the end of the set. The track keeps its mixer, and its clips keep their places; its devices and clip settings are locked while frozen. The freeze runs offline through the processed-file writer, one undo step when every file is whole. It's an edit.

### `track.link`

**Link Tracks**. Permission: `edit`. Contexts: `global`, `arrangement`, `session`, `track-headers`.

Links audio and MIDI tracks (`tracks`, or the selected tracks; a group track stands for the audio and MIDI tracks inside it, at any depth) into a new link group, so the Arrangement edits them as one: selecting, moving, resizing, splitting and consolidating clips, fades, arming, and the take lanes and comps all reach every track of the group. Each track leaves the group it was in, and a group left with one track ends. With `into`, naming a linked track, the tracks join its group instead. Needs two audio or MIDI tracks, or one with `into`. One undo step, named Link Tracks. Read the group back with the query tool's `track`, field `linked`.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `into` | [`TrackId`](README.md#trackid) or null | no | A linked track: the tracks join its link group instead of a new one. |
| `tracks` | array or null | no | The tracks to link; the selected tracks if left out. A group track stands for the audio and MIDI tracks inside it. |

Result: [`TracksLinked`](README.md#trackslinked).

### `track.move`

**Move Track**. Permission: `edit`. Contexts: `track-headers`.

Moves a track to `index` in the top-level track list, or inside the group `parent`. A return track moves among the returns. The index counts positions after the track is taken out of its current place, so moving a track down past its neighbour is its current index plus one. Use it to reorder tracks or to put tracks into or out of groups. A group can't go inside itself, and the Main track can't be moved.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `track` | [`TrackId`](README.md#trackid) | yes | The track. |
| `index` | integer, at least 0 | yes | Where it goes in that list. |
| `parent` | [`TrackId`](README.md#trackid) or null | no | The group to move it into, or `null` (or nothing) for the top level. |

Result: [`ChangeSet`](README.md#changeset).

### `track.set_link_group`

**Set Link Group**. Permission: `edit`. Contexts: `track-headers`, `session`, `arrangement`.

Puts audio and MIDI tracks into the link group `group`, or takes them out of their groups when `group` is left out. A track leaves the group it was in, and a group left with one track ends. `group` is a new ID to link the tracks in a group of their own, or the ID another linked track's group has (`track.link` and `track.unlink` choose it for you). Group, return and Main tracks can't be linked. Linked tracks are edited as one: a clip move, resize, split or consolidate, fades, arming, and take lane edits made on one reach the others. Read the group back with the query tool's `track`, field `linked`. One undo step.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `tracks` | array of [`TrackId`](README.md#trackid) | yes | The audio or MIDI tracks. |
| `group` | [`LinkGroupId`](README.md#linkgroupid) or null | no | The group they join; an existing group to add to it, or a new ID for a new one. Left out, the tracks are unlinked. |

Result: [`ChangeSet`](README.md#changeset).

### `track.set_tuning_bypass`

**Bypass Tuning**. Permission: `edit`. Contexts: `track-headers`, `session`, `arrangement`.

Switches a MIDI track's Bypass Tuning, as its In/Out section's switch does. On, the track plays twelve equal steps whatever tuning the set holds, and its clips' editors show twelve-step keys; off (a new track's), it plays the tuning. A track that holds a Drum Rack plays twelve equal steps whatever the switch says. Only MIDI tracks have it. The switch is saved with the set only where it's on, and each change is one undo step, named "Bypass Tuning".

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `track` | [`TrackId`](README.md#trackid) | yes | The MIDI track. |
| `bypass` | boolean | yes | Whether it bypasses the tuning. |

Result: [`ChangeSet`](README.md#changeset).

### `track.set_tuning_layout`

**Set MIDI Controller Layout**. Permission: `edit`. Contexts: `track-headers`, `session`, `arrangement`.

Sets a MIDI track's MIDI Controller Layout, the chooser beside Bypass Tuning, and its custom table; what is left out stays. `layout` is `all_keys` (a new track's: each key plays the same key of the tuning), `black_keys_only` (C#3 plays key 60 of the tuning, each black key above or below the next key up or down; white keys play nothing), `white_keys_only` (the same from C3 over the white keys), `closest_in_pitch` (each key plays the key of the tuning nearest its twelve-step pitch) or `custom`. `keys` is the custom table, 128 entries, one for each incoming key 0 to 127: the key of the tuning it plays, or null for none; a key the tuning has none for plays nothing. It maps notes from MIDI inputs and the computer MIDI keyboard as they enter the track, and does nothing while Bypass Tuning is on. Only MIDI tracks have one. Saved with the set where it differs from a new track's; one undo step (Change MIDI Controller Layout). The query tool's `track` reads it as `tuning_layout`.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `track` | [`TrackId`](README.md#trackid) | yes | The MIDI track. |
| `keys` | array or null | no | The custom table: 128 entries, the key of the tuning each incoming key plays or `null` for none. |
| `layout` | [`LayoutKind`](README.md#layoutkind) or null | no | The mapping to use. |

Result: [`ChangeSet`](README.md#changeset).

### `track.unfreeze`

Default keys: none.
