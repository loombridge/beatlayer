## Commands

### `set.backups`

**Beatlayer Set Backups**. Permission: `read`. Contexts: `global`.

The open set's backups, in the project folder's `Backup` folder, newest first, each with the time it was made in local time. The list is empty when the set has no backups.

Default keys: none.

Arguments: none (send `{}`).

Result: [`Backups`](README.md#backups).

### `set.collect_all_and_save`

**Collect All and Save**. Permission: `external`. Contexts: `global`.

Copies the files the open set uses that live outside its project folder into the project's `Samples/Imported` folder, re-points the set's media table at the copies, and saves the set, as File ▸ Collect All and Save does in Live, so the set no longer depends on files elsewhere. `groups` chooses which places to collect from: "other-project", "user-library" and "elsewhere"; all of them when none are given. Fails if the set has never been saved; use `set.save_as` to give it a project folder first. The result's `files` is how many files were copied.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `groups` | array of [`ExternalGroup`](README.md#externalgroup) | no | The groups to collect from: "other-project", "user-library" or "elsewhere". All of them when none are given. |
| `project` | string or null | no | The project folder to collect for, when it isn't the open set's: every set in it is rewritten, each keeping the version it replaces in its project's `Backup` folder (R16). |

Result: [`FileReport`](README.md#filereport).

### `set.discard_changes`

**Don't Save**. Permission: `destructive`. Contexts: `global`.

Throws away the open set's unsaved changes, as choosing Don't Save when asked to save does: the set goes back to how it was when it was last opened or saved (a set never saved goes back to the factory default set), and its undo history is cleared. The changes can't be brought back. Nothing on disk changes. Does nothing if there are no unsaved changes.

Default keys: none.

Arguments: none (send `{}`).

Result: [`SetResult`](README.md#setresult).

### `set.discard_recovery`

**Discard Recovery**. Permission: `destructive`. Contexts: `global`.

Declines to recover a set that `set.list_recoverable` lists, the one with `id` or the newest: its unsaved edits are removed from beside the set, so it isn't offered again, and a copy of its journal is kept in the recovery folder's Discarded folder for seven days. Its set file is untouched.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `id` | string or null | no | The recoverable set's `id`, as `set.list_recoverable` gives it. Leave it out for the newest. |

Result: [`DiscardedRecovery`](README.md#discardedrecovery).

### `set.import_dawproject`

**Import DAWproject File**. Permission: `external`. Contexts: `global`.

Reads the DAWproject file at `path` and opens what it holds as a new set, in place of the open one, as opening a set does: it is refused while the open set has unsaved changes. The new set starts empty and holds what the file carries: its tracks, groups, returns and their mixer and routing, its clips with their notes, media, warping and loops, its scenes and slots, its tempo and time signature. It is unsaved, and its name is the file's name without `.dawproject` until it is first saved. The result's `report` says what the import left out or changed, and `set.import_report` gives that report again while the set the import made is open. Reads a file outside the project.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `path` | string | yes | The DAWproject file to read, absolute or relative to the app's working directory. |

Result: [`ImportDawProjectResult`](README.md#importdawprojectresult).

### `set.import_report`

**DAWproject Import Report**. Permission: `read`. Contexts: `global`.

Reports what the last DAWproject import left out or changed: each thing, where it was, how many there were, and what Beatlayer did, and the application and version the file says made it. It gives the report again while the set the import made is open, and nothing after another set opens. Changes nothing.

Default keys: none.

Arguments: none (send `{}`).

Result: [`ImportReport`](README.md#importreport).

### `set.later_recovery`

**Later Recovery**. Permission: `read`. Contexts: `global`.

Closes the recovery prompt the app shows at launch, leaving every set it listed to be offered again at the next launch: nothing is recovered and nothing is thrown away. The prompt's Later button runs it, and Esc does the same. Changes nothing in the set.

Default keys: none.

Arguments: none (send `{}`).

Result: [`RecoveryPrompt`](README.md#recoveryprompt).

### `set.list_recoverable`

**List Recoverable Sets**. Permission: `read`. Contexts: `global`.

Lists the sets that Beatlayer, here or in an earlier run, stopped without closing (a crash, a forced quit, a power cut) while they had unsaved edits. Each has an `id` for `set.recover` or `set.discard_recovery`, its file (null if it had never been saved), how many edits followed its last save, and when the last was made. Sets open in another running instance aren't listed. Changes nothing.

Default keys: none.

Arguments: none (send `{}`).

Result: [`RecoverableSets`](README.md#recoverablesets).

### `set.new`

**New Beatlayer Set**. Permission: `destructive`. Contexts: `global`.

Replaces the open set with the factory default set: four tracks (two MIDI, two audio) and two return tracks, shown in the Arrangement View. Unsaved changes to the open set are lost, and its undo history is cleared, so save first if they matter.

Default keys:

| Shortcut | macOS | Windows | Context | Action in the reference | Binding |
|---|---|---|---|---|---|
| S-FILE-001 | `Cmd+N` | `Ctrl+N` | `global` | Create a new set | runs it |

Arguments: none (send `{}`).

Result: [`SetResult`](README.md#setresult).

### `set.open`

**Open Beatlayer Set...**. Permission: `external`. Contexts: `global`.

Opens the set file at `path` (or the only set in the project folder at `path`), replacing the open set and clearing its undo history. It refuses while the open set has unsaved changes: save them first with `set.save` or `set.save_as`, or throw them away with `set.discard_changes`, so losing work is always its own step. A person choosing the menu item or pressing the shortcut is asked whether to save, then picks the file in a dialog.

Default keys:

| Shortcut | macOS | Windows | Context | Action in the reference | Binding |
|---|---|---|---|---|---|
| S-FILE-002 | `Cmd+O` | `Ctrl+O` | `global` | Open a set | runs it |

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `path` | string | yes | The set file's path, absolute or relative to the app's working directory. |

Result: [`SetResult`](README.md#setresult).

### `set.open_backup`

**Open Beatlayer Set Backup**. Permission: `external`. Contexts: `global`.

Opens the backup at `path` as the set itself, as File ▸ Open Beatlayer Set Backups does: the set keeps its own file and name, its song is the backup's, and it opens unsaved with an empty undo history, so `set.save` makes the backup the set's current version. Refuses while the set has unsaved changes, as `set.open` does.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `path` | string | yes | The backup to open, by its path. |

Result: [`SetResult`](README.md#setresult).

### `set.recover`

**Recover Set**. Permission: `destructive`. Contexts: `global`.

Opens a set that `set.list_recoverable` lists, the one with `id` or the newest, exactly as it was after its last journalled edit. It replaces the open set, whose undo history is cleared; if the open set had unsaved edits they're kept for recovery in turn. The recovered set is unsaved: use `set.save` to keep it in its file, or `set.save_as`. Use it when the user wants back the work a crash interrupted.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `id` | string or null | no | The recoverable set's `id`, as `set.list_recoverable` gives it. Leave it out for the newest. |

Result: [`RecoveredSet`](README.md#recoveredset).

### `set.relink_missing`

**Relink Missing Files**. Permission: `external`. Contexts: `global`.

Searches for the files the open set uses that are missing or changed, and relinks each one to the file found with the same content, as Live's automatic search does. The search covers the set's project folder, the User Library, the folders the files were last in, and any `folders` given, each with its subfolders; `project` and `library` switch the first two off, and `folder` names the folder the Automatic Search's Search Folder chooses. A file with one candidate is relinked to it; a file with several keeps its row, and the candidates are in the result's `candidates`, so the person chooses. The result's `files` is how many files were relinked. It also runs by itself when a set is opened.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `folder` | string or null | no | The folder the Automatic Search's Search Folder names. |
| `folders` | array of string | no | Folders to search, each with its subfolders, absolute or relative to the app's working directory. May be empty. |
| `library` | boolean or null | no | Whether the User Library is searched. On unless asked otherwise. |
| `project` | boolean or null | no | Whether the set's project folder is searched. On unless asked otherwise. |

Result: [`FileReport`](README.md#filereport).

### `set.restore`

**Restore**. Permission: `destructive`. Contexts: `global`.

Replaces the whole song with the one a row of `set.save_history` holds, as one undo step named `Restore Save Point` or `Restore Saved Version` that undo takes back. The set keeps its file and name, and the transport keeps playing. With Save Continuously on the restore is a new save point; every row stays listed. A row that can't be read changes nothing. Read the result back with the query tool's `song` (`undo.next_undo`).

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `id` | string | yes | The row's `id`, as `set.save_history` gives it. |

Result: [`Restored`](README.md#restored).

### `set.save`

**Save Beatlayer Set**. Permission: `destructive`. Contexts: `global`.

Saves the set to its file, replacing the file's previous contents, which are kept in the `Backup` folder of the set's project folder (the last 10 saves). Fails if the set has never been saved; use `set.save_as` to give it a file and a project folder first.

Default keys:

| Shortcut | macOS | Windows | Context | Action in the reference | Binding |
|---|---|---|---|---|---|
| S-FILE-003 | `Cmd+S` | `Ctrl+S` | `global` | Save the set | runs it |

Arguments: none (send `{}`).

Result: [`SetResult`](README.md#setresult).

### `set.save_as`

**Save Beatlayer Set As...**. Permission: `external`. Contexts: `global`.

Saves the set under a new name or in a new place, always inside a project folder, and that file becomes the set's. `path` gives a folder and the set's name, such as `/Music/Tango.blset` (`.blset` is added if it's missing). If the folder is a project folder, one that already holds a `.blset` set, the set joins that project as `<name>.blset` there; a set of that name there is replaced, and the replaced version kept in that project's `Backup` folder. Otherwise a new project folder, `<name> Project`, is made in the folder (or `<name> Project 2` and so on if that name is taken, so nothing is overwritten), and the set is saved inside it, as `/Music/Tango Project/Tango.blset`. The result's `path` is where the set was saved. Moving to another project folder keeps the set using the same media files. A person choosing the menu item or pressing the shortcut picks the path in a dialog that opens in the set's project folder.

Default keys:

| Shortcut | macOS | Windows | Context | Action in the reference | Binding |
|---|---|---|---|---|---|
| S-FILE-004 | `Cmd+Shift+S` | `Ctrl+Shift+S` | `global` | Save the set under a new name | runs it |

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `path` | string | yes | A folder and the set's name, as a set file's path such as `/Music/Tango.blset`, absolute or relative to the app's working directory. The set goes in that folder if it's a project folder (it holds a set already), and otherwise in a new `<name> Project` folder inside it; the result says where. |

Result: [`SetResult`](README.md#setresult).

### `set.save_as_default`

**Save Beatlayer Set As Default Set...**. Permission: `destructive`. Contexts: `global`.

Saves the open set as the default set, which every new set starts from, as File ▸ Save Beatlayer Set As Default Set does in Live. `path` names the default set's file; left out it goes in the User Library's `Templates` folder, or beside the app's preferences when there is no User Library. The open set itself doesn't change and keeps its own file. The result's `path` is the default set's file.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `path` | string or null | no | The file to save the default set as, absolute or relative to the app's working directory. Left out, it goes in the User Library's `Templates` folder, or beside the app's preferences when there is no User Library. `.blset` is added if it's missing. |

Result: [`SetResult`](README.md#setresult).

### `set.save_as_template`

**Save Beatlayer Set As Template...**. Permission: `destructive`. Contexts: `global`.

Saves the open set as a template in the User Library's `Templates` folder, making that folder if it isn't there, as File ▸ Save Beatlayer Set As Template does in Live. `name` names the template; left out it takes the open set's name. The open set itself doesn't change and keeps its own file. The result's `path` is the template's file.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `name` | string or null | no | The template's name, without the `.blset` extension; left out uses the open set's name. |

Result: [`SetResult`](README.md#setresult).

### `set.save_copy`

**Save a Copy...**. Permission: `external`. Contexts: `global`.

Saves a copy of the open set at `path`, as File ▸ Save a Copy... does: in the folder when it is a project folder, otherwise in a new "<name> Project" folder. The copy names the same media files. The open set keeps its file, its name, its undo history and whether it has unsaved changes.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `path` | string | yes | Where to save the copy, as a save dialog gives it: a folder and the set's name, such as `/Music/Tango.blset`. |

Result: [`SavedCopy`](README.md#savedcopy).

### `set.save_history`

**Save History**. Permission: `read`. Contexts: `global`.

Lists the open set's save history, newest first: the save points Save Continuously kept since the last save (none while it is off), then the set as last saved, then its backups. Each row has an `id` for `set.restore`, its kind (`save_point`, `saved` or `backup`), its time in UTC and its label, which is the edit's name for a save point. A set never saved has no rows. Changes nothing.

Default keys: none.

Arguments: none (send `{}`).

Result: [`SaveHistory`](README.md#savehistory).
