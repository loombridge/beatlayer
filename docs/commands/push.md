## Commands

### `push.display_frame`

**Push 2 Display Frame**. Permission: `read`. Contexts: `global`.

Returns what Push 2's display shows as a 960 × 160 PNG, base64, drawn from the same content `push.state` reports as text. Changes nothing.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `row` | integer or null | no | The row, from 1 to 6. Left out, the first Push 2. |

Result: [`PushDisplayFrame`](README.md#pushdisplayframe).

### `push.set_mode`

**Set Push 2 Mode**. Permission: `read`. Contexts: `global`.

Sets the pad mode (`note` or `session`) and the display mode (`device`, `browse`, `mix` or `clip`, with Mix's page) of one Push 2 or all of them, as a tap on their buttons does; an open menu closes. The surface switches on its next tick. Changes only what Push 2 shows, never the set. Read back by `push.state`.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `display` | [`PushDisplayMode`](README.md#pushdisplaymode) or null | no | The display mode to switch to. |
| `mix` | [`PushMixPage`](README.md#pushmixpage) or null | no | Mix's page, with `display` `mix`; Track Mix if left out. |
| `pad` | [`PushPadMode`](README.md#pushpadmode) or null | no | The pad mode to switch to. |
| `row` | integer or null | no | The row, from 1 to 6. Left out, every Push 2. |

Result: [`PushSetModeResult`](README.md#pushsetmoderesult).

### `push.set_setup`

**Set Push 2 Setup**. Permission: `edit`. Contexts: `global`.

Sets Push 2's Setup menu: Pad Sensitivity, Pad Gain and Pad Dynamics (0 to 10, which shape the velocity curve), Display Light and LED Brightness (0 to 100 %) and PushWorkflow (`scene` or `clip`), any of them. The values are preferences, kept between launches and the same for every set, and reach every Push 2 that runs. Read back by `push.state` (`setup`).

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `display_light` | integer or null | no | Display Light, 0 to 100 %. |
| `led_brightness` | integer or null | no | LED Brightness, 0 to 100 %. |
| `pad_dynamics` | integer or null | no | Pad Dynamics, 0 to 10. |
| `pad_gain` | integer or null | no | Pad Gain, 0 to 10. |
| `pad_sensitivity` | integer or null | no | Pad Sensitivity, 0 to 10. |
| `workflow` | [`PushWorkflow`](README.md#pushworkflow) or null | no | Workflow. |

Result: [`PushSetup`](README.md#pushsetup).

### `push.state`

**Push 2 State**. Permission: `read`. Contexts: `global`.

Reads each Push 2 that runs in the Control Surfaces table: its ports, firmware version and power supply; its MIDI mode; the pad mode, the display mode (with Track Mix or Global Mix), any open menu and the buttons held or locked; each LED's colour index and animation by control name; the touch strip's configuration and LEDs; the Setup menu's values; and the display's content as text, by band and column: labels, parameter names and values, dots, notifications; and, in Browse Mode, what Load does, its columns with their entries and selection and the column in use; in Device Mode, the devices on the upper buttons with their depth and which is selected, whether Edit Mode is on, the bank and its page of banks, the parameters on the encoders, the chains shown while a rack's button is held, and whether Mute is locked. Changes nothing.

Default keys: none.

Arguments: none (send `{}`).

Result: [`PushState`](#pushstate).
