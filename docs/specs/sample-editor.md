# The Sample Editor in the Clip View: the waveform, its markers, editing them by mouse and keys, and the Audio Utilities panel

- **Status:** draft
- **Work packages:** WP-4.10 (the editor, its markers and keys: R1 to R13 and R19 to R22), WP-4.10b (the Audio Utilities panel, Edit, Save Default Clip, and replacing a clip's sample: R14 to R18)
- **Parity-matrix row:** Audio clips and warping: "Warp markers, transient markers, pseudo-warp markers" (editing them in the Clip View); "Clip pitch, reverse, RAM mode, high-quality interpolation" (their controls in the Audio Utilities panel)
- **Checked against:** the Live 12 reference manual (online edition), read 17 October 2026: chapter 8 (8.1 to 8.1.3, 8.4 to 8.4.7, 8.7, 8.8, 8.10, 8.12, 8.13), chapter 9 (9.1.4, 9.2.3 to 9.2.5.1) and chapter 42 (42.8, 42.10, 42.11); and the UI parity reference's Clip View rows, recorded from Live 12.4.3 on macOS on 10 October 2026

## The behaviour

When the Clip View shows an audio clip, its editor is the Sample Editor, in the place the MIDI Note Editor takes for a MIDI clip. It draws the clip's file as a waveform, one band per channel, against the clip's beats when the clip is warped and against time in the file when it isn't, with the clip's warp markers, its transients, its Start and End markers and its loop brace. The person double-clicks to make and delete warp markers, drags them to move the audio to the beat, Shift-drags one to move the waveform under it, hovers a transient to find its pseudo-warp marker, and uses the arrow keys and Live's Sample Editor shortcuts to do the same from the keyboard. The editor's context menu holds the warp commands, and the Create and Edit menus hold the marker, transient and quantise commands while the editor has focus.

To the editor's left the Audio Utilities panel holds the clip's sound settings: the Warp switch and warp mode, the BPM field with ×2 and ÷2, the Lead/Follow switch, Reverse, Edit, the Clip Fade switch on Session clips, RAM, HiQ, Gain, and the clip's Transpose and Detune.

This spec covers how the Sample Editor and the Audio Utilities panel look and what each gesture, key and menu item runs. What those commands do to the clip is [warping.md](warping.md)'s; the warp modes' controls, Transpose, Detune, RAM and HiQ are [warp-modes.md](warp-modes.md)'s; and Reverse and Crop Clip Sample are [audio-clip-editing.md](audio-clip-editing.md)'s. The Envelopes tab is [clip-envelopes.md](clip-envelopes.md)'s editor (WP-3.16), the Main Properties and Launch Properties panels are WP-2.3's and WP-3.9's, and cropping a clip's sample is WP-4.13's ([audio-clip-editing.md](audio-clip-editing.md)).

Every gesture, key and menu item runs a registered command, so an agent reaches everything the editor does; selecting, zooming, scrolling and Follow change the view only and are never undo steps, and every edit is one undo step however long its drag lasts. Colours, icons and type are Beatlayer's own.

## Rules

- **R1.** While the Clip View is shown, its editor is the Sample Editor when the clip it shows is an audio clip (the Arrangement's first selected clip, or the Session clip the Clip View shows), in the MIDI Note Editor's place (L-CLIP-016), under a Sample tab and an Envelopes tab. The Sample tab is Option+Shift+1 (S-CLIPMODE-003) and View ▸ Content Editor (M-VIEW-018); Option+Tab switches between the tabs. Which tab shows is view state: no undo step, and not saved with the set. (S1, S6, S7)
- **R2.** The editor's header shows the file's name, sample rate, bit depth and channel count. With several audio clips selected it shows each value they share, an asterisk where they differ, and how many files are selected. Clicking the name, or Show in Browser in the editor's context menu, shows the file in the browser (`browser.show_file`, `external`, as the browser's commands that list files are). (S3)
- **R3.** A warped clip's editor runs along the clip's beats, its ruler (L-CLIP-011) in bars and beats with the editing grid's lines, as the note editor's does; an unwarped clip's runs along time in the file, its ruler in minutes and seconds. Either way the editor first shows the whole file. (S3, S6, S8; showing the whole file first is Beatlayer's own)
- **R4.** The waveform is drawn from the file's peaks ([waveform-peaks.md](waveform-peaks.md)), one band per channel; on a warped clip each segment of the file is drawn stretched between its two warp markers, so the waveform lines up with the beats it plays on. The file outside the clip's region — before its Start marker and after its End marker, or outside its brace once the loop has started — is drawn dimmed. The Arrangement draws a warped clip's waveform through the same mapping. (S3, S8; the dimming is Beatlayer's own)
- **R5.** Over the waveform the editor draws: the warp markers as handles reaching down from the editor's top, the selected ones in the selection colour; the transients as small markers along the top; a transient's pseudo-warp marker, in a quieter colour than a warp marker, while the pointer is over a transient that has no warp marker; the insert marker and the time selection; and, while the clip plays, the playhead. The Start and End markers and the loop brace are in the marker strip above it, dragged as the note editor's are ([piano-roll.md](piano-roll.md) R21, running `clip.set_region` and `clip.set_loop`). (S3, S4, S6)
- **R6.** A double-click in the editor's upper half where there's no marker makes a warp marker at the point under the pointer, snapped to the grid's nearest line on a warped clip (`clip.insert_warp_marker`); a double-click on a warp marker deletes it (`clip.delete_warp_markers`). A click on a marker selects it alone, and Cmd-click (Ctrl-click) adds it to the selection or takes it out (`clip_view.select_warp_markers`, `read`, no undo step). (S4)
- **R7.** Dragging a warp marker moves it, or every selected marker when it is one of them, along the beats (`clip.move_warp_markers`), the grabbed one landing on the nearest grid line, and Cmd (Alt on Windows) held doing the opposite of the grid's setting (I-DRAG-021); the waveform either side stretches to follow as the drag goes. Shift-dragging a selected marker moves the waveform under it instead (`clip.shift_warp_marker`), the marker staying on its beat. A drag stops short of a neighbour it would reach. Each drag is one undo step however many frames it lasts, and Esc puts the clip and the selection back. (S4, S7, S8)
- **R8.** Double-clicking a pseudo-warp marker, or dragging it, makes it a warp marker (warping R26), with Cmd (Ctrl) held also at the transients either side; dragging it then moves it as R7 does, in the same undo step. Shift-dragging a pseudo-warp marker moves its transient (`clip.move_transient`). (S4)
- **R9.** A click on the waveform away from a marker sets the editor's insert marker (`clip_view.set_insert_marker`), on the nearest grid line while snapping is on; dragging selects a span of the clip (`clip_view.select_time`) and Shift-click extends it. Clicking the scrub area under the ruler of an Arrangement clip's editor moves the song to where that point of the clip plays, by steps of the global launch quantisation while the song plays. None of these is an undo step. (S3, S7; the insert marker's and the selection's gestures are Beatlayer's own, after the Arrangement's)
- **R10.** With the Sample Editor focused: Left and Right move the selected warp markers by one step of the editing grid (S-SAMPLE-003); Cmd+Left and Cmd+Right select the previous or next marker (S-SAMPLE-004); Cmd+I inserts a warp marker at the insert marker, or at the transients of the time selection (S-SAMPLE-009, warping R25); Delete deletes the selected warp markers, or with none selected those in the time selection (S-SAMPLE-010); Cmd+Shift+I inserts a transient at the insert marker (S-SAMPLE-011); Cmd+Shift+Delete deletes the selected transients or those in the time selection (S-SAMPLE-012); Cmd+U quantises and Cmd+Shift+U opens the quantise settings (S-SAMPLE-001, S-SAMPLE-002); Shift+Left and Shift+Right with the Start marker selected move the clip's region with it (S-SAMPLE-006); Option+Left and Option+Right move the insert marker by a grid step (S-A11Y-012), and Shift+Left and Shift+Right with nothing selected start or extend a time selection (S-A11Y-013). The keymap binds every S-SAMPLE row. (S4, S7; the arrow keys' step is Beatlayer's own)
- **R11.** Z zooms to the time selection and X steps back (S-SAMPLE-007, S-SAMPLE-008), W fits the clip's content to the editor's width and H the waveform to its height (S-SAMPLE-013, S-SAMPLE-014); dragging vertically in the ruler zooms about the pointer and horizontally scrolls, and the wheel scrolls. Option+Shift+F and the Control Bar's Follow switch (S-SAMPLE-005) make the editor follow playback, as the Arrangement does ([arrangement-view.md](arrangement-view.md) R10); an edit in the editor pauses it, and Play, Stop, or a click in the Arrangement or the scrub area resumes it. (S3, S7)
- **R12.** The editor's context menu holds Set 1.1.1 Here, Warp From Here, Warp From Here (Start At …), Warp From Here (Straight), Warp … BPM From Here, Warp as x-Bar Loop, and with a time selection Warp Selection as x-Bar Loop; Insert Warp Marker, Delete Warp Marker, Insert Transient, Delete Transient and Reset Transients; Quantize; Crop Clip Sample, and with a time selection Crop Clip Sample to Time Selection ([audio-clip-editing.md](audio-clip-editing.md)); and Show in Browser. Each runs the command its spec names, and an item whose command would refuse the clip, such as a warp command on an unwarped clip, is drawn disabled. (S4, S7; the items' order is Beatlayer's own)
- **R13.** While the Sample Editor has focus, the Create menu shows Insert Warp Marker, Insert Transient and Delete Transient and runs their commands, and the Edit menu's Quantize (M-EDIT-035) runs `clip.quantize_audio`; Quantize Settings… (M-EDIT-036) is the note editor's ([piano-roll.md](piano-roll.md) R19). (S7)
- **R14.** The Audio Utilities panel sits in the panels' right group on an audio clip (L-CLIP-003, L-CLIP-008) and holds, in order: the Warp switch (`clip.set_warp`) and the Warp Mode chooser (`clip.set_warp_mode`), with the chosen mode's own controls (`clip.set_warp_settings`; [warp-modes.md](warp-modes.md)); the BPM field with ×2 and ÷2 (R15); the Lead/Follow switch on an Arrangement clip (`clip.set_tempo_leader`); Reverse ([audio-clip-editing.md](audio-clip-editing.md)); Edit (R16); Clip Fade on a Session clip; RAM and HiQ (`clip.set_ram_mode`, `clip.set_high_quality`; [warp-modes.md](warp-modes.md)); Gain (`clip.set_gain`, in dB, down to −∞ dB, rule G1); and Transpose in semitones with Detune in cents beside it (`clip.set_pitch`; [warp-modes.md](warp-modes.md)). Each control runs its command, and one whose package isn't built is drawn pending — quiet, unusable, and announced to assistive technology with the package that brings it — as the Settings page draws its rows ([audio-clips.md](audio-clips.md) R22). With several clips selected, the panel shows what they share and, on a control whose values differ, their range. (S2, S5, S6)
- **R15.** The BPM field shows the tempo of the segment that starts at the selected warp marker, or with none selected the first segment's (warping R9): typing a tempo or dragging the field sets it (`clip.set_segment_bpm`), finely with Shift held (I-DRAG-022), and ×2 and ÷2 run `clip.scale_tempo`. With Warp off, the BPM field, ×2, ÷2, the Warp Mode chooser and the Lead/Follow switch are disabled, and so is the Main Properties panel's Loop switch (warping R14). (S2, S7)
- **R16.** Edit (`clip.edit_sample`, `external`) opens the clip's file in the editor the File & Folder page's Sample Editor row names (L-SET-015), or opens that page when it names none. When Beatlayer comes to the front again and the file's content has changed, the edited file is new media, and every clip in the set that played the old file plays the new one, in one undo step, each keeping its warp markers only if the file kept its length to the frame (warping R27). (S2; when Beatlayer looks for the change is Beatlayer's own)
- **R17.** The title bar's Save Default Clip button, on an audio clip (L-CLIP-002), runs `clip.save_default` (warping R42) for the clip, or for each selected audio clip. (S1, S6)
- **R18.** A file dropped from the browser on the Clip View replaces the shown clip's file (`clip.replace_sample`, `edit`, one undo step; I-DROP-009): the clip keeps its gain and pitch, and its warp markers only as warping R27 says. (S5, S7)
- **R19.** With several audio clips selected, the editor shows the first of them, and its marker edits are made to every selected clip whose file is as long as the shown clip's, in one undo step (warping R11); a clip of another length is left alone. (S4, S5)
- **R20.** The editor reaches assistive technology: the waveform as a region naming the clip and its file, and each warp marker, transient, Start and End marker and the loop brace as an item with its role, its name, and its value (its beat and its time in the file), the selected ones marked as selected. Every action the mouse does has a key or a menu item that does it too (R10, R12, R13). (S7, S8)
- **R21.** Every gesture, key, button and menu item in the editor and the panel runs a registered command an agent runs too: the edits are [warping.md](warping.md)'s and [warp-modes.md](warp-modes.md)'s, and `clip_view.select_warp_markers`, `clip_view.set_insert_marker`, `clip_view.select_time`, the zoom commands and Follow are `read`, changing the view and never the set. (S8, S9)
- **R22.** A frame builds only what's in view: the peaks of the visible span, and the markers and transients inside it, found by binary search, so a ten-minute file with a warp marker on every bar draws as quickly as a one-bar loop. (S8)
