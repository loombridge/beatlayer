## Commands

### `scene.create`

**Insert Scene**. Permission: `edit`. Contexts: `session`.

Inserts a new empty scene at `index` among the scenes, as Create ▸ Insert Scene (Cmd+I) does: it holds an empty slot in every audio and MIDI track. A new set opens with eight scenes. `id` must be a new ID the project has issued for it.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `id` | [`SceneId`](README.md#sceneid) | yes | The new scene's ID. |
| `index` | integer, at least 0 | yes | Where it goes among the scenes, from 0 to the number of scenes. |

Result: [`ChangeSet`](README.md#changeset).

### `scene.delete`

**Delete Scene**. Permission: `destructive`. Contexts: `session`.

Deletes a scene, and the clips in its slots with it; the clips in the other scenes stay. Undo restores everything it deleted, but because it removes the person's work an agent asks first.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `scene` | [`SceneId`](README.md#sceneid) | yes | The scene. |

Result: [`ChangeSet`](README.md#changeset).

### `scene.duplicate`

**Duplicate Scene**. Permission: `edit`. Contexts: `session`.

Copies a scene and the clips in its slots into a new scene directly after it, as Edit ▸ Duplicate does. `clips` lists every track that holds a clip in the scene, each with the new ID its copy takes; each copy is an independent clip. A scene whose slots are all empty copies no clips. `id` must be a new ID the project has issued for it.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `scene` | [`SceneId`](README.md#sceneid) | yes | The scene. |
| `id` | [`SceneId`](README.md#sceneid) | yes | The new scene's ID. |
| `clips` | array of pair of [`TrackId`](README.md#trackid) and [`ClipId`](README.md#clipid) | yes | Each track that holds a clip in the scene, with the new ID its copy takes, each track once. |

Result: [`ChangeSet`](README.md#changeset).

### `scene.move`

**Move Scene**. Permission: `edit`. Contexts: `session`.

Moves a scene to `index` among the scenes, with the clips in its slots, as dragging a scene does. The index counts positions after the scene is taken out of its current place, so moving a scene down past its neighbour is its current index plus one.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `scene` | [`SceneId`](README.md#sceneid) | yes | The scene. |
| `index` | integer, at least 0 | yes | Where it goes among the scenes. |

Result: [`ChangeSet`](README.md#changeset).

### `scene.rename`

**Rename Scene**. Permission: `edit`. Contexts: `session`.

Renames a scene. A name may be empty: a scene without a name shows its number, which is its position.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `scene` | [`SceneId`](README.md#sceneid) | yes | The scene. |
| `name` | string | yes | The new name. |

Result: [`ChangeSet`](README.md#changeset).

### `scene.set_colour`

**Change Scene Color**. Permission: `edit`. Contexts: `session`.

Colours scenes with swatch `colour` of the palette of 5 rows of 14 (0 to 69, numbered from the top row's left, row by row: swatch 14 is row 2, colour 1), or clears their colour with null, as a new scene has none.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `scenes` | array of [`SceneId`](README.md#sceneid) | yes | The scenes, each listed once. |
| `colour` | integer or null | no | The swatch, or `null` for none. |

Result: [`ChangeSet`](README.md#changeset).

### `scene.set_follow_actions`

**Set Scene Follow Actions**. Permission: `edit`. Contexts: `session`.

Changes a scene's follow actions, as the Scene View does: what the scene does after it was launched, over the scenes as a clip's do over its track's slots. `enabled` is the Follow Action switch; `action_a` and `action_b` are one of `no_action`, `stop`, `play_again`, `previous`, `next`, `first`, `last`, `any`, `other` and `jump`; `chance_a` is action A's chance in whole percent, 0 to 100, and action B has the rest; `jump_a` and `jump_b` are the slot (scene) numbers Jump goes to, 1 up to the number of scenes, and 0 for none, where Jump stops the scene; `linked` is Longest (on by default): the follow time is the multiplier times the scene's longest clip; off: `time`; `multiplier` is the Linked multiplier, a whole number from 1; and `time` is the Unlinked follow time in ticks, from a sixteenth (a bar is 2822400 ticks in 4/4). Fields left out stay as they are, and a number past its limit is held at the limit. One undo step. The defaults are off, A Next, B No Action, 100 %, Linked, 1x, one bar. While the song plays the action runs when the follow time has passed after the scene started, and the global switch (`session.set_follow_actions_enabled`) must be on.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `scene` | [`SceneId`](README.md#sceneid) | yes | The scene. |
| `action_a` | [`FollowAction`](README.md#followaction) or null | no | Action A. |
| `action_b` | [`FollowAction`](README.md#followaction) or null | no | Action B. |
| `chance_a` | integer or null | no | The chance of action A in whole percent, 0 to 100; B has the rest. |
| `enabled` | boolean or null | no | The Follow Action switch. |
| `jump_a` | integer or null | no | The slot (scene) number action A's Jump goes to: 1 up to the number of scenes, and 0 for none. |
| `jump_b` | integer or null | no | The slot (scene) number action B's Jump goes to. |
| `linked` | boolean or null | no | Linked (on a scene, Longest) or Unlinked. |
| `multiplier` | integer or null | no | The Linked multiplier, a whole number from 1. |
| `time` | [`Ticks`](README.md#ticks) or null | no | The Unlinked follow time in ticks, from a sixteenth. |

Result: [`ChangeSet`](README.md#changeset).

### `scene.set_info_text`

**Edit Info Text**. Permission: `edit`. Contexts: `session`.

Sets the info text of a scene, which the Info View shows while the pointer is over it (Edit Info Text). Empty clears it. One undo step, `Change Info Text`.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `scene` | [`SceneId`](README.md#sceneid) | yes | The scene. |
| `info_text` | string | yes | The text. |

Result: [`ChangeSet`](README.md#changeset).

### `scene.set_tempo`

**Set Scene Tempo**. Permission: `edit`. Contexts: `session`.

Gives a scene a tempo, from 20 to 999 BPM, that launching the scene sets for the set, as the Tempo field in the Main column and the Scene View does. `tempo` left out or null switches the scene's tempo off, as double-clicking the field or Return to Default does, so launching it leaves the set's tempo as it is. One undo step.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `scene` | [`SceneId`](README.md#sceneid) | yes | The scene. |
| `tempo` | [`Bpm`](README.md#bpm) or null | no | The tempo, or `None` for none of its own. |

Result: [`ChangeSet`](README.md#changeset).

### `scene.set_time_signature`

**Set Scene Time Signature**. Permission: `edit`. Contexts: `session`.

Gives a scene a time signature that launching the scene sets for the set, as the Signature field in the Main column and the Scene View does: a numerator from 1 to 99 over a denominator of 1, 2, 4, 8, or 16. `signature` left out or null switches the scene's signature off, so launching it leaves the set's signature as it is. One undo step.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `scene` | [`SceneId`](README.md#sceneid) | yes | The scene. |
| `signature` | [`TimeSignature`](README.md#timesignature) or null | no | The signature, or `None` for none of its own. |

Result: [`ChangeSet`](README.md#changeset).
