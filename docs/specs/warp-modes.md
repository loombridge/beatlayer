## The behaviour

A warped audio clip's warp map ([warping.md](warping.md)) says where each moment of its file lands in the song, and so how fast the clip has to read its file: its *speed*, the file frames it plays per song frame ([warping.md](warping.md) R12), which is 1 where the song's tempo equals the tempo of the warp segment playing and 2 where the song runs at twice that. The clip's warp mode decides how the audio is made to fit: Re-Pitch plays it faster or slower, so its pitch moves with the speed, like a turntable; the other five keep its pitch and change only its timing, each in its own way and for its own kind of material. Beats cuts the audio into segments at its transients or on a beat grid and starts each one on its beat, filling or cutting the time between them; Tones and Texture rebuild it from overlapping grains, Tones following the pitch of pitched material and Texture ignoring pitch, with some randomness; Complex and Complex Pro, for full mixes, work in the frequency domain through Signalsmith Stretch (D11), and Complex Pro can keep a voice's formants in place when its pitch moves. The clip's Transpose and Detune shift its pitch through whichever mode it uses (Re-Pitch ignores them), its Gain scales what the mode puts out, RAM holds its file in memory instead of streaming it, and HiQ chooses a better interpolator wherever the clip's audio is resampled as it plays.

Live leaves an unstretched clip in Beats, Tones, Texture and Re-Pitch untouched, sample for sample, and Beatlayer keeps that promise (R4). Every one of the clip's sound settings, Formants included, can be automated along the song, drawn as a clip envelope, and modulated (rule G2, IMP-09), beyond the gain, transposition and Beats sample-offset envelopes the manual describes for a clip. The last rules set Beatlayer's own measured quality targets for each mode, which a measurement package checks across tempos.

This spec covers what each mode does with the audio, its controls, the clip's pitch, gain, RAM and HiQ, what changing them does to a playing clip, and the clip's settings as parameters for automation, clip envelopes and modulation. It leaves to [warping.md](warping.md) the Warp switch, the warp map and its markers, the segment BPM, transients and their detection, a warped clip's loop and markers in beats, which clips may loop, and the Default Warp Mode setting; to [audio-clip-editing.md](audio-clip-editing.md) Reverse, Crop and Consolidate; to [audio-clips.md](audio-clips.md) the clip's region, fades and streaming; to [clip-envelopes.md](clip-envelopes.md) and [automation.md](automation.md) envelopes themselves; and to [sample-editor.md](sample-editor.md) (WP-4.10) how the Audio Utilities panel draws these controls (L-CLIP-008), which run this spec's commands.

## Rules

**Every mode (WP-4.2, and each mode's package for its own)**

- **R1.** A warped audio clip plays through one of six warp modes, offered in this order: Beats, Tones, Texture, Re-Pitch, Complex, Complex Pro. The mode decides how the clip's audio is fitted to the speed its warp map sets and shifted to the pitch its Transpose and Detune set; where each moment of the file lands in the song is the warp map's, the same in every mode ([warping.md](warping.md)). A new warped clip takes its mode from the Default Warp Mode setting, Beats in a new install ([warping.md](warping.md) R29 and R33). An unwarped clip keeps its mode and every setting, which act again when Warp goes back on. (S1 to S5, S10, S16)
- **R2.** Each mode has the controls in this table, with these values and defaults; Re-Pitch and Complex have none. A clip keeps every mode's settings at once, so changing its mode and changing it back restores them (Beatlayer's own). "Beatlayer's own" marks a value the manual doesn't give. (S1, S2, S4)

  | Mode | Control | Values | Default |
  |---|---|---|---|
  | Beats | Preserve | Transients, or a grid division of the clip's beats: 1 Bar, 1/2, 1/4, 1/8, 1/16, 1/32 (the manual names grid divisions, and 1/16 and 1/32 elsewhere, S6, S8; the list is Beatlayer's own) | Transients (Beatlayer's own) |
  | Beats | Transient Loop Mode | Loop Off, Loop Forward, Loop Back-and-Forth | Loop Forward (Beatlayer's own) |
  | Beats | Transient Envelope | 0 to 100, in whole numbers | 100 (Beatlayer's own) |
  | Tones | Grain Size | 10 to 100 ms (Beatlayer's own) | 30 ms (Beatlayer's own) |
  | Texture | Grain Size | 10 to 500 ms (Beatlayer's own) | 65 ms (Beatlayer's own) |
  | Texture | Flux (the manual's Fluctuation) | 0 to 100 % (Beatlayer's own) | 25 % (Beatlayer's own) |
  | Complex Pro | Formants | 0 to 100 % | 100 % (Beatlayer's own) |
  | Complex Pro | Envelope | 8 to 512, in whole numbers (Beatlayer's own range) | 128 |

  Every clip, in every mode, also has Transpose, −48 to 48 semitones in whole semitones (the limit the manual gives for Transpose with its envelope, S6; the control's own range is Beatlayer's own), 0 by default; Detune, −50 to 50 cents (Beatlayer's own range), 0 by default; Gain ([audio-clips.md](audio-clips.md) R5); RAM, off by default (Beatlayer's own); and HiQ, on by default (Beatlayer's own). (S5, S6)
- **R3.** Every setting changes through a registered command (D17) in the `edit` class, one undo step, run by ID with JSON arguments, which refuses a MIDI clip and a value outside R2's range and then leaves the document as it was: `clip.set_warp_mode`; `clip.set_warp_settings`, which sets any of R2's controls, named by mode, one or several in one step; `clip.set_pitch`, which sets Transpose, Detune or both; `clip.set_ram_mode`; and `clip.set_high_quality`. Gain stays `clip.set_gain` ([audio-clips.md](audio-clips.md) R15). Each reads back through the query tool's `clip` object, under `data.audio`: `warp_mode`, `warp_settings`, `transpose`, `detune`, `ram`, `high_quality` and `gain`. The set saves every setting, each written only where it differs from a new clip's, so a set saved before these settings existed loads with every clip at R2's defaults. (S11, S15)
- **R4.** Where a warped clip's speed is exactly 1, its pitch change (R25) is 0, and no envelope or automation moves its pitch, Beats, Tones, Texture and Re-Pitch play the file's frames unchanged: each song frame plays the file frame nearest the position the warp map gives, as an unwarped clip is aligned ([audio-clips.md](audio-clips.md) R3), so a clip at 0 dB with no fades adds its file's samples to the bit. This holds in Beats at any Preserve and Transient Loop Mode with Transient Envelope at 100, and in Tones and Texture at any Grain Size and Flux. Warping leaves no trace in the clip: played at another tempo, then at its own again, it is neutral again wherever its speed is back at 1. (S8, S11)
- **R5.** Each playing clip's mode keeps its state (its grains or segments, its stretcher, and the audio it has read around the playhead) in memory made with the track's clip list, off the audio thread, and freed on the drop thread. Nothing a mode does on the audio thread allocates, locks or blocks, and its work in a block is bounded by the block's frames. (S15)
- **R6.** A mode's output depends only on the song, its media, and the frame the clip's playback began on (its start, a launch, a locate, or a jump), never on the block size: a render is the same to the bit at any block size, run after run. Texture's randomness comes from a generator seeded from the clip, so it repeats in every render. (S11, S15)
- **R7.** A start, a launch, a locate, or the Arrangement loop's wrap into a warped clip plays from the new point on its exact frame ([audio-clips.md](audio-clips.md) R10 and R21), each mode starting afresh there: Beats from the segment the point falls in, Tones and Texture with a grain starting at the point, and Complex and Complex Pro primed with the audio before the point, so the clip is at its level from the first frame (R35). A wrap of the clip's own loop brace doesn't restart the mode: it goes on with the audio from the brace's start as though it followed the brace's end. (S11, S16)
- **R8.** A change to a playing clip's mode, to any of R2's controls, or to its Transpose, Detune or HiQ reaches the clip's player in its track's clip list ([audio-clips.md](audio-clips.md) R12), with no new program, and the clip keeps its place in its warp map. A new mode takes over from the first frame of the block the list arrives in, its output crossfaded from the old mode's in a straight line over 20 ms, the span a continuous parameter glides over ([device-framework.md](device-framework.md) R4; the crossfade is Beatlayer's own). A changed setting acts from the mode's next grain, segment or processing step. Beatlayer applies these changes when they arrive, without waiting for the Clip Update Rate (Beatlayer's own). (S5, S11, S13)

**Re-Pitch, RAM, HiQ and Gain (WP-4.2)**

- **R9.** Re-Pitch reads the file at the clip's speed and changes nothing else, so pitch and tempo move together: at speed *s* the audio sounds 12·log₂ *s* semitones from its own pitch, an octave up at twice the speed. Between the file's frames it interpolates, through the interpolator HiQ chooses (R12). (S3, S16)
- **R10.** In Re-Pitch, Transpose, Detune, and the clip's transposition and Detune envelopes and automation don't act, and the Audio panel draws Transpose and Detune switched off (L-CLIP-008). Their values stay with the clip and act again in another mode. Switching Detune and the envelopes off with Transpose is Beatlayer's own reading of the manual, which says only that the clip's transposition is switched off. (S3, S18)
- **R11.** With RAM on, the clip's whole file is held in memory at the engine's rate, decoded on the loader thread and shared with every other reader of that file held in memory, so the clip never reads the disk while it plays and never underruns; with RAM off it streams as [audio-clips.md](audio-clips.md) R17 says, and a file shorter than 10 seconds is in memory either way. RAM changes nothing the clip plays: a render is the same to the bit with it on or off. Switching it while the clip plays leaves no gap and no step: switched on, the clip reads its stream until the file is in memory, then reads memory from the next block at the same frame; switched off, it reads memory until a stream has preloaded the point it has reached, then the stream. (S5, S9, S11)
- **R12.** HiQ chooses the interpolator through which a clip's audio is read wherever that read runs at a rate other than 1 as the clip plays: Re-Pitch at any speed but 1, and a pitch change in Beats, Tones and Texture and on an unwarped clip (R17, R20, R27). On, it is a band-limited interpolator that meets R36's HiQ targets; off, a cheaper one that meets R36's standard targets. (WP-4.2 builds a Kaiser-windowed sinc of 64 taps for on, widened in proportion to the speed above 1 so its cutoff stays below the output's Nyquist frequency, and a four-point cubic for off; WP-4.19 measures them against R36 and tunes them.) Where no such rate change happens, HiQ changes nothing (R4). Converting a file to the engine's rate isn't HiQ's: Beatlayer does that once, when the file loads, at [audio-import.md](audio-import.md) R6's quality, whatever HiQ says. Complex and Complex Pro, which shift pitch in the frequency domain, sound the same with HiQ on or off (Beatlayer's own). (S5, S8, S17)
- **R13.** A clip's Gain scales what its mode puts out, after the mode, with its fades, as [audio-clips.md](audio-clips.md) R5 and R6 say: at 0 dB it adds the mode's output unchanged, and at −∞ dB it is silent (G1). (S5, S11, S14)

**Beats (WP-4.4)**

- **R14.** Beats plays the clip as segments. With Preserve at Transients, a segment begins at the clip's Start marker, at each warp marker (Beatlayer's own), and at each of the file's transients ([warping.md](warping.md)); at a grid division, a segment begins at each line of that grid in the clip's own beats, counted from the clip's 1.1.1, whatever the transients. Each segment starts on the song frame its beginning falls on through the warp map (the nearest frame) and reads the file from there at the clip's pitch ratio (R25), which is the file's own rate when the clip isn't transposed. (S1, S16)
- **R15.** A segment sounds until the next one begins, and stops there, so a song faster than the clip cuts each segment short. Where a segment runs out of its own audio first (the file up to where the next segment begins), as it does when the song is slower than the clip or the clip is transposed up, Transient Loop Mode fills the rest: Loop Off leaves silence until the next segment; Loop Forward goes back to the zero crossing nearest the segment's middle and plays to its end again, as often as the time needs; Loop Back-and-Forth plays backwards from the end to that zero crossing, then forwards to the end, and so on. The zero crossing is the sign change of the channels' sum nearest the middle (Beatlayer's own), so each turn joins the audio without a step. (S1)
- **R16.** Transient Envelope shapes each segment's level, by Beatlayer's own law within the manual's two ends: at 100 nothing fades; below 100, a segment holds its full level for that percentage of the time from its beginning to the next segment's, then falls in a straight line to silence over 10 ms, or by the next beginning if that comes first. At 0 a segment starts to fall at once, so each one dies away almost at once; values just under 100 fade only each segment's last moment, which smooths its join with the next; values between gate the sound in time with its segments. (S1)
- **R17.** A Beats clip's pitch changes at each segment's beginning: a new pitch, from Transpose, Detune, an envelope or automation, acts from the next segment, read at the new ratio through HiQ's interpolator, so a finer Preserve grid follows a pitch envelope more closely. (S1, S6)

**Tones and Texture (WP-4.5)**

- **R18.** Tones rebuilds the clip from overlapping grains taken from the file where its warp map reads (Beatlayer's own method, made to keep what the manual says Tones keeps: the pitch of pitched audio). Where the audio has a clear pitch, each grain spans a whole number of its pitch periods, as near to Grain Size as that allows, and grains are placed whole periods apart, so a steady tone keeps its pitch and its waveform; where the pitch isn't clear, grains are Grain Size long. Grain Size so sets the grains' average length, and the material sets each one's. (S2)
- **R19.** Texture rebuilds the clip from overlapping, crossfaded grains Grain Size long, without regard to the audio's pitch. Flux moves each grain's place in the file and its length by a random amount of up to Flux's share of Grain Size; at 0 % the grains fall regularly and nothing is random. Flux's randomness is seeded from the clip (R6). (S2)
- **R20.** In Tones and Texture a pitch change resamples each grain by the pitch ratio, through HiQ's interpolator, so the pitch moves and the timing doesn't, and the clip's formants move with its pitch. A new pitch acts from the next grain, so a smaller Grain Size follows a pitch envelope more closely. (S2, S6)

**Complex and Complex Pro (WP-4.6)**

- **R21.** Complex and Complex Pro are built on Signalsmith Stretch (D11), which changes speed and pitch independently in the frequency domain, for mixed material such as whole songs. Complex uses the library's default configuration; Complex Pro a finer one, at more CPU (Beatlayer's own). Neither is neutral, even at speed 1 with no pitch change. In Complex, the clip's formants move with its pitch. (S4, S8, S15)
- **R22.** Complex Pro's Formants sets how far the clip's formants stay put when its pitch moves: at 100 % they stay where they were however far the pitch moves; at 0 % they move with the pitch, as in Complex; between, they move by the rest of the pitch change, in semitones (at 25 %, by three quarters of it; Beatlayer's own). With no pitch change, Formants and Envelope change nothing: the output is the same to the bit at any of their values. (S4)
- **R23.** Complex Pro's Envelope sets the detail of the spectral envelope the formants are kept by, as the fundamental the formant analysis allows for: 128 suits most material, lower values suit high-pitched audio, and higher values low-pitched. It changes the output only where the pitch changes and Formants is above 0 %. (S4)
- **R24.** Complex and Complex Pro read the file ahead of the playhead by their stretcher's latency, so the clip's audio lands where its warp map places it (within R35's timing target), and the clip's player reports no latency to delay compensation. (S15, S16)

**Transpose and Detune (WP-4.7)**

- **R25.** A clip's pitch change, in semitones, is its Transpose plus its transposition envelope's and automation's values, the sum held to −48 to 48, plus its Detune plus its Detune envelope's and automation's values, in cents, the sum held to −50 to 50 and divided by 100 (100 cents to the semitone). Its pitch ratio is 2 raised to that change over 12. (S5, S6)
- **R26.** In Beats, Tones, Texture, Complex and Complex Pro, the pitch ratio changes the clip's pitch and leaves its timing to its warp map: every moment of the file lands where it would untransposed, and a steady tone sounds at its own pitch times the ratio, within R35's 1 cent. Beats does it per segment (R17), Tones and Texture per grain (R20), and Complex and Complex Pro in their stretcher (R21, R22). In Re-Pitch they don't act (R10). (S1 to S4)
- **R27.** With Warp off, Transpose and Detune change the clip's speed and pitch together, as a tape running faster does: the file is read at the pitch ratio, through HiQ's interpolator, from its Start marker at the clip's start, so a clip transposed up an octave runs through its file twice as fast (Beatlayer's own). The transposition and Detune envelopes act only while Warp is on. (S5, S6, S8)

**Automation, clip envelopes and modulation (WP-4.8)**

- **R28.** Each of a clip's sound settings is a parameter with a descriptor ([device-framework.md](device-framework.md) R1), with R2's range and default: Gain (a gain, from −∞ dB to +24 dB, the top Beatlayer's own), Transpose (a whole number), Detune (continuous, in cents), HiQ (a switch), and every control in R2's table (Preserve and Transient Loop Mode choices, Transient Envelope and Envelope whole numbers, the rest continuous). Every one can be automated, drawn as a clip envelope, and modulated (G2, IMP-09), and a test fails for one that can't. The Warp switch, the warp mode, RAM, and the clip's markers and loop are the clip's structure rather than its sound, and aren't targets (Beatlayer's own). (S7, S13, S14)
- **R29.** An audio clip's clip envelopes can name its sound settings: the Envelopes tab's device chooser offers "Clip" (L-CLIP-017), whose controls are the ones the manual names for it first (Gain, Transposition and, in Beats, Sample Offset), then Beatlayer's additions in R2's order: Detune, HiQ, and the controls of the clip's mode. Gain's envelope scales the clip's Gain by a share from 0 to 100 %, so it can take the clip to silence but never above its Gain; Transposition's adds semitones to Transpose (R25); each of the rest adds its value, in the setting's own units, to the setting's own or automated value, clamped to its range ([clip-envelopes.md](clip-envelopes.md) R3), a choice or a switch taking the step nearest the sum. Each acts at the frame where its mode next reads it (R8). (S6, S12, S18)
- **R30.** Sample Offset, in Beats only, moves where in the clip's audio each segment is taken from by the envelope's value, in sixteenth notes of the clip's beats, from −8 to 8: a positive value takes the audio from later in the clip, a negative one from earlier, and a falling ramp slows the clip's way through its audio. It acts at each segment's beginning (R14); audio taken from outside the file is silence (Beatlayer's own). In another mode the envelope stays with the clip and does nothing. (S6)
- **R31.** A track's automation lane offers "Clip" in its device chooser too, above the track's devices and mixer (Beatlayer's own, IMP-09), with R29's controls. Its envelope drives that setting for each of the track's audio clips as it plays in the Arrangement, at the frame the clip's mode next reads it, as a track envelope drives a device's parameter ([automation.md](automation.md) R3), and a hand change to a clip's setting overrides it as [automation.md](automation.md) R5 says. A clip envelope modulates the automated value (R29), and automation of one mode's control does nothing to a clip in another mode. (S7, S12, S14)
- **R32.** These envelopes are made, edited, saved and undone with automation's and clip envelopes' own commands ([automation.md](automation.md) R7, [clip-envelopes.md](clip-envelopes.md) R5), their target given as `{"type": "clip", "param": …}`; each edit is one undo step, and each reads back where those commands' edits do, in the track's `automation` and the clip's `envelopes`. An envelope for a control of a mode the clip isn't in stays with the clip and acts when the clip is in that mode again. A set saved before these targets existed loads unchanged. (S12, S15)
- **R33.** Each mode reads its settings' values through automation's read path ([automation.md](automation.md) R10, [clip-envelopes.md](clip-envelopes.md) R4): the value for the frame where it applies them, allocating nothing, so a render is the same at any block size. A modulator reaches these parameters as it reaches any device's: the value is the base, from the setting or its automation, plus every modulation source, clamped to the range (the architecture's "Parameters, automation, and modulation"). (S12, S15)

**Measured quality targets (WP-4.19)**

- **R34.** The targets are Beatlayer's own, not measurements of Live. They are measured at an engine rate of 48 kHz on fixtures generated by a script in `tests/fixtures/gen/`: a 440 Hz sine and a band-limited 220 Hz sawtooth (harmonics to 10 kHz), steady, at −6 dBFS; pink noise; a 120 BPM drum loop of synthesised kick, snare and hats with known hit times; a vowel made of a 150 Hz pulse train through resonators at 700, 1,220 and 2,600 Hz; and a logarithmic sine sweep from 20 Hz to 20 kHz at −6 dBFS. Each is a clip warped at 120 BPM in songs at 60, 90, 120, 180 and 240 BPM (speeds 0.5, 0.75, 1, 1.5 and 2), each mode at R2's defaults, and transposed by −12, −7, 7 and 12 semitones where a target names a pitch change. Pitch is the strongest spectral peak's frequency over one-second windows, interpolated; level is RMS over the steady part; onsets are `bl-analysis`'s; the spectral balance is `bl-analysis`'s octave bands from 63 Hz to 16 kHz, relative to the source's. (S15)
- **R35.** Each mode meets these targets at every speed and transposition R34 names:

(S5, S8)
