## The behaviour

A set plays twelve equal steps to the octave until a tuning system is loaded into it. A tuning comes from a Scala `.scl` file, or an `.ascl` file, which is a `.scl` file whose comments carry more: the tuning's note names, its reference pitch and its note range. A tuning divides an octave, or a pseudo-octave of another size, into its own steps, and once it is loaded each key of a MIDI clip is a step of the tuning, not a key of the twelve-step keyboard. The set holds one tuning at a time and keeps it inside the set file, so the set opens with it without the file.

The browser's Tuning section shows the loaded tuning: its name, the reference pitch (an octave, a note and a frequency, which tunes the whole set up or down), and its lowest and highest notes, which say which of its notes the keys play. A button saves it as an `.ascl` file, and Delete removes it, putting the set back to twelve equal steps. A MIDI track can bypass the tuning, and a track with a Drum Rack always does. Native instruments play each key at the tuning's pitch for it; a plug-in hears the tuning as per-note pitch bend over a 48-semitone range, so only plug-ins that take per-note pitch play in tune. The MIDI Controller Layout of a track lays the tuning's notes onto a keyboard's keys in one of several ways. With Retune Set On Loading Tuning Systems on, loading a tuning moves the set's notes to the keys nearest their old pitches; with it off, notes keep their keys and may sound at other pitches.

While a tuning that doesn't hold twelve notes to its pseudo-octave is loaded, the scale controls are hidden and scale-aware devices can't follow the scale. In the note editor the rows become the tuning's notes, with its names, and hovering a note shows its pitch and frequency. Beatlayer ships tunings of its own, each generated by a script from its mathematical definition. The Tuner names the notes of the set's tuning.

## Rules

**The set's tuning (WP-6.9)**

- **R1.** A set holds at most one tuning. With none, it plays twelve equal steps to the octave: key k sounds at 440 × 2^((k − 69) / 12) Hz, A3 (key 69) at 440 Hz, as Beatlayer's instruments play today. (S1)
- **R2.** `tuning.load` (`external`) reads a `.scl` or `.ascl` file and makes it the set's tuning, in place of any other, as one undo step, `Load Tuning` (Beatlayer's own name). A file it can't read, or one that breaks R3, is refused with an error naming the problem, and the set's tuning stays as it was. (S1, S2, S6, S7)
- **R3.** A `.scl` file is read as the Scala format says (S8): comments skipped, the description, the number of notes n, then n pitches, the last of them the pseudo-octave, with degree 0 the unison. A pitch in cents may be negative and the pitches needn't rise in order; every one of them is used. A file is refused if it holds no pitches, a count that doesn't match the lines that follow, a ratio of 0 or less, or a pseudo-octave at or below the unison. (S1, S7, S8)
- **R4.** An `.ascl` file is read as a `.scl` file (R3) and its comments can also carry the tuning's note names, one per degree; its reference pitch (R7); its note range (R8), as the lowest and highest notes or as a lowest and a highest frequency, the range then stopping at the last note at or below the highest frequency; and a link to a page about the tuning. Beatlayer reads these where the file has them and ignores comments it doesn't know. (S1, S3, S7)
- **R5.** A tuning's name is its file's name without the extension, kept whole, a dash followed by a number included. (S7)
- **R6.** The note at octave o and degree d (0 to n − 1) sounds at f × P^(o − o₀) × r(d) / r(d₀) Hz, where f, o₀ and d₀ are the reference pitch's frequency, octave and degree (R7), r(d) is degree d's ratio (r(0) = 1) and P is the pseudo-octave's ratio. (S1, S3)
- **R7.** The reference pitch is an octave, a degree of the tuning (its Note) and a frequency in Hz. A tuning takes it from its `.ascl` file, or else octave 3, degree 0 and 261.626 Hz, C3 of twelve equal steps at A3 = 440 Hz (the degree and frequency are Beatlayer's own). `tuning.set_reference` (`edit`) sets any of the three, as one undo step, `Change Reference Pitch`. Changing the octave or the degree changes only which note the reference names: the frequency becomes that note's present frequency, and nothing sounds different. Changing the frequency moves every pitch of the set by the same ratio. (S3, S6)
- **R8.** The tuning's notes, in order of octave and degree, lie on keys from key 0 up, one step of the tuning to a key: key 0 plays the Lowest Note and each key above it the next note, to the Highest Note, at most 128 notes; keys above the Highest Note play nothing (Beatlayer's own). Lowest Note and Highest Note are an octave and a degree each. `tuning.set_range` (`edit`), one undo step, `Change Tuning Range`, sets one of them and moves the other by as many notes, so the count stays the same; a range that would hold more than 128 notes or start above its end is refused. A tuning takes its range from its `.ascl` file, or else the 128 notes that put degree 0 of the reference's octave on key 60 (Beatlayer's own). (S3, S7)
- **R9.** `tuning.remove` (`destructive`) removes the set's tuning and returns it to twelve equal steps (R1), as one undo step, `Remove Tuning`. (S3, S6)
- **R10.** `tuning.save` (`external`) writes the set's tuning, with its present reference pitch, range and note names, as an `.ascl` file named after it in the User Library's Tunings folder, which the app makes with the others ([browser.md](browser.md) R3), written whole or not at all; a name already taken there gets a number after it (Beatlayer's own). A file it writes reads back to the same tuning (R3, R4). (S3, S6, S10)
- **R11.** The set saves its tuning inside the set file: its name, description, pitches, note names, link, reference pitch and range. A set opens with its tuning whether or not its file is still there, and a set saved before tunings opens with none. (S2)
- **R12.** On a MIDI track that doesn't bypass the tuning (R14), a native instrument plays each key at the tuning's pitch for it: where it played key k at 12 × log₂(f₁₂(k) / 440) + 69 semitones, it plays it at 12 × log₂(f(k) / 440) + 69, f(k) being the key's frequency under R6 and R8 and f₁₂(k) under R1, and its transposition, detune, glide, pitch modulation and pitch envelope add to that as they add to a key without a tuning (the law is Beatlayer's own). What an instrument chooses by key — a Sampler zone, a Simpler slice, an Impulse slot, a Drum Rack pad, a Key modulation source — goes by the key number, so a tuning doesn't change which sample plays (Beatlayer's own). Each instrument's spec says which of its parts follow the tuned pitch. (S1, S6)
- **R13.** Under a tuning, a per-note pitch bend of b semitones moves a note by b steps of the tuning: it sounds at the tuned pitch of key k + b, between two keys' tuned pitches in proportion in semitones. The channel's pitch bend still moves notes by semitones (Beatlayer's own). (S7)
- **R14.** Bypass Tuning, a switch in a MIDI track's In/Out section shown while the set has a tuning (L-MIX-010), off in a new track, makes the track play twelve equal steps (R1) and its clips' editors show twelve-step keys, as one undo step, `Bypass Tuning`, saved with the set (`track.set_tuning_bypass`, `edit`). A MIDI track whose chain holds a Drum Rack plays twelve equal steps whatever the switch says, and the switch shows on and can't be changed while the rack is there (the presentation is Beatlayer's own). (S4, S6)
- **R15.** Retune Set On Loading Tuning Systems (Options ▸ M-OPT-022, ticked while on; `settings.set_retune_on_tuning_load`, `edit`) is off in a new install and kept between launches. With it off, loading, changing or removing a tuning leaves every note on its key. With it on, a dialog asks first (Retune, or Cancel to change nothing; the wording is Beatlayer's own), and then every note of every MIDI clip on a track that doesn't bypass the tuning moves to the key whose new pitch is nearest the pitch it had, the lower on a tie, in the same undo step as the load. Where two notes that overlap land on one key, the earlier is shortened to end where the later starts, and of two that start together the shorter is deleted (Beatlayer's own). `tuning.load` and `tuning.remove` take `retune`, which, left out, follows the setting. (S2)
- **R16.** While the set's tuning holds 12 notes to its pseudo-octave, scales work on its keys as on twelve equal steps' ([scales.md](scales.md) R2). While it holds any other number, the Scale Mode switch and choosers in the Control Bar and the Clip View are hidden, the note editor's scale buttons are hidden, and each scale-aware device's Use Current Scale switch is disabled and acts as off; every clip keeps its scale, and the controls come back with it when the tuning goes. (S2, S6, S7)
- **R17.** MIDI effects work on keys whatever the tuning, so under a tuning a move of n semitones is a move of n keys, n steps of the tuning. (S6)
- **R18.** The engine gives every instrument on a track that doesn't bypass the tuning the tuned pitch of each key (R12), as data sent to its node: a tuning loaded, changed or removed, a new reference pitch or range, or a track's bypass changed reaches the next notes on their frames, with no new program and nothing allocated, locked or blocked on the audio thread. A note already sounding keeps its pitch (Beatlayer's own). A render is the same at any block size. (S10)
- **R19.** `tuning.load`, `tuning.remove`, `tuning.set_reference`, `tuning.set_range`, `tuning.save`, `track.set_tuning_bypass` and `settings.set_retune_on_tuning_load` are registered commands with schemas, descriptions and permission classes, run by ID through the agent API. `tuning.state` (`read`) reports the set's tuning (its name, description, notes to the pseudo-octave, pitches, pseudo-octave, note names, link, reference pitch and range, and each key's frequency), or none, and the query tool's `song` gives the same in its `tuning` field: that is the readback for the tuning commands. The query tool's `track` reads `tuning_bypass`, and `settings.state` the retune setting. `tuning.save`'s readback is the Tunings label (R25). (S10)

**Tunings on plug-ins and MIDI controllers (WP-6.9b)**

- **R20.** A plug-in instrument plays the set's tuning when its tuning switch, an item in its title bar's context menu (C-DEVICE-015), is on: each note goes to it on the key whose twelve-step pitch is nearest the note's tuned pitch (R12, R13), with a per-note pitch bend making up the difference over a bend range of 48 semitones, through the per-note pitch WP-6.17b sends to the plug-in's format ([mpe.md](mpe.md)). The switch is on for a plug-in whose MPE mode is on and off otherwise, and saved with the device; each change is one undo step (`plugin.set_tuning`, `edit`; the default is Beatlayer's own). (S1, S6, S7)
- **R21.** A plug-in whose tuning switch is off hears plain keys, so it plays its own pitch for each key whatever the set's tuning. (S1, S6)
- **R22.** A MIDI track's MIDI Controller Layout, a chooser in its In/Out section beside Bypass Tuning (L-MIX-010), shown while the set has a tuning and disabled while Bypass Tuning is on, says which key of the tuning each key of an incoming keyboard plays, for notes from MIDI inputs and the computer MIDI keyboard as they enter the track, monitored and recorded alike: All Keys (each key plays the same key of the tuning, the default; Beatlayer's own), Black Keys Only (C#3 plays key 60 of the tuning and each black key above or below it the next key up or down; white keys play nothing), White Keys Only (the same from C3, over the white keys), Closest in Pitch to Keyboard (each key plays the key of the tuning whose pitch is nearest the key's twelve-step pitch, the lower on a tie), or Custom Controller Layout (R23). Changing it is one undo step, saved with the set (`track.set_tuning_layout`, `edit`). (S4, S7)
- **R23.** Custom Controller Layout's "…" button opens the Configure MIDI Layout dialog (L-OTH-009), which sets for each incoming key the key of the tuning it plays, or none; the layout is saved with the track. A value the set's tuning has no key for, after a tuning with fewer notes is loaded, shows unavailable and plays nothing. (S4, S7)
- **R24.** `plugin.set_tuning` and `track.set_tuning_layout` are registered commands with schemas, descriptions and permission classes; the query tool's `device` reads a plug-in's `tuning` and its `track` reads `tuning_layout` with a custom layout's keys, their readbacks. (S10)

**Tunings in the browser and the editor (WP-6.10)**

- **R25.** The browser's Tunings label (L-BRW-004) lists Beatlayer's own tunings (R31), then the `.scl` and `.ascl` files in the places ([browser.md](browser.md) R6): the User Library, the current project and the added folders. Names show without their extension (R5), and a search under the label matches them ([browser.md](browser.md) R9). With the browser's tags, the files from the places carry the User tag. (S1, S7, S10)
- **R26.** Selecting a tuning in the browser shows its description in the Info View: the file's description, its number of notes to the pseudo-octave and the pseudo-octave's size in cents (the last is Beatlayer's own). A file R3 would refuse shows the error there instead. Hovering the loaded tuning's name in the Tuning section shows the same. (S1, S7)
- **R27.** A double-click or Enter on a tuning in the browser loads it (R2) and shows the Tuning section; dropping a `.scl` or `.ascl` file from the browser or from the operating system onto the Tuning section loads it too (I-DROP-013). (S2, S9)
- **R28.** The Tuning section (L-BRW-014) sits in the browser column, hidden in a new set, and shows and hides with the Browser Config Menu's Tuning item (L-CTRL-001) and View ▸ Tuning (M-VIEW-023), both ticked while it shows (`view.tuning_section`, `read`); Navigate ▸ Tuning (M-NAV-009) shows it and gives it the keyboard focus (`focus.tuning`, `read`). It shows the loaded tuning's name, or that the set plays twelve equal steps; a triangle beside the name shows Octave, Note, Ref. Pitch, Lowest Note and Highest Note, each running R7's or R8's command, then a save button (R10) and a link button, which opens the tuning's link in the system's web browser and is unavailable when the tuning has none. With the tuning's name selected, Delete removes it (R9). Assistive technology reads each control with its name and value. (S2, S3, S9)
- **R29.** In the note editor of a clip on a track that doesn't bypass the tuning, the rows are the tuning's keys from the Lowest Note to the Highest Note, keys past the range not shown, each named by its degree's note name from the file, or by its degree's number where the file names none, followed by its octave number (the form is Beatlayer's own); on a track that bypasses it, the editor shows twelve-step keys and their names ([piano-roll.md](piano-roll.md) R12). (S2, S4, S5)
- **R30.** Hovering a note or a row in the note editor under a tuning shows in the Status Bar its name (R29) and its frequency in Hz, and the key of an incoming keyboard that plays it under the track's MIDI Controller Layout (R22). (S2, S6)
- **R31.** Beatlayer ships tunings of its own, each an `.ascl` file a script in the repository writes from its mathematical definition alone, with no third-party tuning file: equal divisions of the octave, just intonations, historical meantones and well temperaments, and at least one tuning whose pseudo-octave isn't an octave. A test runs the script and fails if a shipped file differs from what it writes, and each file reads back (R3, R4) to the pitches its definition gives, within 0.001 cent. (S1)
- **R32.** `view.tuning_section` and `focus.tuning` are registered commands with schemas and descriptions; the menu items and the Browser Config Menu run them, and loading from the browser runs `browser.load_selected`, which reads back through `tuning.state`. (S10)
- **R33.** While the set has a tuning, the Tuner, on any track but a MIDI track that bypasses the tuning (R14), names the note of the tuning nearest the pitch it hears, as the note editor names it (R29), and shows how far the pitch is from that note in cents; its Reference slider is set aside while a tuning is loaded, the tuning's own reference pitch (R7) placing its notes (Beatlayer's own). In a set without a tuning, and on a MIDI track that bypasses it, the Tuner reads twelve equal steps from its Reference, as it does without tunings. (S7, S11)
