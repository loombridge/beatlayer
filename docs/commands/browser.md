## Commands

### `browser.add_folder`

**Add Folder to Browser...**. Permission: `external`. Contexts: `global`, `browser-sidebar`.

Adds the folder at `path` to the browser's Places, after Current Project, without moving or changing it, and indexes its files in the background so search finds them. Added folders are kept between launches; adding one twice changes nothing. A person choosing the menu item or the sidebar's Add Folder... picks the folder in a dialog.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `path` | string | yes | The folder's path. |

Result: [`BrowserState`](#browserstate).

### `browser.add_tag`

**Add Browser Tag**. Permission: `edit`. Contexts: `global`, `browser`.

Makes a tag in the browser: in the group `group`, or under the tag `parent`, which makes it a subtag. A subtag can't hold another subtag. Changes the browser's database.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `name` | string | yes | The tag's name. |
| `group` | string or null | no | The group to make it in, by its name. Left out with `parent` left out too, the first group. |
| `parent` | string or null | no | The tag to make it under, by its full name or its own name. It becomes a subtag. |

Result: [`TagsState`](README.md#tagsstate).

### `browser.add_tag_group`

**Add Browser Tag Group**. Permission: `edit`. Contexts: `global`, `browser`.

Makes a tag group in the browser, named `name`, at the end of the list. Changes the browser's database.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `name` | string | yes | The group's name. |

Result: [`TagsState`](README.md#tagsstate).

### `browser.add_to_arrangement`

**Add Files to Arrangement**. Permission: `external`. Contexts: `arrangement`, `browser`.

Puts audio files into the Arrangement as clips, as dragging them from the browser does: onto the audio track `track` starting at `at` (or the insert marker), one after another; or, with no `track`, onto a new audio track below the last track (the drop area), named after the first file. With `spread`, each file goes on a track of its own, new tracks below the target. Each clip is named after its file and lasts as long as the file plays at the song's tempo. A clip placed over part of another replaces that part: the other is shortened, split around it, or removed, so a track never plays two clips at once; when a clip on `track` ends after `at`, it's destructive as well as external. One undo step. Reads the files, outside the project, and registers them so the set keeps them.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `paths` | array of string | yes | The audio files, in the order they go down. |
| `at` | [`Ticks`](README.md#ticks) or null | no | Where the first clip starts. Left out, the insert marker. It isn't snapped: snap first if you want the grid. |
| `spread` | boolean | no | Put each file on a track of its own (as dropping with Cmd or Ctrl held does), new tracks going below the target, instead of one after another on one track. |
| `track` | [`TrackId`](README.md#trackid) or null | no | The audio track to put them on. Left out (or `null`), a new audio track below the last track, as dropping in the drop area does. |

Result: [`AddResult`](README.md#addresult).

### `browser.delete_tag`

**Delete Browser Tag**. Permission: `destructive`. Contexts: `global`, `browser`.

Deletes a tag or a group in the browser: `tag` for a tag, by its full name (`Format|CLAP`) or its own name, `group` for a group, by its name. Deleting a group deletes its tags. Beatlayer's own tags and groups can't be deleted. A deleted tag is gone from every item that carried it, and undo can't bring it back.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `group` | string or null | no | The group to delete, by its name. |
| `tag` | string or null | no | The tag to delete, by its full name or its own name. |

Result: [`TagsState`](README.md#tagsstate).

### `browser.load_selected`

**Load Selected Item**. Permission: `external`. Contexts: `browser`.

Loads the browser's selected audio files into the Arrangement, as Enter or a double-click does: onto the selected track at the insert marker if it's an audio track, otherwise onto a new audio track below the last one, one after another, as one undo step. A clip placed over part of another replaces that part, so when a clip on that track ends after the insert marker it's destructive as well as external. A selected preset file, or a device or rack listed under a label (Drums, Instruments, Audio Effects, MIDI Effects or Modulators), is added to the shown track as `device.add_preset` and `device.add` add it, and a chain preset to the chain list's rack (`chain.load_preset`). While a device is being hot-swapped (`device.hot_swap`), a selected preset or device replaces it instead (`device.replace`), as does a chain preset the chain armed by its Hot-Swap button (`chain.load_preset`); a selected audio file loads into it if the device plays samples (the sampler, or the eight-slot drum sampler, into its selected slot: `device.load_sample`). With one plug-in selected it loads that plug-in instead, as `plugin.load` does: onto the selected track (a new track when none is), an instrument onto a new MIDI track when the selected track holds audio, or in place of the device being hot-swapped. Reads the files, outside the project.

Default keys:

| Shortcut | macOS | Windows | Context | Action in the reference | Binding |
|---|---|---|---|---|---|
| S-BRW-004 | `Enter` | `Enter` | `browser` | Load the selected item | runs it |

Arguments: none (send `{}`).

Result: [`AddResult`](README.md#addresult).

### `browser.move_tag`

**Move Browser Tag**. Permission: `edit`. Contexts: `global`, `browser`.

Moves a tag or a group in the browser to `position`: 0 is the first place in its group, or the first in the list for a group. Beatlayer's own tags and groups can't be moved. Changes the browser's database.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `position` | integer | yes | Where it goes: 0 is the first place in its group or the list. |
| `group` | string or null | no | The group to move, by its name. |
| `tag` | string or null | no | The tag to move, by its full name or its own name. |

Result: [`TagsState`](README.md#tagsstate).

### `browser.open_folder`

**Open Folder**. Permission: `external`. Contexts: `browser`.

Opens or closes a folder in the browser's content pane, listing its folders and audio files indented under it (in the Plug-Ins label, a vendor's folder and its plug-ins). Opening a folder closes the other open folders it isn't inside, unless `keep_others` (Cmd or Ctrl held). Right and Left do this on the selected folder. Changes nothing, but reads folders outside the project.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `path` | string | yes | The folder, as a row of the content pane gives it. |
| `keep_others` | boolean | no | Keep the other open folders open, as holding Cmd (Ctrl) does. Otherwise opening a folder closes every open folder it isn't inside. |
| `open` | boolean or null | no | Open (true) or close (false). Left out, it toggles. |

Result: [`BrowserState`](#browserstate).

### `browser.open_place`

**Open Browser Label**. Permission: `external`. Contexts: `browser`, `browser-sidebar`.

Chooses a label in the browser's sidebar and shows its contents: a place's folders and audio files, the places themselves under `all`, every audio file under `samples`. Ends any search. Up and Down in the sidebar do this. Changes nothing, but reads folders outside the project.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `label` | [`Label`](README.md#label) | yes | The label to choose. |

Result: [`BrowserState`](#browserstate).

### `browser.preview`

**Preview**. Permission: `external`. Contexts: `browser`.

Previews an audio file (`path`, or the selected file): plays it once from its start through the main output, at the preview volume, on a voice of its own, replacing any preview, whether or not the Preview switch is on, as Shift-Enter and Right do. The file is decoded in the background, so it starts a moment later; `browser.state` reports it loading, then playing. Never changes the set. Plays through the audio device.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `path` | string or null | no | The audio file to preview. Left out, the selected file. |

Result: [`PreviewState`](README.md#previewstate).

Takes a folder the person added out of the browser's Places, as its context menu's Remove from Sidebar does. The folder and its files stay on disk. The User Library and Current Project can't be removed.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `path` | string | yes | The folder's path. |

Result: [`BrowserState`](#browserstate).

### `browser.rename_file`

**Rename Browser File**. Permission: `external`. Contexts: `browser`.

Renames the file whose name is open for editing in the browser (or the file at `path`) to `name`, keeping its extension, as typing a name and pressing Enter does after a clip is saved. A name another file in the folder has is refused. Without a `name` the name is kept and editing ends, as Esc does. Renames a file outside the project.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `name` | string or null | no | The new name, without the extension. Left out (or `null`), the name is kept and editing ends, as Esc does. |
| `path` | string or null | no | The file to rename. Left out, the file whose name is open for editing. |

Result: [`BrowserState`](#browserstate).

### `browser.scrub_preview`

**Scrub Preview**. Permission: `external`. Contexts: `browser`.

Moves a playing warped preview to `position` (in seconds) or `fraction` (0 to 1). While the transport runs it moves on the next step of the global launch quantisation; while stopped it moves at once. With Raw on or on an unwarped preview, does nothing.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `fraction` | number or null | no | Where in the preview to scrub to, as a fraction from 0 (the start) to 1 (the end). Give this or `position`. |
| `position` | number or null | no | Where in the preview to scrub to, in seconds from its start. Give this or `fraction`. |

Result: [`PreviewState`](README.md#previewstate).

### `browser.search`

**Browser Search**. Permission: `external`. Contexts: `global`, `browser`, `browser-search`.

Searches the browser by file name, as typing in its search field does: an item matches when every word in `query` appears in its name, ignoring case. Under `all` and `samples` it searches every place (User Library, Current Project, added folders; `samples` only audio files), under a place that place. Returns the browser's state with the results as its rows, in name order; an empty query ends the search. Changes nothing, but lists files outside the project.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `query` | string | yes | The words to find. Empty ends the search. |
| `label` | [`Label`](README.md#label) or null | no | Search under this label instead of the chosen one: `all` searches every place. |

Result: [`BrowserState`](#browserstate).

### `browser.select`

**Select in Browser**. Permission: `external`. Contexts: `browser`.

Selects items in the browser's content pane by path (or, in the Plug-Ins label, by the row's key), replacing the selection or, with `add`, adding to it, as clicking, Shift-clicking, and Up and Down do. While the Preview switch is on, selecting one audio file previews it through the audio device; selecting anything else stops the preview. Changes nothing in the set.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `paths` | array of string | yes | The items to select, by path, as rows of the content pane give them. Empty clears the selection. |
| `add` | boolean | no | Add them to the selection instead of replacing it. |

Result: [`BrowserState`](#browserstate).

### `browser.set_preview`

**Browser File Preview**. Permission: `edit`. Contexts: `global`, `browser`.

Sets the browser's Preview switch (`on`): while it's on, selecting an audio file previews it. Also sets the preview volume (`volume`, a linear gain from 0, silence, to 2, about +6 dB; 1 is unity), which is the Main track's Preview/Cue volume. With no arguments it toggles the switch. Switching it off stops a preview. Both are kept for the next start.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `on` | boolean or null | no | The Preview switch. Left out with `volume` left out too, it toggles. |
| `volume` | number or null | no | The preview volume as a linear gain, from 0 (silence) to 2 (about +6 dB); values outside are brought within it. |

Result: [`PreviewState`](README.md#previewstate).

### `browser.set_raw`

**Raw Preview**. Permission: `edit`. Contexts: `global`, `browser`.

Sets the browser's Raw switch (`raw`): with Raw on, previews play once from the start at the file's original tempo; with Raw off, audio files preview at the set's tempo and loop. With no arguments it toggles the switch. Kept for the next start.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `raw` | boolean or null | no | The Raw switch. Left out, it toggles. |

Result: [`PreviewState`](README.md#previewstate).

| `path` | string or null | no | The file to show, by path. Give this or `clip`. |

Result: [`BrowserState`](#browserstate).

### `browser.state`

**Browser State**. Permission: `external`. Contexts: `global`, `browser`, `browser-sidebar`.

Reports what the browser shows: the sidebar's labels and places, the chosen label, the search text, the content pane's rows (folders and audio files, with open folders' contents under them, or the search results; `offset` and `limit` page through them, 100 at a time by default), the selection, the preview, and how far indexing has got. Changes nothing, but lists files outside the project.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `limit` | integer or null | no | How many rows to return, at most. Left out, 100. |
| `offset` | integer or null | no | The first row to return. Left out, 0. |

Result: [`BrowserState`](#browserstate).

### `browser.stop_preview`

**Stop Preview**. Permission: `read`. Contexts: `global`, `browser`.

Stops the browser's preview, fading it out. Changes nothing else.

Default keys: none.

Arguments: none (send `{}`).

Result: [`PreviewState`](README.md#previewstate).

### `browser.tag_items`

**Tag Items**. Permission: `edit`. Contexts: `global`, `browser`.

Puts tags on items in the browser, or takes them off (`attach` false puts them on). The items are named by their keys: a file or folder by its path, a plug-in by its format and identifier (`clap/org.example.synth`), a device or rack by its row's ID. The tags are named by their full names (`Format|CLAP`) or their own names. Beatlayer's own tags and a tag that comes from a folder can't be taken off. Changes the browser's database, not the files.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `items` | array of string | yes | The items to tag, by their keys. |
| `tags` | array of string | yes | The tags, by their full names or their own names. |
| `attach` | boolean or null | no | Put the tags on the items (true) or take them off (false). Left out, they're put on. |

Result: [`TagsState`](README.md#tagsstate).

### `browser.tags`

**Browser Tags**. Permission: `external`. Contexts: `global`, `browser`.

Reports the browser's tag groups and their tags, in order: Beatlayer's own groups (Content, Format, Creator and Devices) and the person's. With `items`, the keys of the items to report on, it also says which tags each carries and where each comes from: its own, a folder's, or Beatlayer's. Changes nothing, but lists files outside the project.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `items` | array or null | no | The items to report on, by their keys. Left out, none are. |

Result: [`TagsState`](README.md#tagsstate).
