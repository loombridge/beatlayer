## Commands

### `control_surface.banks`

**Device Banks**. Permission: `read`. Contexts: `global`.

Lists a device's banks as a control surface reads them, each with its name and its parameters by ID, name and value text, in the order the surface's device controls take them (at most eight to a bank): a native device's own banks, a rack's macros, a plug-in's configured list in eights, and last the title bar's switch and the menu options. `held` marks a parameter a macro holds. Changes nothing.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `device` | [`DeviceId`](README.md#deviceid) | yes | The device. |

Result: [`BanksResult`](README.md#banksresult).

### `control_surface.dump`

**Dump Control Surface Setup**. Permission: `external`. Contexts: `global`.

Sends a row's surface's setup to the row's output, as the row's Dump button does. It works while the surface declares a setup to send and the output is present (`can_dump` in `control_surface.list`), and fails otherwise. Changes nothing in the set. Sends messages to a device outside Beatlayer.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `row` | integer from 0 to 255 | yes | The row, from 1 to 6. |

Result: [`DumpResult`](README.md#dumpresult).

### `control_surface.list`

**List Control Surfaces**. Permission: `read`. Contexts: `global`.

Lists the six rows of the Control Surfaces table (Settings, Tempo & MIDI): each row's surface by ID and name, its input and output by name with whether each is present, whether the surface runs, waits for a port to appear or is stopped with an error (`state` and `error`), whether Dump is enabled, and, for a running surface, what it reports of itself: its ring and its own mode. Changes nothing.

Default keys: none.

Arguments: none (send `{}`).

Result: [`ListResult`](README.md#listresult).

### `control_surface.lock`

**Lock Device to Control Surface**. Permission: `read`. Contexts: `global`.

Locks a device to a running control surface that supports locking, as Lock to in the device's menu does: the surface's device controls stay on that device whatever is selected. A surface locks to one device at a time, so locking another moves the lock; locking the device it is locked to gives it back. A device may be locked to several surfaces. The lock is surface state: it is never saved or an undo step, and ends when the device is deleted or the surface stops. Arming a MIDI track locks the surfaces to its instrument unless one was locked by hand. Read back by `control_surface.list` (`state.device`) and `device_view.state` (`locks`).

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `row` | integer from 0 to 255 | yes | The row, from 1 to 6. |
| `device` | [`DeviceId`](README.md#deviceid) | yes | The device to lock. |

Result: [`RowInfo`](README.md#rowinfo).

### `control_surface.move_ring`

**Move Session Ring**. Permission: `read`. Contexts: `global`.

Moves a row's session ring, the block of tracks and scenes its grid controls: to a first `track` and `scene` by ID, either or both, or by a `step` (a track or scene, or a page of its width or height). The ring stops where its last column holds the last track and its last row the last scene; with fewer tracks or scenes than its size it stays at the first. Its tracks are the Session View's columns, a folded group's tracks left out, then the return tracks. Selects nothing, launches nothing and adds no undo step; the Session View scrolls to show it. Read back by `control_surface.list` (`state.ring`) and `session.state` (`rings`).

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `row` | integer from 0 to 255 | yes | The row, from 1 to 6. |
| `scene` | [`SceneId`](README.md#sceneid) or null | no | The ring's new first scene. |
| `step` | [`RingStep`](README.md#ringstep) or null | no | A step instead of a place. |
| `track` | [`TrackId`](README.md#trackid) or null | no | The ring's new first track. |

Result: [`RowInfo`](README.md#rowinfo).

### `control_surface.set`

**Set Control Surface**. Permission: `external`. Contexts: `global`.

Sets a row of the Control Surfaces table, as its choosers do: the surface by ID (`control_surface.surfaces`), the input and the output by name (`midi.ports`), any of them; `null` is None, and what is left out stays. A port a row names is open while the row names it, whatever its Track, Sync and Remote switches say, and a port serves one row: naming one another row uses is refused, naming that row. A port that isn't present is kept by name and the surface starts when it appears. The surface starts when its row has it and its input is present, and its output where it needs one; it stops, sending the controller its goodbye, when the row changes, its input goes away or Beatlayer quits. Choosing a surface again restarts one that stopped with an error. The rows are kept for the next start, and are not part of the set or an undo step. Opens and closes devices outside Beatlayer and sends them messages.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `row` | integer from 0 to 255 | yes | The row, from 1 to 6. |
| `input` | string or null | no | The input's name from `midi.ports`, or `null` for None. A port that isn't present is kept by name. Left out, it stays as it is. |
| `output` | string or null | no | The output's name, or `null` for None. Left out, it stays as it is. |
| `surface` | string or null | no | The surface's ID from `control_surface.surfaces`, or `null` for None. Left out, it stays as it is; given again, a surface that stopped with an error starts again. |

Result: [`RowInfo`](README.md#rowinfo).

### `control_surface.set_bank`

**Set Control Surface Bank**. Permission: `read`. Contexts: `global`.

Puts a running surface on a bank of the device its device controls reach, by index as `control_surface.banks` lists them, as the surface's own bank buttons do. The surface shows that bank of that device again whenever it comes back to it while it runs. Changes surface state only. Read back by `control_surface.list` (`state.device`).

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `row` | integer from 0 to 255 | yes | The row, from 1 to 6. |
| `bank` | integer, at least 0 | yes | The bank, from 0, as `control_surface.banks` lists them. |

Result: [`RowInfo`](README.md#rowinfo).

### `control_surface.surfaces`

**Control Surfaces**. Permission: `read`. Contexts: `global`.

Lists every control surface the table's chooser offers, with the ID `control_surface.set` takes, whether it needs an output, whether a device can be locked to it, the size of its ring and whether it has a setup for Dump. Changes nothing.

Default keys: none.

Arguments: none (send `{}`).

Result: [`SurfacesResult`](README.md#surfacesresult).

### `control_surface.templates`

**Controller Templates**. Permission: `read`. Contexts: `global`.

Reads the controller templates again, the one bundled with Beatlayer and the `.bltemplate.toml` files in the User Library's `Controller Templates` folder and its subfolders, and lists every file found with its name, its path (none for the bundled one), whether the chooser lists it and, for a broken file, each mistake with its line. A template that doesn't parse or breaks a rule isn't listed; a User Library template with the bundled one's name replaces it. A listed template is chosen with `control_surface.set` by the ID `template:<name>`. Changes nothing in the set.

Default keys: none.

Arguments: none (send `{}`).

Result: [`TemplatesResult`](README.md#templatesresult).

### `control_surface.unlock`

**Unlock Device from Control Surface**. Permission: `read`. Contexts: `global`.

Gives a row's surface back to the device in focus, ending the lock `control_surface.lock` or arming made. Changes surface state only. Read back by `control_surface.list`.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `row` | integer from 0 to 255 | yes | The row, from 1 to 6. |

Result: [`RowInfo`](README.md#rowinfo).
