## Commands

### `rack.delete_variation`

**Delete Macro Variation**. Permission: `destructive`. Contexts: `device-view`.

Deletes the variation at `index`. One undo step, `Delete Macro Variation`.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `rack` | [`DeviceId`](README.md#deviceid) | yes | The rack. |
| `index` | integer, at least 0 | yes | The variation's place in the rack's list, from 0. |

Result: [`ChangeSet`](README.md#changeset).

### `rack.duplicate_variation`

**Duplicate Macro Variation**. Permission: `edit`. Contexts: `device-view`.

Puts a copy of the variation at `index`, with the same name and values, straight after it. One undo step, `Duplicate Macro Variation`.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `rack` | [`DeviceId`](README.md#deviceid) | yes | The rack. |
| `index` | integer, at least 0 | yes | The variation's place in the rack's list, from 0. |

Result: [`ChangeSet`](README.md#changeset).

### `rack.invert_mapping`

**Invert Macro Mapping**. Permission: `edit`. Contexts: `device-view`.

Swaps a mapping's Min and Max, as Invert Range does. The mapped parameter takes the value the macro gives it now. One undo step.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `rack` | [`DeviceId`](README.md#deviceid) | yes | The rack. |
| `target` | [`MacroTarget`](README.md#macrotarget) | yes | The mapped parameter. |

Result: [`ChangeSet`](README.md#changeset).

### `rack.launch_variation`

**Launch Macro Variation**. Permission: `edit`. Contexts: `device-view`.

Sets every macro of a rack that isn't excluded from variations to the value the variation at `index` holds, at once and on one frame, as the Launch Macro Variation button does. Excluded macros keep their values. Each macro moved is a hand move on it, so its automation envelope is overridden and, while Automation Arm records, the move is written as its envelope. Continuous mapped parameters glide to their new values. One undo step, `Launch Macro Variation`.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `rack` | [`DeviceId`](README.md#deviceid) | yes | The rack. |
| `index` | integer, at least 0 | yes | The variation's place in the rack's list, from 0. |

Result: [`ChangeSet`](README.md#changeset).

### `rack.macros`

**Rack Macros**. Permission: `read`. Contexts: `device-view`.

Reports a rack's macros and mappings: each macro's number, name, colour, value from 0 to 1, how it reads, and whether Randomize leaves it alone, with each mapping's target, device and parameter names and its range in the parameter's units and as positions on its travel, and how many macros show. The query tool's `device` reports the same in its `macros` field.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `rack` | [`DeviceId`](README.md#deviceid) or null | no | The rack; the selected device if left out, which must be a rack. |

Result: [`MacroState`](README.md#macrostate).

### `rack.map_macro`

**Map to Macro**. Permission: `edit`. Contexts: `device-view`.

Maps a parameter inside a rack to one of its macros, numbered 1 to 16, as Map mode's Map button does: `target` is `{"type": "device", "device": d, "param": p}` for a device inside the rack at any depth (or the rack's own chain selector), or `{"type": "chain", "chain": c, "param": "volume" | "pan" | "mute"}` for a chain's mixer. A parameter is mapped to one macro of a rack: mapping it to another moves its mapping there. A new mapping runs the whole of the parameter's travel. One undo step, `Map to Macro`. What it maps reads back in `rack.macros`.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `rack` | [`DeviceId`](README.md#deviceid) | yes | The rack. |
| `macro_number` | integer from 0 to 255 | yes | The macro, numbered from 1. |
| `target` | [`MacroTarget`](README.md#macrotarget) | yes | The parameter to map. |

Result: [`ChangeSet`](README.md#changeset).

### `rack.map_mode`

**Map Mode**. Permission: `edit`. Contexts: `device-view`.

Turns a rack's Map mode on or off, the selected device's or `rack`'s: with it on, every parameter the rack can map is tinted, a Map button shows under each shown macro, and the mappings list takes the browser's place. Turning on another rack's Map mode turns this one's off. Map mode is view state: it isn't an undo step and the set doesn't keep it.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `on` | boolean or null | no | Turn Map mode on (true) or off (false); switches if left out. |
| `rack` | [`DeviceId`](README.md#deviceid) or null | no | The rack; the selected device if left out, which must be a rack. |

Result: [`MacroState`](README.md#macrostate).

### `rack.move_pads`

**Move the Pads**. Permission: `read`. Contexts: `device-view`.

Moves the sixteen notes a drum rack's pad view shows (the rack in focus, or `rack`): to `first` (a note, rounded down to a row), or by `groups` of sixteen notes and `rows` of four from where it is, as dragging the overview's selector, or Up and Down with Cmd (Alt on Windows and Linux) for a row, do. The view stays within notes 0 to 127. It changes only the view: it isn't an undo step, and the set keeps which notes show (`device_view.state`, the rack's `pads.first`).

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `first` | integer or null | no | Show the sixteen notes from here (rounded down to a row); the view moves by `groups` and `rows` from where it is if left out. |
| `groups` | integer or null | no | How many groups of sixteen notes to move up (positive) or down. |
| `rack` | [`DeviceId`](README.md#deviceid) or null | no | The drum rack; the selected device if left out. |
| `rows` | integer or null | no | How many rows of four notes to move up or down. |

Result: [`DeviceViewState`](README.md#deviceviewstate).

### `rack.randomize_macros`

**Randomize Macros**. Permission: `edit`. Contexts: `device-view`.

Sets every macro of a rack that has a mapping and isn't excluded from Randomization to a random position from 0 to 1, as the rack's Rand button does. Macros with no mapping, and excluded ones, keep their values. `seed` makes the values repeatable: the same seed gives the same values, and without one a new seed is picked. Each macro moved is a hand move on it, so its automation envelope is overridden. One undo step, `Randomize Macros`.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `rack` | [`DeviceId`](README.md#deviceid) | yes | The rack. |
| `seed` | integer or null | no | The seed; without one a new seed is picked. |

Result: [`ChangeSet`](README.md#changeset).

### `rack.set_auto_select`

**Auto Select**. Permission: `edit`. Contexts: `device-view`.

Switches a rack's Auto Select, the selected device's or `rack`'s: while it is on, the chain list selects every chain that is processing, which the engine publishes after each block: in an instrument or MIDI effect rack each chain a held note reached, in an audio effect rack each chain whose chain select zone holds the chain selector's value. The devices view follows. It changes only the view: neither the switch nor the selections it makes are undo steps, and the set keeps the switch.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `on` | boolean or null | no | Switch on (true) or off (false); switches if left out. |
| `rack` | [`DeviceId`](README.md#deviceid) or null | no | The rack; the selected device if left out, which must be a rack. |

Result: [`DeviceViewState`](README.md#deviceviewstate).

### `rack.set_macro_style`

**Change Macro Style**. Permission: `edit`. Contexts: `device-view`.

Sets how macro `macro_number` is drawn and which positions it takes: `style` is `knob`, Live's continuous control, `stepped`, a knob that takes `steps` steps, or `radio_buttons`, a stepped macro drawn as its steps' buttons. A stepped macro takes from 2 to 16 steps, 8 by default, and only the positions `k / (steps - 1)`: a drag, an arrow key and `device.set_param` all move it a step at a time. A macro that becomes stepped moves to its nearest step. One undo step, saved with the set and with the rack in a preset.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `rack` | [`DeviceId`](README.md#deviceid) | yes | The rack. |
| `macro_number` | integer from 0 to 255 | yes | The macro, numbered from 1. |
| `style` | [`MacroStyle`](README.md#macrostyle) | yes | The style. |
| `steps` | integer or null | no | How many steps a stepped macro takes, from 2 to 16; the macro's own number of steps when left out. |

Result: [`ChangeSet`](README.md#changeset).

### `rack.set_macro_variation_excluded`

**Exclude Macro from Variations**. Permission: `edit`. Contexts: `device-view`.

Leaves macro `macro_number` out of variations (`excluded` true), so no launch changes it, or puts it back (false). Storing and overwriting still record its value, so switching the exclusion off lets the next launch set it. One undo step, saved with the set.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `rack` | [`DeviceId`](README.md#deviceid) | yes | The rack. |
| `macro_number` | integer from 0 to 255 | yes | The macro, numbered from 1. |
| `excluded` | boolean | yes | Whether it's left out. |

Result: [`ChangeSet`](README.md#changeset).

### `rack.set_mapped_value`

**Change parameter**. Permission: `edit`. Contexts: `device-view`.

Sets a parameter a rack's macro drives to `value`, in the parameter's own units, without overriding its own automation envelope, which waits while the macro drives it. The macro commands run it inside their own undo step; run it directly only to correct a mapped value.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `target` | [`MacroTarget`](README.md#macrotarget) | yes | The mapped parameter. |
| `value` | number | yes | The value, in the parameter's own units. |

Result: [`ChangeSet`](README.md#changeset).

### `rack.set_mapping_range`

**Change Macro Mapping**. Permission: `edit`. Contexts: `device-view`.

Sets the range of a mapping to `min` and `max`, each a position from 0 (the bottom of the parameter's travel) to 1 (its top); Min above Max inverts the mapping, so the parameter falls as the macro rises. The mapped parameter takes the value the macro gives it now. One undo step.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `rack` | [`DeviceId`](README.md#deviceid) | yes | The rack. |
| `target` | [`MacroTarget`](README.md#macrotarget) | yes | The mapped parameter. |
| `min` | number | yes | The bottom of the range. |
| `max` | number | yes | The top of the range. |

Result: [`ChangeSet`](README.md#changeset).

### `rack.set_view`

**Show or Hide a Rack's View**. Permission: `edit`. Contexts: `device-view`.

Shows or hides one of the views of a rack, the selected device or `rack`: the Macro Controls, the chain list (View > Show Chains and Hide Chains) or the selected chain's devices. With every view hidden the rack folds into its view column. It changes only the view: it isn't an undo step, and the set keeps which views each rack shows.

Default keys:

| Shortcut | macOS | Windows | Context | Action in the reference | Binding |
|---|---|---|---|---|---|
| S-DEV-012 | `Plus` | `Plus` | `device-view` | Show the selected rack's chain list | fixes `shown` = `true`; fixes `view` = `"chain_list"` |
| S-DEV-013 | `Minus` | `Minus` | `device-view` | Hide the selected rack's chain list | fixes `shown` = `false`; fixes `view` = `"chain_list"` |

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `view` | [`RackView`](README.md#rackview) | yes | The view. |
| `rack` | [`DeviceId`](README.md#deviceid) or null | no | The rack; the selected device if left out, which must be a rack. |
| `shown` | boolean or null | no | Show (true) or hide (false); switches if left out. |

Result: [`DeviceViewState`](README.md#deviceviewstate).

### `rack.set_zone_editor`

**Show a Rack's Zone Editor**. Permission: `edit`. Contexts: `device-view`.

Shows the zone editor of a rack, the selected device or `rack`, beside its chain list: `editor` is `key` (the Key button), `velocity` (Vel) or `select` (Chain); an audio effect rack has only `select`, and a drum rack none. Leaving `editor` out, or null, hides it (Hide). It changes only the view: it isn't an undo step, and the set keeps which editor each rack shows.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `editor` | [`ZoneKind`](README.md#zonekind) or null | no | The editor to show: `key`, `velocity` (the Vel button) or `select` (the Chain button). None, or left out, is Hide. |
| `rack` | [`DeviceId`](README.md#deviceid) or null | no | The rack; the selected device if left out, which must be a rack. |

Result: [`DeviceViewState`](README.md#deviceviewstate).

### `rack.store_variation`

A rack holds any number of variations. One undo step, `Store Macro Variation`. `rack.macros` reports the variations.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|

### `rack.switch_hot_swap_target`

**Switch Hot-Swap Target**. Permission: `read`. Contexts: `global`.

While a drum rack is being hot-swapped, switches the target between the rack and the rack's last selected pad, as D does; with a pad the target an item loaded from the browser lands on the pad. It changes only the view.

Default keys:

| Shortcut | macOS | Windows | Context | Action in the reference | Binding |
|---|---|---|---|---|---|
| S-VIEW-007 | `D` | `D` | `global` | Switch between a Drum Rack and its last selected pad | runs it |

Arguments: none (send `{}`).

Result: [`DeviceViewState`](README.md#deviceviewstate).

Default keys: none.
