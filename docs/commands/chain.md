## Commands

### `chain.add`

**Add Chain**. Permission: `edit`. Contexts: `device-view`.

Adds a chain to a rack at `index` in the rack's list of chains, where 0 is first. The chain has a new ID from the project, a `name` (left empty, a chain made with a device in it is named after the device's title and an empty one `Chain`), an optional `colour` (0 to 69), `info` text, a `mixer` (leave it out for a new chain's: `volume` 1, `pan` 0, `enabled` true, `solo` false) and its `devices`, each with a new ID, in the order for the kind of rack. A drum rack's chain also takes `receive`, `play`, `choke` and `sends`, and `is_return` makes it one of the rack's return chains (up to six, after the drum chains, audio effects only; a new one has `audio_to` null, which is the rack's own output); any other rack's chain keeps none of these. An empty chain passes its input straight to its mixer, which makes a dry path. One undo step.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `rack` | [`DeviceId`](README.md#deviceid) | yes | The rack. |
| `index` | integer, at least 0 | yes | Where the chain goes in the rack's list, from 0 to its length. |
| `chain` | [`Chain`](README.md#chain) | yes | The chain, with a new ID, and new IDs for its devices. An empty `name` becomes its first device's title, or `Chain` with none. |

Result: [`ChangeSet`](README.md#changeset).

### `chain.create`

**Create Chain**. Permission: `edit`. Contexts: `device-view`.

Makes a chain in a rack at `index` (the end if left out), as the chain list's drop area does, named after what it holds, and selects it: holding a new `device`, a device made from a `preset` file, or the existing device `move_device` moved out of where it is; with none of them it is empty. A `preset` that holds a rack makes a chain holding the rack, and one that holds a chain is loaded as `chain.load_preset` loads it. The chain must fit the rack's kind. In a drum rack a chain made without `index` receives the first pad from the view's first that holds no chain, and with `returns` it is a return chain, after the others. One undo step (Insert Chain).

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `rack` | [`DeviceId`](README.md#deviceid) | yes | The rack. |
| `device` | [`NewDevice`](README.md#newdevice) or null | no | A new device to put in it, as `device.add` describes one. |
| `index` | integer or null | no | Where the chain goes in the rack's list; the end if left out. |
| `move_device` | [`DeviceId`](README.md#deviceid) or null | no | A device to move into it from where it is. |
| `preset` | string or null | no | A preset file: the chain holds a new device with its values. |
| `returns` | boolean | no | Make a return chain of a drum rack (the drop area of its return section): it goes after the drum chains and the rack's other return chains, holds audio effects only, and sends to the rack's own output. A drum rack holds six at most. |

Result: [`ChainAdded`](README.md#chainadded).

### `chain.hot_swap`

**Hot-Swap Chain**. Permission: `read`. Contexts: `device-view`.

While it is armed, loading a chain preset from the browser replaces the chain (`chain.load_preset`), and loading a device or a preset gives the chain that device as its only one (`device.replace`). It changes only the view.

### `chain.load_preset`

**Load Chain Preset**. Permission: `external`. Contexts: `device-view`.

Loads a chain preset file (.blpreset) into a rack as a new chain at `index` (the end if left out), as dropping it on the rack's chain list does, with new IDs for it and its devices, and selects it. With `chain` (or, with no `rack`, the chain armed by its Hot-Swap button) it replaces that chain in its place instead, and the new chain stays armed. The chain must fit the rack's kind. One undo step, named Insert Chain, or Load Preset when it replaces a chain. Reads a file outside the project; the samples the preset carries are written to the User Library's Samples/Preset Samples folder if the set's media store lacks them.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `path` | string | yes | The chain preset file. |
| `chain` | [`ChainId`](README.md#chainid) or null | no | A chain to replace in its place, instead of adding one; the chain armed by its Hot-Swap button, if there is one and no `rack` is given. |
| `index` | integer or null | no | Where the new chain goes in the rack's list; the end if left out. |
| `rack` | [`DeviceId`](README.md#deviceid) or null | no | The rack that takes it as a new chain; the chain list's rack, or the rack being hot-swapped, if left out. |

Result: [`ChainAdded`](README.md#chainadded).

### `chain.save_preset`

**Save Chain Preset**. Permission: `external`. Contexts: `device-view`.

Saves a chain as a Beatlayer chain preset file (.blpreset), as dragging its row into the browser's User Library or a folder in Places does: to `path`, or to a new file named after the chain in `folder`, or, with neither, in the User Library, under Presets/<its rack's category>/<its rack's name>/, numbered if the name is taken. ### `chain.set_receive`

**Change Receive**. Permission: `edit`. Contexts: `device-view`.

Sets the note a drum rack's chain answers: `receive` is `{"note": n}` for one MIDI note from 0 to 127 (Live's octave numbering: C3 is 60, and a pad's chain answers its pad's note, 36 for C1 on the first pad) or `"all_notes"`, which passes every note as it came and leaves the chain's Play and Choke unused. A note-on reaches every chain that answers it; a note no chain answers sounds nothing, and a note-off follows its note-on to the chains it reached whatever Receive says by then. The chain moves to its new note's pad at once. Only a drum rack's drum chains have a Receive. One undo step.

Default keys: none.

### `chain.set_zone`

**Change Chain Zone**. Permission: `edit`. Contexts: `device-view`.

Sets one of a chain's zones: `kind` key (notes 0 to 127), velocity (1 to 127) or select (the chain select zone, 0 to 127), with `low`, `high` and the values each fade spans (`fade_low`, `fade_high`). A zone holds at least one value of its scale and its fades stay inside it. A note in a key or velocity fade reaches the chain with its velocity scaled linearly, silent at the zone's edge and full at the fade's inner edge, as a multisampler's linear fades are; a chain select fade scales the chain's output the same way. A new chain's zones pass everything: every note, every velocity, and chain select 0 alone. An audio effect rack's chains have only a chain select zone, and a drum rack's none. One undo step, as one drag in the zone editor is. What it sets reads back in the `zones` of the query tool's `device` object.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `chain` | [`ChainId`](README.md#chainid) | yes | The chain. |
| `kind` | [`ZoneKind`](README.md#zonekind) | yes | Which zone. |
| `zone` | [`Zone`](README.md#zone) | yes | The new zone. |

Result: [`ChangeSet`](README.md#changeset).

### `chain.solo`

**Solo Chain**. Permission: `edit`. Contexts: `rack-chains`.

Solos the selected chains, or `chain`, as a chain's Solo button does: it is the rack's only soloed chain, and soloing it again unsolos it; with `add` it adds or removes the chain and leaves the others as they are (Cmd-click, Ctrl-click). Other racks and the tracks are not touched. One undo step. `chain.set_solo` sets one chain's solo by its ID.

Default keys:

| Shortcut | macOS | Windows | Context | Action in the reference | Binding |
|---|---|---|---|---|---|
| S-SES-023 | `S` | `S` | `rack-chains` | Solo the selected rack chain | runs it |

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `add` | boolean | no | Add or remove the chain without touching the others' solo, as Cmd-click (Ctrl-click) does; otherwise it's the only one soloed. |
| `chain` | [`ChainId`](README.md#chainid) or null | no | The chain; the selected chains if left out. |

Result: [`DeviceViewState`](README.md#deviceviewstate).
