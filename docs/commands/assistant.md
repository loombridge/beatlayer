## Commands

### `assistant.forget_key`

**Forget Assistant API Key**. Permission: `external`. Contexts: `settings`.

Removes the built-in assistant's API key for its current provider from the OS keychain, so turns are refused until a key is stored again. It changes how the assistant works, so only a person can run it, in the Settings window's Agents page: the agent API refuses it.

Default keys: none.

Arguments: none (send `{}`).

Result: [`AssistantState`](README.md#assistantstate).

### `assistant.send`

**Send to Assistant**. Permission: `read`. Contexts: `global`.

Sends the person's message to the built-in assistant: it joins the conversation in the panel, and the assistant answers it as one turn, whose changes to the set are one undo step. Refused while a turn is running or when the message is empty. It belongs to the person using the app, so the agent API refuses it.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `text` | string | yes | The message. |

Result: [`AssistantPanelState`](README.md#assistantpanelstate).

### `assistant.set_base_url`

**Assistant Base URL**. Permission: `edit`. Contexts: `settings`.

Sets the base URL the assistant's OpenAI-compatible provider is reached at, such as `http://localhost:11434/v1` for a local Ollama server, or `https://openrouter.ai/api/v1` for OpenRouter. Empty uses the provider's own address. The setting is kept for the next start. It changes how the assistant works, so only a person can run it, in the Settings window's Agents page: the agent API refuses it.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `base_url` | string | yes | The base URL, or empty for the provider's own. |

Result: [`AssistantState`](README.md#assistantstate).

### `assistant.set_key`

**Assistant API Key**. Permission: `external`. Contexts: `settings`.

Stores the built-in assistant's API key for its current provider in the OS keychain (macOS Keychain, Windows Credential Manager, the Secret Service on Linux), replacing any key already there. The key is never written to the preferences or a set, never returned in a result, and never shown again: the Settings window only reports whether one is stored. It changes how the assistant works, so only a person can run it, in the Settings window's Agents page: the agent API refuses it.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `key` | string | yes | The API key. |

Result: [`AssistantState`](README.md#assistantstate).

### `assistant.set_model`

**Assistant Model**. Permission: `edit`. Contexts: `settings`.

Sets the model the assistant asks its provider for, such as `gpt-4o-mini` for an OpenAI-compatible API or `claude-sonnet-4-5` for Anthropic. The setting is kept for the next start. It changes how the assistant works, so only a person can run it, in the Settings window's Agents page: the agent API refuses it.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `model` | string | yes | The model. |

Result: [`AssistantState`](README.md#assistantstate).

### `assistant.set_panel_width`

**Assistant Panel Width**. Permission: `read`. Contexts: `global`.

Sets the width in points of the assistant's panel while it is docked, as dragging its left edge does. A width outside 240 to 640 points is brought within them. The width is kept for the next start. Changes nothing in the set and isn't an undo step. It belongs to the person using the app, so the agent API refuses it.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `width` | number | yes | The width in points. A width outside the limits is brought within them. |

Result: [`AssistantPanelState`](README.md#assistantpanelstate).

### `assistant.set_provider`

**Assistant Provider**. Permission: `edit`. Contexts: `settings`.

Chooses the model provider the built-in assistant talks to: an OpenAI-compatible API (OpenAI itself, OpenRouter, or a local server such as Ollama, LM Studio, llama.cpp, or vLLM), Anthropic's Messages API, or Google's Gemini API. The setting is kept for the next start. Its API key is stored separately, in the OS keychain. It changes how the assistant works, so only a person can run it, in the Settings window's Agents page: the agent API refuses it.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `provider` | [`AssistantProvider`](README.md#assistantprovider) | yes | The provider. |

Result: [`AssistantState`](README.md#assistantstate).

### `assistant.stop`

**Stop Assistant**. Permission: `read`. Contexts: `global`.

Stops the assistant's turn that is running, between two of its commands. What it already did stays done, and is the turn's one undo step. Does nothing while no turn is running. It belongs to the person using the app, so the agent API refuses it.

Default keys: none.

Arguments: none (send `{}`).

Result: [`AssistantPanelState`](README.md#assistantpanelstate).

### `assistant.toggle_activity_log`

**Assistant Activity Log**. Permission: `read`. Contexts: `settings`.

Opens or closes the built-in assistant's activity log, which lists every command the assistant ran with the time and the result. It changes how the assistant works, so only a person can run it, in the Settings window's Agents page: the agent API refuses it.

Default keys: none.

Arguments: none (send `{}`).

Result: [`AssistantState`](README.md#assistantstate).

### `assistant.toggle_floating`

**Float Assistant**. Permission: `read`. Contexts: `global`.

Floats the assistant's panel into a window of its own, or docks it back at the main window's right edge. The choice is kept for the next start. Changes nothing in the set and isn't an undo step. It belongs to the person using the app, so the agent API refuses it.

Default keys: none.

Arguments: none (send `{}`).

Result: [`AssistantPanelState`](README.md#assistantpanelstate).
