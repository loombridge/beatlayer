## Commands

### `modulator.arm_map`

**Map**. Permission: `read`. Contexts: `device-view`.

Lights or puts out a modulator slot's Map button, as clicking it does. While one is lit, every parameter in the set that can be mapped is tinted, and clicking one maps it to the slot (`modulator.map`); Esc, or the button again (`armed`: false), puts it out and changes nothing. Lighting a button puts out the one that was lit. It changes only the view: it isn't an undo step, and `device_view.state` reports the lit button in `armed_map`. Only a modulator has slots.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `slot` | integer from 0 to 255 | yes | The slot, from 0 to 7. |
| `armed` | boolean or null | no | Arm (true) or disarm (false); switches if left out. |
| `device` | [`DeviceId`](README.md#deviceid) or null | no | The modulator; the selected device if left out. |

Result: [`DeviceViewState`](README.md#deviceviewstate).

### `modulator.map`

**Map Modulator**. Permission: `edit`. Contexts: `device-view`.

Maps one of a modulator's slots (`slot`, 0 to 7; the Expression Control's are 0 to 4) to a parameter, as the slot's Map button and a click on the parameter's control do. `target` is a mixer control (`volume`, `pan` or `mute`) or a send of any track, or a parameter of any device on any track, but not a parameter of the modulator itself. The slot's earlier mapping is replaced; one modulator doesn't map one parameter twice. A modulator in Remote Control can't map a parameter another modulator in Remote Control holds. A modulator driven by audio, notes or MIDI (the Envelope Follower, Envelope MIDI, Shaper MIDI and Expression Control) doesn't map another modulator's parameters, nor one on a track that feeds its own track, which would make the two tracks wait on each other. The mapping is saved with the set, goes with its target when that is deleted, and shows in the `mappings` field of the query tool's `device`. One undo step (Map Modulator).

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `device` | [`DeviceId`](README.md#deviceid) | yes | The modulator device. |
| `slot` | integer from 0 to 255 | yes | The slot, from 0 to 7. |
| `target` | [`ModTarget`](README.md#modtarget) | yes | The parameter to map: a mixer control or send of any track, or a parameter of any device but the modulator's own. |

Result: [`ChangeSet`](README.md#changeset).

### `modulator.set_shape`

**Edit Shape**. Permission: `edit`. Contexts: `device-view`.

Replaces the breakpoint shape of a Shaper, a Shaper MIDI or a CV Shaper, as every edit of its display does (adding, moving, bending or deleting a breakpoint, making one the sustain breakpoint, Clear and the six presets). `points` lists up to 64 breakpoints in order along the cycle, each with `x` (its place, 0 to 1), `y` (the output there, 0 to 1), `bend` (of the segment starting there, from -1 to 1, 0 straight) and `sustain` (true on the Shaper MIDI's sustain breakpoint, at most one in a shape). An empty list outputs 0. One undo step (Edit Shape).

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `device` | [`DeviceId`](README.md#deviceid) | yes | The Shaper device. |
| `points` | array of [`ShapePoint`](README.md#shapepoint) | yes | The breakpoints, in order along the cycle (at most 64), each with its place and output from 0 to 1 and the bend of the segment starting there, from −1 to 1. |

Result: [`ChangeSet`](README.md#changeset).

### `modulator.unmap`

**Unmap Modulator**. Permission: `edit`. Contexts: `device-view`.

Removes the mapping of a modulator's slot (`slot`, 0 to 7; the Expression Control's are 0 to 4), as its Unmap button does: the parameter plays its own value again from the next frame. A slot with no mapping stays as it is. One undo step (Unmap Modulator).

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `device` | [`DeviceId`](README.md#deviceid) | yes | The modulator device. |
| `slot` | integer from 0 to 255 | yes | The slot, from 0 to 7. |

Result: [`ChangeSet`](README.md#changeset).
