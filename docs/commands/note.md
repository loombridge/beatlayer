## Commands

### `note.add`

**Add Note**. Permission: `edit`. Contexts: `note-editor`, `note-selection`.

Adds a note to a MIDI clip: pitch `key` (0 to 127; 60 is middle C), starting `start` ticks from the beginning of the clip's contents, lasting `length` ticks, with `velocity` (1 to 127; 100 unless given). With Draw Mode on, clicking the note area runs this for a note one grid step long. The new note is selected afterwards, and the edit is one undo step.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `key` | integer from 0 to 255 | yes | The pitch, a MIDI key from 0 to 127; 60 is middle C. |
| `start` | [`Ticks`](README.md#ticks) | yes | Where the note starts, in ticks from the beginning of the clip's contents. Never negative. |
| `length` | [`Ticks`](README.md#ticks) | yes | How long the note lasts, in ticks. Always positive. |
| `clip` | [`ClipId`](README.md#clipid) or null | no | The MIDI clip. Left out, the one the Clip View shows (the Arrangement's selected clip). |
| `velocity` | integer or null | no | The velocity, from 1 to 127; 100 unless given. |

Result: [`NoteEditResult`](README.md#noteeditresult).

### `note.add_expression_breakpoint`

**Add Expression Breakpoint**. Permission: `edit`. Contexts: `note-editor`, `note-selection`.

Adds a breakpoint at `at` (ticks counted from each note's start, from 0 to its length) with `value` to the `envelope` (`pitch`, `slide` or `pressure`) of notes (`notes`, or the selected notes), as clicking a segment in the Clip View's MPE tab does. A breakpoint already at `at` takes the value, and `bend` if given. Nothing changes if the value, the position or the bend is out of range for any of the notes. One undo step, Add Expression Breakpoint. The clip query's notes read the envelope back.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `envelope` | [`Expression`](README.md#expression) | yes | Which envelope: `pitch`, `slide` or `pressure`. |
| `at` | [`Ticks`](README.md#ticks) | yes | The breakpoint's position in ticks counted from each note's start, from 0 to the note's length. |
| `value` | number | yes | The value in the envelope's range. |
| `bend` | number or null | no | The bend of the segment starting there, from −1 to 1. Left out, a breakpoint already there keeps its bend and a new one is straight. |
| `clip` | [`ClipId`](README.md#clipid) or null | no | The MIDI clip. Left out, the one the Clip View shows. |
| `notes` | array or null | no | The notes, by their place in the clip's notes in order. Left out, the selected notes. |

Result: [`NoteEditResult`](README.md#noteeditresult).

### `note.adjust_value`

**Adjust Note Values**. Permission: `edit`. Contexts: `note-editor`, `note-selection`.

Changes one value of notes (`notes`, or the selected notes) by `by`, as the value keys and dragging a marker in an expression lane do: `field` is `velocity` or `release_velocity` (whole numbers, 1 to 127), `chance` (0 to 1; 0.1 is 10 %), or `velocity_deviation` (whole numbers, held to the room each note's velocity leaves: at most 127 less its velocity and at least 1 less). Each note is held within its range, so a change past an end brings it to that end, and a call that changes no note records no undo step. The edited notes stay selected, and the whole drag is one undo step.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `field` | [`NoteField`](README.md#notefield) | yes | Which value to change. |
| `by` | number | yes | How much to add to each note's value; negative lowers it. Whole numbers for the whole-number fields; for `chance`, a fraction (0.1 is 10 %). |
| `clip` | [`ClipId`](README.md#clipid) or null | no | The MIDI clip. Left out, the one the Clip View shows (the Arrangement's selected clip). |
| `clips` | array or null | no | The clips, each with its notes, in place of `clip` and `notes` (Spec: multi-clip-editing R18). Left out with `clip` and `notes`, the selected notes of every clip shown, or of the active clip alone in Focus Mode. |
| `notes` | array or null | no | The notes, by their place in the clip's notes in order (by start, then pitch). Left out, the selected notes. |

Result: [`NoteEditResult`](README.md#noteeditresult).

### `note.chop`

**Chop Note(s) on Grid**. Permission: `edit`. Contexts: `note-selection`.

Chops notes (`notes`, or the selected notes), as Cmd-E (Ctrl-E) with notes selected does: each is cut at every line of `grid` (ticks apart; the editing grid if left out) that falls strictly inside it, or with `parts`, into that many equal parts, from 1 to 64. `steps` then change each note's number of parts, one part more or fewer or the next or previous power of two, as Cmd with Up and Down does while Cmd is held; the number stays from 1 to 64, and a note keeps parts of at least a tick. The parts keep what Split keeps, and stay selected. The edit is one undo step, `Chop Notes`.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `clip` | [`ClipId`](README.md#clipid) or null | no | The MIDI clip. Left out, the one the Clip View shows (the Arrangement's selected clip). |
| `grid` | [`Ticks`](README.md#ticks) or null | no | Cut at every line of a grid this many ticks apart. Left out (and without `parts`), the editing grid. |
| `notes` | array or null | no | The notes, by their place in the clip's notes in order. Left out, the selected notes. |
| `parts` | integer or null | no | Instead of the grid: cut every note into this many equal parts, from 1 to 64. |
| `steps` | array of [`ChopStep`](README.md#chopstep) | no | Changes to make to each note's parts after the first cut, in order, as Cmd with Up and Down does. |

Result: [`NoteEditResult`](README.md#noteeditresult).

### `note.delete_time`

**Delete Time**. Permission: `destructive`. Contexts: `note-editor`, `note-selection`.

Removes a span of the clip's contents (`start` to `end`, or the editor's time selection): deletes the notes that start inside it, shortens a note that runs into it to end at its start, and moves the notes that start at its end or later earlier by its length. The clip's Start and End markers and loop brace stay where they are. The insert marker goes to the span's start and the time selection is cleared. Refused with no span. One undo step. With the note editor focused, Cmd-Shift-Delete (Ctrl-Shift-Delete) and Edit ▸ Delete Time run it.

Default keys: none.

Arguments:

| Name | Type | Required | Description |
|---|---|---|---|
| `clip` | [`ClipId`](README.md#clipid) or null | no | The MIDI clip. Left out, the one the note editor shows. |
| `end` | [`Ticks`](README.md#ticks) or null | no | Where the span ends, after `start`. |
| `start` | [`Ticks`](README.md#ticks) or null | no | Where the span starts, in ticks from the beginning of the clip's contents. Give `start` and `end` together, or neither to take the editor's time selection. |

Result: [`NoteEditResult`](README.md#noteeditresult).

### `note.draw_expression`

**Draw Expression**. Permission: `edit`. Contexts: `note-editor`, `note-selection`.

Draws an `envelope` freehand over notes (`notes`, or the selected notes) as Draw Mode does in the MPE tab: in each note, the stretch from the first step's start to the last step's end loses its breakpoints and gets the `steps`, each a value held for `length` ticks (a breakpoint at its start and one tick before the next). With `absolute`, a pitch step is in semitones above key 0 and each note takes it less its own key. Values outside the range are held in it. One undo step, Draw Expression; a drag runs this once per frame in one transaction.

Default keys: none.

Arguments:

| Name | Type | Required | Description |

| `steps` | array of [`DrawStep`](README.md#drawstep) | yes | The steps drawn, in order of `at`. In each note, the stretch from the first step's start to the last step's end gets the steps in place of its breakpoints. |
| `absolute` | boolean | no | For `pitch`: the steps' values are pitches in semitones above key 0 (the note area's rows), and each note takes the value less its own key. Otherwise they are values in the envelope's range. |
| `clip` | [`ClipId`](README.md#clipid) or null | no | The MIDI clip. Left out, the one the Clip View shows. |
| `notes` | array or null | no | The notes, by their place in the clip's notes in order. Left out, the selected notes. |

### `note.group`

**Group Notes**. Permission: `edit`. Contexts: `note-editor`, `note-selection`.

Puts notes (`notes`, or the selected notes) in a new probability group of `kind`: `play_all` plays all of its notes or none, `play_one` plays one of them, chosen evenly. Left out, `kind` is the one made last in this session, `play_all` until one is chosen. Notes leave the group they were in, a group left with fewer than two notes ends, and the new group's chance is that of its first note in the clip's order, which every note of it takes. Naming every note of one group changes its kind. Refused with fewer than two notes. One undo step, named Group Notes, or Change Group when it changes one group's kind; the notes stay selected. Read the groups back from the clip's `data.midi.groups` and each note's `group`.

Default keys:

| Name | Type | Required | Description |
|---|---|---|---|
| `clip` | [`ClipId`](README.md#clipid) or null | no | The MIDI clip. Left out, the one the Clip View shows (the Arrangement's selected clip). |
| `kind` | [`GroupKind`](README.md#groupkind) or null | no | How the group plays. Left out, the kind made last in this session, `play_all` until one is chosen. |

### `note.move`

**Move Notes**. Permission: `edit`. Contexts: `note-editor`, `note-selection`.
